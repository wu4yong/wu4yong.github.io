    📅 2022-12-21

    总目录与学习路径

    57 讲 · 9 个模块的学习地图｜依据 Redis 7.4 官方文档自绘

    一、一句话定位

    这套课只讲 Redis 官方文档（redis.io/docs 7.4）里写得明明白白的东西：每个定义、每个参数、每条限制都有出处；
    原理部分能讲到「为什么」，但绝不为了顺口而改写成错的。凡是 8.x 的行为差异、新特性、许可证变更，单独开小节标注，不混进主线叙述。

    三、总目录

    M1 认识 Redis（4 讲）

    1. RD01 能力边界与最小概念闭环
    2. RD02 安装、启动与 redis-cli 上手
    3. RD03 配置体系：redis.conf 全貌与运行时 CONFIG 的边界
    4. RD04 RESP 协议与客户端选型

    M2 数据结构与键空间（9 讲）

    1. RD05 String 类型：文本、整数与位操作
    2. RD06 List 类型：两端进出与阻塞语义
    3. RD07 Hash 类型：字段级读写与字段级过期
    4. RD08 Set 类型：唯一性与集合运算
    5. RD09 Sorted Set：分值排序与范围查询
    6. RD10 Stream 类型：追加日志与消费组入门
    7. RD11 HyperLogLog、GEO 与 Bitmap
    8. RD12 过期策略与内存淘汰
    9. RD13 大 key 与热 key

    M3 持久化（4 讲）

    1. RD14 RDB 快照：fork、CoW 与丢数据的边界
    2. RD15 AOF 与三种 appendfsync
    3. RD16 AOF 重写与混合持久化
    4. RD17 备份、迁移与恢复演练

    M4 复制与高可用（8 讲）

    1. RD18 主从复制：PSYNC、replid 与全量增量
    2. RD19 复制配置与四类典型故障
    3. RD20 Sentinel 架构与选举
    4. RD21 Sentinel 故障转移与客户端接入
    5. RD22 Cluster 的 hash slot 与请求路由
    6. RD23 Cluster 搭建、扩容与 reshard
    7. RD24 Cluster 的限制与运维边界
    8. RD25 高可用选型：主从、Sentinel 与 Cluster

    M5 内存与性能原理（7 讲）

    1. RD26 SDS 与 redisObject：字符串到底怎么存
    2. RD27 dict 与渐进式 rehash
    3. RD28 listpack 与 intset：小对象为什么省内存
    4. RD29 skiplist 与 quicklist：ZSet 与 List 的底层
    5. RD30 网络模型与事件循环：五种 IO 模型、epoll、io-threads
    6. RD31 内存碎片与 jemalloc
    7. RD32 慢查询、LATENCY 与 MONITOR

    M6 事务、脚本与消息（6 讲）

    1. RD33 MULTI/EXEC/WATCH：事务能给什么保证
    2. RD34 Lua 脚本与原子性
    3. RD35 Redis Functions：把脚本变成可管理的库
    4. RD36 Pipeline 与批量命令
    5. RD37 Pub/Sub 的投递语义
    6. RD38 Stream 消费组与 pending

    M7 缓存工程（9 讲）

    1. RD39 四种缓存模式与选型
    2. RD40 穿透、击穿与雪崩

    4. RD42 分布式锁：SET NX 与 Lua 释放
    5. RD43 Redlock 与官方立场
    6. RD44 多级缓存：本地 + Redis + 库
    7. RD45 客户端缓存与 TRACKING
    8. RD46 限流与原子计数
    9. RD47 预热、降级与演练

    M8 安全、运维与上线（6 讲）

    1. RD48 ACL 权限模型
    2. RD49 TLS 与安全加固
    3. RD50 监控指标与告警
    4. RD51 容量规划与压测
    5. RD52 版本升级 6 → 7 → 8
    6. RD53 生产故障剧本

    M9 实战串讲（4 讲）

    四、每一讲的结构

    学习目标 → 前置知识 → 理论讲解（官方定义）→ 原理拆解 → 场景说明 → 示例代码或实操步骤 → 常见坑（官方明说过的限制）→ 课后小结 → 思考题。
