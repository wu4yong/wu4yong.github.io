    Spring Boot（二）SSM 整合

    📅 2022-03-25

    基于 Spring Boot 实现 SSM 整合

    SSM（Spring + Spring MVC + MyBatis）在 Spring Boot 里的整合量，从原来的三份 XML 掉到了”两个 starter + 几行 yml”。这一篇按真实项目顺序搭：依赖 → 数据源配置 → 实体与 Mapper → Service 与事务 → Controller 与分页，最后给一份能直接跑的最小表结构与排错清单。

    Spring、MVC、MyBatis 三块拼起来后接上数据库

    1.1 依赖

    <dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <!-- MyBatis 官方 starter：会自动装配 SqlSessionFactory -->
    <dependency>
        <groupId>org.mybatis.spring.boot</groupId>
        <artifactId>mybatis-spring-boot-starter</artifactId>
        <version>2.2.0</version>
    </dependency>

    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <scope>runtime</scope>
    </dependency>

    <!-- 可选：连接池（HikariCP 已是默认，Druid 用于监控） -->
    <dependency>
        <groupId>com.alibaba</groupId>
        <artifactId>druid-spring-boot-starter</artifactId>
        <version>1.2.6</version>
    </dependency>

    <dependency>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <optional>true</optional>
    </dependency>
</dependencies>
    依赖
    解决什么
    不写会怎样
    starter-web
    MVC + 内嵌 Tomcat + Jackson
    起不来 Web 容器
    mybatis-spring-boot-starter
    SqlSessionFactory + Mapper 扫描
    Mapper 注入失败
    mysql-connector-java
    JDBC 驱动
    启动时报 Driver class not found
    druid-spring-boot-starter
    连接池 + 监控页
    默认走 HikariCP

    注意 mybatis-spring-boot-starter 是第三方 starter，版本要自己指定（不在 parent 的管辖范围内）。

    1.2 数据源与 MyBatis 配置

    spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://127.0.0.1:3306/demo?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: root
    password: 123456
    hikari:
      maximum-pool-size: 10
      minimum-idle: 2
      connection-timeout: 30000

mybatis:
  mapper-locations: classpath:mapper/*.xml     # XML 位置
  type-aliases-package: com.example.demo.domain
  configuration:
    map-underscore-to-camel-case: true         # user_name -> userName
    default-statement-timeout: 30

    三个高频错误直接对应上面三行：

    • 漏 serverTimezone → The server time zone value is unrecognized
    • 漏 mapper-locations → Invalid bound statement (not found)
    • 漏驼峰映射 → 查出来字段全是 null

    1.3 表结构与实体

    CREATE TABLE `user` (
  `id`        BIGINT PRIMARY KEY AUTO_INCREMENT,
  `user_name` VARCHAR(64) NOT NULL,
  `age`       INT DEFAULT NULL,
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
    @Data
public class User {
    private Long id;
    private String userName;      // 对应 user_name（靠驼峰映射）
    private Integer age;
    private LocalDateTime createTime;
}

    1.4 Mapper：XML 与注解怎么选

    @Mapper
public interface UserMapper {
    User findById(Long id);

    List<User> findByAge(@Param("min") int min, @Param("max") int max);

    int insert(User user);

    int updateAge(@Param("id") Long id, @Param("age") int age);

    int deleteById(Long id);
}
    <?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.demo.mapper.UserMapper">

    <select id="findById" resultType="User">
        SELECT * FROM `user` WHERE id = #{id}
    </select>

    <select id="findByAge" resultType="User">
        SELECT * FROM `user` WHERE age BETWEEN #{min} AND #{max}
    </select>

    <insert id="insert" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO `user`(user_name, age) VALUES (#{userName}, #{age})
    </insert>

    <update id="updateAge">
        UPDATE `user` SET age = #{age} WHERE id = #{id}
    </update>

    <delete id="deleteById">
        DELETE FROM `user` WHERE id = #{id}
    </delete>
</mapper>
    方式
    适合
    缺点
    注解 @Select/@Insert
    一行简单 SQL
    多表/动态 SQL 立刻爆炸
    XML 映射
    动态 SQL、复用片段、复杂结果映射
    文件多、要维护 namespace
    MyBatis-Plus
    单表 CRUD 全自动
    复杂查询仍要写 SQL

    @Mapper 与 @MapperScan 二选一：接口少就逐个 @Mapper；接口多就在启动类上 @MapperScan("com.example.demo.mapper")，一次性扫完（写了 @MapperScan 就不要再逐个标，重复注册会报警告）。

    1.5 Service 与事务

    @Service
@RequiredArgsConstructor
public class UserService {

    private final UserMapper userMapper;

    public User get(Long id) {
        return userMapper.findById(id);
    }

    @Transactional(rollbackFor = Exception.class)
    public void transfer(Long from, Long to, int amount) {
        userMapper.updateAge(from, -amount);   // 示例：改余额
        if (amount > 100) throw new IllegalStateException("限额");
        userMapper.updateAge(to, amount);      // 抛异常后整体回滚
    }
}

    @Transactional 在 Spring Boot 里默认已开启（DataSourceTransactionManager 自动装配），不需要 XML。但同类内部方法互调不会走代理，事务失效——这是事务失效最常见的原因。

    1.6 Controller 与统一返回

    @RestController
@RequestMapping("/users")
@RequiredArgsConstructor
public class UserController {

    private final UserService userService;

    @GetMapping("/{id}")
    public Result<User> get(@PathVariable Long id) {
        return Result.ok(userService.get(id));
    }

    @PostMapping
    public Result<Long> create(@RequestBody User user) {
        userMapper.insert(user);
        return Result.ok(user.getId());
    }
}

@Data
class Result<T> {
    private int code;
    private String msg;
    private T data;
    static <T> Result<T> ok(T data) {
        Result<T> r = new Result<>();
        r.code = 0; r.msg = "ok"; r.data = data;
        return r;
    }
}

    分页推荐 PageHelper（starter 依赖 pagehelper-spring-boot-starter）：

    PageHelper.startPage(pageNo, pageSize);
List<User> list = userMapper.findByAge(18, 60);
PageInfo<User> info = new PageInfo<>(list);   // total / pages / list

    1.7 最小验证清单

    1. 启动日志里能看到 HikariPool-1 - Starting... 和 Tomcat started on port(s): 8080
    2. /users/1 能返回 JSON，字段名是驼峰（说明映射生效）
    3. 插入后 getId() 有值（说明 useGeneratedKeys 生效）
    4. 事务方法里故意抛异常，数据库没有脏数据

    1.8 排错对照

    报错
    原因
    修法
    Invalid bound statement (not found)
    XML 没被加载 / namespace 不匹配
    检查 mapper-locations 与方法名
    Consider defining a bean of type 'UserMapper'
    没 @Mapper 也没 @MapperScan
    补注解
    字段全 null
    驼峰映射未开
    map-underscore-to-camel-case: true
    Unknown column
    @Param 没加 / 名字写错
    多参数方法必须加 @Param
    时区报错
    缺 serverTimezone
    URL 里补 Asia/Shanghai
    No qualifying bean of type DataSource
    没配 spring.datasource 或驱动缺失
    补 URL 与驱动

    1.10 清单

    1. SSM 整合只需要两个 starter + 一段 yml，XML 全退役
    2. mapper-locations、驼峰映射、serverTimezone 三个坑占新手问题一大半
    3. @Mapper 与 @MapperScan 二选一，别重复
    4. 多参数方法必须 @Param，否则 #{name} 取不到值
    5. 事务默认已开，同类内部调用会绕过代理导致失效
    6. 插入主键用 useGeneratedKeys + keyProperty
    7. 分页优先 PageHelper，避免手写 LIMIT 拼串
