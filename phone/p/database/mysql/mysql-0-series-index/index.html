总目录与学习路径

54 讲 · 8 个模块的学习地图｜以 MySQL 8.4 LTS 为基线自绘

一、一句话定位

这套课以 MySQL 8.4 LTS 为主线，每个结论都对齐官方 Reference Manual；8.0 与 5.7 的差异不混进正文，统一放在每讲末尾的「版本差异」小节。面试篇单独成篇，不并入这条学习路径。

三、总目录

M1 入门与环境（5 讲）

  1. MQ01 一条 SQL 的一生：五层各干一件事
  2. MQ02 版本与选型：8.4 是今天的基线
  3. MQ03 安装与初始化：Linux、Docker、Windows、macOS
  4. MQ04 客户端与图形化工具

M2 SQL 基础（10 讲）

  1. MQ05 库与表：DDL、字符集与排序规则
  2. MQ06 数据类型总览：整数、DECIMAL、字符串、时间与 JSON
  3. MQ07 选类型的四条原则
  4. MQ08 增删改：INSERT / UPDATE / DELETE 与批量写入
  5. MQ09 单表查询：WHERE、排序、分页与 NULL 语义
  6. MQ10 聚合与分组：GROUP BY、HAVING、WITH ROLLUP
  7. MQ11 多表连接：INNER / LEFT、自连接与连接顺序
  8. MQ12 子查询与派生表：EXISTS、IN 与 LATERAL
  9. MQ13 窗口函数与 CTE
  10. MQ14 内置函数：字符串、日期与 JSON 函数

M3 表设计与索引（6 讲）

  1. MQ15 约束：主键、唯一、外键、CHECK 与默认值
  2. MQ16 三大范式与反范式：什么时候故意冗余
  3. MQ17 主键选型：自增、雪花与 UUID 的页分裂代价
  4. MQ18 索引基础：B+Tree、聚簇索引与二级索引
  5. MQ19 索引设计：联合索引、最左前缀、覆盖索引与索引下推
  6. MQ20 索引失效的八种写法

M4 事务与并发（7 讲）

  1. MQ21 事务与 ACID、四种隔离级别
  2. MQ22 MVCC：版本链、Read View 与可重复读怎么实现
  3. MQ23 幻读与间隙锁：RR 下到底解决了什么
  4. MQ24 锁的类型：表锁、行锁、意向锁、记录锁与临键锁
  5. MQ25 死锁：成因、检测与四种规避
  6. MQ26 长事务与大事务的代价
  7. MQ27 分布式事务：XA 与本地消息表

M5 存储引擎与内部（7 讲）

  1. MQ28 InnoDB 架构总览：Buffer Pool、Change Buffer 与 Log Buffer
  2. MQ29 页与行格式：16KB 页、DYNAMIC 与行溢出
  3. MQ30 redo log：WAL、两阶段提交与崩溃恢复
  4. MQ31 undo log 与 purge：多版本是怎么留下来的
  5. MQ32 binlog：三种格式与复制基础
  6. MQ33 存储引擎对比：为什么生产几乎只剩 InnoDB
  7. MQ34 表空间与文件：ibdata、独立表空间与 undo 表空间

M6 性能与优化（8 讲）

  1. MQ35 EXPLAIN 逐列讲
  2. MQ36 慢查询日志与 profiling：定位一条慢 SQL
  3. MQ37 优化器与统计信息：为什么它选错了索引
  4. MQ38 索引优化实战：回表、覆盖与索引合并
  5. MQ39 SQL 改写：深翻页、OR、子查询与 UNION
  6. MQ40 JOIN 优化：驱动表与连接算法
  7. MQ41 排序与分组优化：filesort 与临时表
  8. MQ42 参数调优：buffer pool、连接数与并发线程

M7 高可用与架构（6 讲）

  1. MQ43 主从复制：一条 binlog 怎么到从库
  2. MQ44 复制格式与延迟：半同步与并行复制
  3. MQ45 读写分离：中间件、客户端与延迟读一致性
  4. MQ46 高可用方案：MHA、MGR 与 Orchestrator
  5. MQ47 分库分表：垂直、水平与分片键
  6. MQ48 分片中间件：ShardingSphere 的路由与归并

M8 运维与安全（6 讲）

  1. MQ49 备份恢复：mysqldump、xtrabackup 与 PITR
  2. MQ50 在线 DDL：INSTANT、gh-ost 与 pt-osc
  3. MQ51 监控指标与告警
  4. MQ52 权限体系与最小权限
  5. MQ53 安全加固：TLS、注入与账号隔离
  6. MQ54 常见故障与应急

四、每一讲的结构

学习目标 → 前置知识 → 理论讲解（官方定义）→ 原理拆解 → 场景说明 → 示例代码或实操步骤（含 Java 侧落地）→ 常见坑 → 版本差异 → 课后小结 → 思考题（逐题带参考回答）。
