为什么没有更多开发者”使用平台”？

一篇颇具洞察力的文章，探讨我们为何常常重新实现浏览器已经提供的东西——而作者本身通常是站在”平台”这一边的。文章在 Hacker News 上引发了热烈的讨论，许多人认为原生控件和 API 过于有限或笨拙，难以依赖。

免费课程：使用 OpenAI Codex 更快构建雄心勃勃的现代界面

跟随 Katia Gil Guzman 一起学习这门免费的 Codex 课程，了解智能体编程如何改变前端开发。课程涵盖环境搭建、提示词、反馈、技能、自动化、部署等内容。

Master.dev 赞助

Preact 11 发布

距离 Preact 11 之路启程已过去六年，这个广受欢迎的”拥有相同现代 API 的 React 替代品”终于迎来最新版本：改进了 hydration，支持自动 ref 转发，并提供仅 ESM 的包。升级指南涵盖了所有变更。

Preact 团队

Nuxt 4.6：朝着服务器无关的 Nuxt 迈出一大步

这个全栈 Vue 框架的一次重磅发布：服务器层不再将你绑定到 Nitro（纯 Vite 服务器构建现已成为实验性选项）、内置会话（sessions）、支持 Vue Vapor，以及全新的 CLI（Nuxt CLI 4.0）。

Daniel Roe

简讯

  • 多产的包维护者 Sindre Sorhus 已关闭外部 pull request，原因是 AI 贡献垃圾太多，不过他仍会继续维护自己的项目。SWC 现在也将 PR限制为受信任的贡献者。

  • 📊 JavaScript Framework Benchmark 网站新增了 Chrome 154 的测试结果，涵盖 196（！）种应用实现方式、每种方式的性能表现及其体积大小。

  • npm stage publish 现在可以创建新包，因此自动化工作流不再需要手动完成首次发布。

版本发布

  • Remix 3.0 – 尚无官方公告，但这是重建版全栈框架的新稳定版本，不再需要 React。不过 RC 发布公告里有更多信息。

  • Ink 8.0 – 这个流行的 TUI 渲染器现在要求 React 19.3，并新增滚动偏移，用于构建可滚动视图——这在如今的编程智能体 UI 中已很常见。

  • Inferno 10 – 为极致渲染速度而生的类 React UI 库。现在将更多工作从运行时转移到其 JSX 编译器。

  • Qwik 2.0 RC、pnpm 12.10、Ember 7.3、Video.js 10、ESLint 10.12

🛠 代码与工具

TanStack Charts 1.0：可组合、类型化的图表库

一种与框架无关的方式，用类型化、可 tree-shake 的 JavaScript 以声明式指定可视化，然后通过 SVG 或 Canvas 渲染。内容丰富的示例目录（附代码）展示了折线图、柱状图、饼图和面积图，以及热力图、箱线图、直方图等。

Tanner Linsley

SvelteKit 3：”同一个框架，只是更精致了一些”

Svelte 官方应用框架迎来一次清理/打磨式发布。新功能不多，远程函数（remote functions）仍处于实验阶段，但现有用户需要做一些迁移工作（不过 sv migrate 能处理其中大部分）。

Svelte 团队

Effect 4.0：更小的核心，重建的运行时

这个用于构建可靠应用的流行库经历了一次彻底重写，可处理资源管理、并发、重试、类型化错误等棘手问题。v4.0 号称最小包体积缩小 5 倍，每个并发任务占用的内存减少 86%。

Sebastian Lorenz

Lightpanda 1.0：面向自动化的无头浏览器

一个用 Zig 从零构建的无头浏览器。由于不做图形渲染，它的 CPU 和内存占用只是 Chrome 的一小部分（我刚跑的一次只用了约 35MB 内存！）。可以用 Puppeteer/Playwright 驱动它，更有趣的是，还可以用纯 JavaScript 为它编写脚本。

Francis Bouvier

版本发布

  • eslint-cssicorn 0.1 – Sindre Sorhus 将其庞大的 eslint-plugin-unicorn ESLint 规则集中的纯 CSS 规则移入了一个新的专注 CSS 的包。

  • pixelmatch 8.0 – 小巧、快速的像素级图像比较库。改用更符合感知的颜色度量，因此差异计数会发生变化。

  • PR Comment Inbox – Nicholas Zakas 的 GitHub 评审评论收件箱，采用电子邮件式界面，支持会话线索和已读/未读状态。

  • Electron Forge 8 – 用于构建、打包和发布 Electron 应用的工具包。

  • Redux Toolkit 2.13 – Redux 官方工具集新增对 TypeScript 7 的支持。

  • 📊 State of Devs 2026 调查结果已公布，超过 5,000 名开发者分享了他们对软件开发职业安全感、AI 使用与看法、业余爱好以及工作场所（包括收入）的看法。

  • 🤖 Pi 1.0，这个基于 Node.js 的极简编程智能体，通过”Codemode”新增了对 MCP 和非 LLM 模型的支持。他们还推出了实验性的 Pi Durable 运行时，用于运行具备韧性的长期智能体流程。
