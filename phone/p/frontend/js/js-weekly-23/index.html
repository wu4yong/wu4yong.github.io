JSIR：Google 开源的 JavaScript 高级中间表示

Google 开源了一个新工具（JSIR），并提出了一个用于 JavaScript 的行业标准 IR（中间表示——如果说 AST 告诉你代码长什么样，IR 则告诉你代码做什么）。该工具已在 Google 内部用于代码分析和代码转换，其底层理念可能成为新一代工具链的基础。

Zhixun Tan (Google)
