Rust 仍在吞噬 JavaScript（2026 年版）

我们 2021 年阅读量最高的文章迎来了 2026 年更新。Lee Robinson（当时在 Vercel，现在在 Cursor）曾预测 Rust 将被用于重写越来越多 JavaScript 生态系统的工具，而 Rspack、Biome、Turbopack 以及 Bun 近期的重写不断印证着他的正确性。

Lee Robinson

Octane：React 的编程模型，但是编译式的

Inferno 创建者带来的继任者：一个编译式的类 React 框架（与 React 的差异详见此处），提前生成响应式能力，无 VDOM。支持 TSX/JSX 和 TSRX，集成了 TanStack Query 和 Router，以及其它常见的 React 库。

Dominic Gannaway

🛠 代码与工具

🌐 MapLibre GL JS 6.0: Web 交互式矢量地图

一个基于 WebGL 的库，用于渲染交互式矢量瓦片地图，在 2020 年 Mapbox GL JS 变更许可后从其中 fork 而来。v6 仅支持 ESM、要求 WebGL 2，并带来全面的性能提升。发布说明和 v5→v6 迁移指南。

MapLibre

Bruno 4.0: 开源 HTTP API 客户端

一个开源的、JavaScript 驱动的轻量级 Postman 替代品，用于测试和对 HTTP API 发起请求。

Anoop M D、Anusree P S 及贡献者

tslog 5: 适用于 Node、Deno、Bun 和浏览器的零依赖 Logger

从头重写，现在仅支持 ESM，也覆盖 Worker 和 React Native。默认输出美观，可选 JSON 格式，还有中间件、文件/HTTP/Worker 传输、密钥掩码，以及能够通过 Source Map 解析回原始 .ts 行号的错误堆栈。GitHub 仓库。

Eugene Terehov

eslint-package-json: 针对 package.json 的强大 ESLint 规则

一个 ESLint 插件，可以捕获 package.json 中的错误，如无效的名称、错误的版本范围、损坏的 exports、冗余的 files 条目等，并能自动修复其中许多问题。

Sindre Sorhus

Shadscan: 面向 shadcn 应用的确定性 UI 审计

一个静态分析你的 shadcn 组件的工具，使用近 60 条确定性检查（无需 AI 或 API Key），涵盖可访问性、状态和组合方面的基本最佳实践。
