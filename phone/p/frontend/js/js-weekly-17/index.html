Oxfmt Beta: 基于 Rust 的极速 JavaScript 代码格式化工具

一个100% 兼容 Prettier 的 JavaScript 代码格式化工具（也是 Oxlint 的姊妹项目），号称比 Prettier 快 30 倍，比 Biome 快 3 倍。自 alpha 版本以来，现已支持嵌入式语言格式化（JSX、YAML、HTML 等）、Tailwind CSS 类名排序、import 排序等功能。

Boshen、Dunqing 和 Sugiura (VoidZero)

Wijmo 出品的 FlexGrid: 业界领先的 JavaScript 数据表格

一个用于构建现代 Web 应用的快速灵活的 DataGrid。核心网格模块包含关键功能和虚拟化渲染。可按需选择特殊功能以保持应用体积小巧。为 JavaScript 构建，并可扩展至 Angular、React 和 Vue。

Wijmo From MESCIUS 赞助

告别 innerHTML，迎接 setHTML：更强的 XSS 防护

从 v148 开始，Firefox 支持 Sanitizer API。与其通过 innerHTML 将 HTML 赋值给 DOM 节点，不如使用 setHTML 以获得默认的安全性。这是一项前沿特性，Chrome 146（beta）也已添加支持，但 Safari 尚未跟进，因此 DOMPurify 在一段时间内仍将有用。

通过指针压缩将 Node.js 内存使用减半

🛠 代码与工具

OpenSeadragon 6.0: 高分辨率图像 Web 查看器

这是一个将近 15 年历史的项目的重大进步，也是为数不多的稳定可靠的选择之一，用于渲染超高分辨率图像，供用户缩放和平移浏览。版本 6 引入了新的异步和缓存管理管道，在大规模场景下效率大幅提升。

OpenSeadragon 贡献者

💡 OpenSeadragon 最近被用作 Isometric NYC（本身就非常值得一读！）项目的基础。

SurveyJS: 用于动态 Web 表单的 JavaScript 库

在应用中（React/Angular/Vue）构建 JSON 驱动的表单，不受 SaaS 限制。完全拥有你的数据。

SurveyJS 赞助

bignumber.js 10.0: 任意精度算术库

解决了 JavaScript Number 和 BigInt 类型的局限性，例如需要处理非常大的非整数时。方便的是，该库在页面上直接提供，你可以在 JS 控制台中试用。

Michael Mclaughlin

⏳ Slowmo: 减慢、暂停或加速时间

一个既可作为库也可作为浏览器扩展使用的工具，用于在浏览器中减慢时间以进行调试和测试。它可以减慢多种事物，包括 CSS 动画、过渡效果和 requestAnimationFrame。

Francois Laberge

React Doctor: 给你的 React 代码做个快速体检

来自 React Scan 和 React Grab 创建者的最新工具，扫描你的代码库并给出 0-100 的评分。（GitHub 仓库。）

Aiden Bai

💡 Angular Doctor 是一个受 React Doctor 启发的 Angular 应用类似项目。

Vue Scrollama 3.0: 用于滚动驱动交互的 Vue 组件

Scrollama 是一个用于实现所谓”滚动叙事”的库，其中滚动位置会影响视口中某些元素的存在状态。这个项目使其更易于在 Vue 中使用。

Vignesh Shenoy
