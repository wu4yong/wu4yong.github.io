现代 Web 类型：为更新的 Web API 提供 TypeScript 支持

TypeScript 的 DOM 类型只包含已在多个浏览器引擎中发布的 API，因此像元素级 startViewTransition 和 fetchLater 这样的东西会报错。modern-web-types 是一个可直接替换 lib.dom 的库，补充了在任一浏览器引擎中已发布的缺失接口和成员。

Philip Walton (Google)

React 19.3 发布

一次重要的次要版本发布，让视图过渡和 Fragment Refs 稳定，新增 Trusted Types 支持，等等。我们在上周的 React Status 中做了更深入的报道。

React 团队

简讯

  • 🔒 攻击者正在扫描暴露的 Vite 开发服务器，利用 server.fs.deny 绕过漏洞（今年早些时候已在 Vite 7.3.2 和 8.0.5 中修复），从 .env 文件中窃取凭证。Vite 默认监听 localhost，但请再次检查你的配置。
  • Safari 27 昨天发布（同时还有 macOS/iOS 27），带来了我们上周报道过的模块加载器重写，因此顶层 await 现在能在所有主流浏览器中可靠工作。
  • TC39 两周后将在东京召开会议。这是议程：三个迭代器辅助方法的后续提案（join、includes 和 chunking）都将争取进入 Stage 4，此外还有更多内容。
  • 🔒 从本周四开始，OpenJS 基金会的 CVE 团队将休息一段时间，直到 10 月 6 日，原因是 AI 生成报告激增导致的倦怠。正在被积极利用的问题仍会得到响应。
  • 🔒 npm 现在会在任何账户通过恢复代码成功登录后，对其施加为期 72 小时的临时“安全冻结”。

版本发布

  • pnpm 12.4 – 这个包管理器现在可以在同一个 workspace 中，与 npm 包一起管理 Rust crate 和 Python 包。
  • Playwright 1.63 – 测试现在可以声明一个具名 lock，这样共享同一资源的测试就永远不会并发运行。
  • Node.js v26.8.2（Current） 和 v24.21.0（LTS） – 两者都包含 Undici 的安全版本，修复了多个漏洞。
  • React Router 8.4、Vite 8.3、Moment.js 2.31.0（安全版本）。
