💡 GitHub 正持续聚焦 npm 安全，并开始在发布时扫描每个 npm 包以查找恶意软件。这会带来一些影响，包括发布与可供安装之间出现延迟。

简讯

  • 🚨 事件仍在发展： 流行的 keyv 和 cacheable 包今天遭到一个窃取凭证的蠕虫入侵。影响仍在持续，目前已有数百个包受到波及。
  • Astro 团队和 Svelte 团队发布月度更新：前者见这里，后者见这里。SvelteKit 3 的首批预览版现已可用。
  • ⚖️ Deno 诉 Oracle 的 JavaScript™ 商标案仍在继续，随着取证推进，Deno 同意第五次延期请求。
  • 以高产 JS 库著称的 TanStack 已完成品牌焕新，并推出了新的 “Markdown” 和 “Highlight” 库。

版本发布

  • MobX 7.0 – 这个流行的状态管理器瘦身了，移除了废弃项，更新了 React 绑定，现在始终使用由 Proxy 支持的 observable 对象和数组。
  • Javy 9.1 – 用于将 JavaScript 编译为 WebAssembly、供 WASM 运行时使用的工具链。
  • Node.js v26.6.0 (Current) 和 v24.19.0 (LTS)
  • Vite 8.2、React Three Fiber 9.7、Lerna 10.0、Hono 4.13.0
