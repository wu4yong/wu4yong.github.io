JavaScript 立即执行函数

分类：frontend · js ｜ 标签：web

JavaScript

立即执行函数

  • 不是专门制定发布的，而是通过 () 的特性研发的
  • 在 ES6 之前主要用途是 模仿块级作用域，解决闭包带来的问题，在 ES6 之后，在该场景下使用 块级作用域 替换 立即执行函数，代码更加简洁

两种写法

  1. (function(){}()) W3C建议第一种
  2. (function(){})()

执行原理

  1. 原理就是 () 既可以把函数声明转化为表达式， 同时又是执行符号
  2. 不仅有 () 能把函数声明转化为表达式， +function(){} -function(){} 等一元运算符都能将函数声明转化为表达式
  3. 只有表达式才能被执行符号执行 () 叫执行符号
  4. 能被执行符号执行的函数会被忽略名字

为什么立即执行函数能绕开声明限制

  • 函数声明语句不能被执行符号直接调用，把它包进 () 后变成函数表达式，表达式可以立即执行
  • 除圆括号外，+、- 等一元运算符同样可以把函数声明转换为表达式
  • 被执行符号调用之后，函数名被忽略，不会在当前作用域留下可引用的函数名
  • 函数提升只适用于函数声明，函数表达式只在执行到赋值语句时绑定，提前访问会报错
  • 函数声明是语句，不能作为表达式立即调用；IIFE 利用括号把语句位置改写成表达式位置

常见写法与参数传递

  • 两种经典写法：(function () {})() 和 (function () {})()，参数在调用括号中传入
  • 箭头函数也可以作为立即执行函数：(() => {})()，箭头函数表达式本身总是匿名
  • 箭头 IIFE 没有函数名，与命名函数表达式的内部自指能力不同
  • 把全局对象作为参数传入函数体内（如 (function (global) {})(window)），便于在隔离作用域内引用全局对象
  • 传入的参数在隔离作用域内以局部参数名出现，不占用外层命名空间
  • 立即执行函数可以把内部暴露的接口作为返回值赋给外部变量，外部只能通过这些方法访问内部状态
  • 函数表达式也可以命名，函数名只在函数体内可见，用于内部自指或调试栈跟踪

模块模式：私有变量与公共方法

  • IIFE 形成独立作用域，内部声明的变量和函数不会污染外层作用域，也不会覆盖外层同名变量
  • IIFE 内部声明的函数只在隔离作用域内可见，不会挂到全局对象
  • 嵌套的内部函数对外部函数是私有的，它形成闭包，可以访问外部函数的参数和变量，外部函数却不能访问内部函数的变量
  • 闭包会保存它可见作用域中的所有参数和变量；每次调用外部函数都会重新创建一份独立闭包
  • 闭包中的变量在内部方法被外部引用期间持续保留
  • 模块模式可以返回一个对象，对象上的方法闭包引用同一批私有变量
  • 模块模式返回的方法持有私有词法环境的引用，方法之间共享同一份状态
  • 返回的内部方法共享同一份私有词法环境，对外只暴露方法，不直接暴露数据
  • 外部无法绕过返回的方法直接读取或改写内部私有变量
  • 每次调用 IIFE 会创建一份独立的词法环境，多份实例之间的私有变量互不影响
  • 早期在循环中用 var 声明的变量被所有回调共享，IIFE 可以在每次迭代包裹一层，形成独立词法环境
  • 只有当返回的内部函数不再被引用时，闭包占用的内存才具备被回收的条件
  • 内部函数的变量对外部函数不可见，封装边界由词法作用域决定
const counter = (function () {
  let privateCount = 0;
  return {
    increment() {
      privateCount += 1;
    },
    value() {
      return privateCount;
    },
  };
})();

闭包与作用域链的配合

  • 多层嵌套函数形成的闭包递归包含所有外层函数的作用域，构成作用域链
  • 作用域链查找从当前函数作用域开始，逐层向外直到全局作用域
  • 同一作用域内参数或变量同名时，更近的内部作用域优先级高于外部作用域
  • 内部函数的生存周期长于外部函数时，外部函数中的变量会被闭包保留下来
  • 这种数据隐藏和封装是闭包带来的好处，与面向对象中的私有方法作用相近

用途与现代替代

  • IIFE 常出现在需要立即返回结果的初始化代码中，执行完即完成配置或数据准备，不依赖任何库
  • 立即执行函数的返回值可以是任意类型，常见为对象接口或函数
  • 早期没有块级作用域时，IIFE 是隔离 var 变量的主要手段
  • ES6 之后，同类隔离需求优先用块级作用域或 ES Module 完成
  • 模块顶层变量属于模块作用域，不会挂到全局对象上，天然避免了全局命名空间污染
  • 全局对象传入参数后，内部可通过局部参数名稳定引用，避免依赖全局名
