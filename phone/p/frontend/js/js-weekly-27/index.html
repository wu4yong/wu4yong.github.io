Remix 3 进入 Beta — 不再是 React 框架

Remix 有相当丰富的背景故事。它于 2020 年由 React Router 背后的二人组创建，被视为 Next.js 的替代方案，于 2022 年被 Shopify 收购，其核心理念于 2024 年融入 React Router v7。现在，一个新的方向：一个全栈、Web 标准优先的框架，拥有自己的 UI 组件模型……而且不再依赖 React。

Michael Jackson (Remix)

Node.js 26.0.0 (Current) 发布

macOS 构建问题将发布日期推迟到了今天，但最新版本的 Node.js 终于到来，默认启用了 Temporal API，搭载 V8 14.6 和 Undici 8。v26 是”Current”前沿版本，将在 10 月份升级为 LTS。

Rafael Gonzaga

简讯

  • Vitest 与 Vite 紧密耦合，但其维护者提议将其变得”框架无关”，以支持其他构建工具和运行时。

  • Hacker News 上的用户非常兴奋地讨论 Bun 的 Jarred Sumner 将 Bun 从 Zig 移植到 Rust 的努力。 Jarred 在讨论串中现身安抚了情绪。Rust 移植确实在进行，但目前没有长期切换的意图。

  • Svelte 团队分享了最新的月度回顾，包括 Svelte 出现在 ThoughtWorks 最新的《技术雷达》中的消息。

  • Deno 正在获得实验性的 import defer 支持（TC39 提案），可能是首个支持该特性的运行时。

版本发布

  • PM2 7.0 – Node.js 进程管理器进行了重构，大幅削减了依赖数量，并将集群模式和监控代理扩展到 Bun 应用。

  • Astro v7 Alpha – 面向内容驱动网站的 Web 框架预览了其基于 Vite 8、Rust 编译器驱动的版本，同时发布了 v6.2。

一个基于 Schema 的无头表单库，适用于 Preact、Qwik、React、SolidJS、Svelte 和 Vue，使用 Valibot 管理表单状态和验证。在 Playground 中试用演示。

opentype.js: 读写 OpenType 字体

在浏览器和 Node.js 中直接访问字形。广泛支持 WOFF、OTF 和 TTF，支持连字、字距调整和表情符号。你还可以从零开始创建自己的字体。新版 v1.3.5 是即将发布的 2.0 的预览版。GitHub 仓库。

Frederik De Bleser

View Transitions Mock: 同文档视图过渡的非视觉 Polyfill

一个 JS 实现的同文档视图过渡，不含视觉效果。编写一个干净的代码路径：支持的浏览器获得过渡效果，不支持的获得即时 DOM 替换，但 Promise 行为保持一致。
