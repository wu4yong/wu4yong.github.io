JavaScript 变量

分类：frontend · js ｜ 标签：web

JavaScript

变量

  • JavaScript 中的变量是松散类型: 能保存任何类型的数据。
  • 可以在修改变量的值的同时修改变量的类型, 但是不推荐。
  • 申请多条变量，使用逗号隔开。 var a = 0, b = 0;

一、作用域

  1. Global 作用域(全局作用域、window)
  2. Local 作用域(函数作用域，局部作用域)
  3. Block 作用域(ES6 新增、块级作用域、let const使用、只有有 {} 就算是新的)
  4. Script 作用域(ES6 新增、全局的块级作用域、let const 使用)

二、var

2.1 声明作用域

  • 使用 var 声明的变量会成为包含它的函数的局部变量
  • 声明变量时省略 var 操作符，会创建一个全局的变量 !JS设计糟粕

2.2 声明提升

  • 使用 var 声明的变量会自动提升到函数作用域顶部
  • var a = 1; 只有 var a; 会提升 a = 1 不会提升，在声明前访问变量的值为 undefined

三、let

  1. 声明作用域: 只在命令所在的块级作用域有效
  2. 不存在变量提升: 在声明之前使用变量会报错。
  3. 暂时性死区: 只要块级作用域内有 let 和 const 命令，不会受到外部全局变量的影响。声明之前就使用会报错。
  4. 不允许重复说明: 不允许在相同的作用域内，重复声明同一个变量。

四、const

  1. const 声明一个只读的常量，值不能改变，一旦声明必须赋值。
  2. 声明作用域: 只在命令所在的块级作用域有效
  3. 没有变量提升，有暂时性死区。
  4. 不可重复声明

4.1 const 常量本质

  • 本质是 const 执行的内存地址不改变，简单类型的值就是常量，复合类型的值保证指针是不变的。
  • const 声明的对象可以添加属性。不可以重新赋值新的对象。实质是不改变地址。对象的属性添加不更改地址。
  • 想要实现整个对象冻结，可以使用 Object.freeze() 方法

4.2 const 的性能优点

  1. V8 引擎在编译 JS 为机器码的过程中，会将变量的值直接嵌入到机器码中，而不是在运行时计算
  2. 由于 const 的不可变性，更有利于 V8 的垃圾回收机制进行处理

五、顶层声明与全局对象的关系

  • var 在顶层声明的变量会成为全局对象的属性；let、const 在顶层声明只进入脚本作用域，不会挂到全局对象上
  • 同一脚本里用 let/const 重复声明同名变量是 SyntaxError，var 重复声明不报错
  • 函数参数名不能与函数体内 let/const 声明同名；catch 绑定名也不能与块内声明同名
  • switch 语句共用一个块，多个 case 内用 let/const 声明同名变量会冲突，需要用额外块语句包住每个 case
  • 块级作用域由 {} 界定：if、for、switch、try/catch 块和函数体都形成独立作用域

六、暂时性死区补充

  • let、const、class 从块开头到声明位置之间为暂时性死区，期间访问抛 ReferenceError
  • TDZ 取决于代码执行的时间点，而不是源码书写顺序；在死区外定义、之后才调用的函数可以正常闭包引用该变量
  • 对 TDZ 中的变量使用 typeof 也会抛 ReferenceError，这与未声明变量的 typeof 返回 “undefined” 不同
  • const 声明必须在声明时初始化；绑定本身不能重新赋值，但引用类型内部的属性可以增删改
  • const 复合类型保存的是指针，指针不变但指向的对象内容可变
  • Object.freeze 是浅冻结，内层对象的属性仍可修改；要整体不可变需要逐层冻结

声明方式对比

  • var 是函数作用域，存在声明提升，声明前访问为 undefined；可重复声明
  • let 是块级作用域，有暂时性死区，重复声明报 SyntaxError；适合会被重新赋值的变量
  • const 是块级作用域，同样有暂时性死区；声明时必须初始化，绑定不可重新赋值
  • 惯例上未被重新赋值的变量优先用 const，需要变化的用 let，避免再用 var

作用域常见问题

  • for 循环中用 var 声明的循环变量是函数级共享绑定，循环回调读到的是最后一轮值
  • 改用 let 后每次迭代形成独立绑定，回调各自闭包到当轮变量
  • 外层同名 var 变量在块内被 let/const 重新声明时，块内标识符整体指向新绑定，外层值在块内不可见
  • 全局环境中 var 声明挂到全局对象，let/const 只进入脚本作用域，两者同名在不同脚本重复声明时规则不同
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i));
}
// 0 1 2
