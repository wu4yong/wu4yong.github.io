TypeScript 7.1 Beta 发布

TypeScript 7 新增了编程式 API，以及“内容映射器”（content mappers）——一个用于检查 Vue、Svelte 和 Astro 等组件文件中嵌入代码的插件点。此外还新增了源阶段导入（source phase imports）和 --target es2026。

Daniel Rosenwasser（Microsoft）

Bramus 一直在用 JavaScript 和 WebGL 重新实现原版俯视角 GTA 的引擎，并从游戏最初的演示文件中加载自由城。在这里试玩。

Bramus Van Damme

💡 很巧的是，Pat Kerr 在 1996 年制作的 Atari ST 原型奠定了原版游戏车辆物理的基础，他最近也用 JavaScript 重建了它。

简讯

  • Deno 的 Bartek Iwańczuk 表示，团队正在推动 Deno 加入某个基金会。与此同时，一个新的分支 Ende 计划放弃 Node 兼容性，重新聚焦于沙箱化。

  • Safari 27.1 预览了 Device Posture 和 Viewport Segments API，这些功能以特性开关形式在 iPhone Duo 上提供，让 JavaScript 能够检测折叠并检查屏幕分段。

  • Chrome 156 已进入稳定版，不再缓存模块获取失败，因此因网络或 HTTP 错误而失败的动态 import() 可以重试。

版本发布

  • Node.js v26.12.1（Current）、v24.22.1（LTS） 和 v22.23.4 – 安全版本，修复十个 CVE，其中包括 “Node2Shell” Brotli 解码器漏洞，应用解压恶意数据时可能导致远程代码执行。（另外，Node 26 将于明天成为 LTS。）

  • Bun 1.4.4 – 新增 bun fmt，这是一个兼容 Prettier 的格式化工具，会使用你现有的 Prettier 或 oxfmt 配置。它非常快。

  • Electron 45 – 升级到 Chromium 156、Node 24.22 和 V8 15.6，并新增 Prompt API 的 Hook，让应用可以接入本地模型。

  • pnpm 12.16、Remix 3.1、axios 1.21、Deno 2.9.8

版本发布

  • ☕ CoffeeScript 2.7.1 – 四年半以来的首个版本，带来 Node 22+ 修复以及 with { type: 'json' } 导入属性。

    💡 如果你从未用过 CoffeeScript，它是一门（或曾经是一门）带有 Ruby 和 Python 风格、编译为 JavaScript 的语言。Brendan Eich 曾将其箭头函数和轻量类视为 ES6（ES2015）设计的范本。

  • oxlint 1.89 – 这个基于 Rust 的 linter 现在会把其 React、Vue、Next.js、Jest/Vitest 等插件的上游推荐规则计入“推荐”规则，因此升级后可能会看到更多报告。

  • Mutative 2.0 – Immer 风格的高效不可变更新库。作者称在一套基准测试中比 Immer 快 3.6 倍。

  • SonicJS 3.0 – 面向 Cloudflare Workers、基于 Hono 的无头 CMS。v3 重建了数据层、认证和插件系统。主页。

  • query-string 10.0 – 解析和序列化 URL 查询字符串。现在会对无法表示的值抛出错误。

  • ShareDB 7.0 – 基于操作变换的实时数据库后端。

📢 生态系统其他动态

  • 🔒 Node2Shell： ELLIO 现在报告称已出现实际的在野攻击流量，针对的是 Node 版本中修复的 Brotli RCE（如前所述）。该漏洞位于 Google 的 Brotli 库中，因此其他地方打包的副本也需要修补。

  • Sentry 今年已向开源维护者捐赠 100 万美元。JavaScript 领域的受赠者包括 pnpm、TanStack、MSW、Knip 和三位 Three.js 维护者，以及 OpenJS Foundation。

  • 🎉 CSS-Tricks 这个广受欢迎的 Web 开发资源重新独立，现在归其长期编辑 Geoff Graham 所有。

  • Arc 这款受开发者欢迎、设计导向的 Chromium 浏览器即将停止服务，The Browser Company 正引导所有人转向 Dia。

  • 📄 Google Docs 现在可以原生打开、编辑和协作处理 Markdown 文件，Drive 也会渲染它们的预览。
