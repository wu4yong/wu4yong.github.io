TanStack Hotkeys: 类型安全的跨平台快捷键库

TanStack 家族 迎来了新成员：Hotkeys，一个处于 alpha 阶段的通用键盘交互工具包。它处理跨环境的兼容性问题，支持多步骤序列（如 Vim 命令或秘籍指令），并且可以录制用户的快捷键。这里是完整的介绍。

TypeScript 6.0 Beta 发布

v6.0 在很大程度上是一个*”清理你的 tsconfig”*的版本，旨在为今年晚些时候推出的 Go 驱动的原生 TypeScript 7 搭建过渡桥梁。需要注意一些调整，比如 types 默认为 []，--strict 现在默认为 true，此外还有更多的破坏性变更和弃用。

🎨 DPaint.JS v0.2.0 发布

三年前我们曾介绍过 DPaint.JS，一个模仿传奇的 1980 年代 Amiga 和 PC 图形编辑器 Deluxe Paint 的 Web 图像编辑器。许多类似的业余项目最终会逐渐消失，但 DPaint 没有！经过两年的开发，v0.2.0 已发布，支持动画、手写笔、纹理画笔等功能。
