将 Bun 用 Rust 重写

Bun 的创建者分享了将 JS 运行时从 Zig 移植到 Rust 的完整故事，在此过程中动用了大量 Claude Code 实例，耗费了约 $165K 的 API 使用费（按 API 价格计算）。Rust 版本将构成 Bun 1.4 的基础，预计很快发布。
