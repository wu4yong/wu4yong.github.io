Remix 3 RC：无需 React 的全栈框架

Remix 从昔日的 React 框架彻底重写为独立的全栈框架，这项大工程已基本完成。这篇文章的推介已经不错，但全新的主页更胜一筹，它说明了 Remix 如何用“单个包”提供构建现代 Web 应用所需的一切。

Brooks Lybrand

💡 最终版本定于 10 月 2 日发布，但它现在已经完全可以上手使用。

pnpm 12：用 Rust 重写，命令与 lockfile 保持不变

Rust 重写版已稳定，v11 的几乎所有命令、标志和 lockfile 格式都得以沿用，只有少量改动。不过 npm 的 latest 标签仍指向 pnpm 11，因此你需要执行 pnpm self-update next-12 才能升级。

Zoltan Kochan

简讯

  • TypeScript 已支持能感知 import attribute 的环境模块（ambient modules）。像 declare module "*" with { type: "css" } 这样的声明，现在可以匹配带有该属性的 import。

  • Dani Sandoval 汇总了本月 Svelte 世界的新动态，包括 Svelte 5.57 新增的 SvelteMap 方法、SvelteKit 3 进入 RC，以及 sv CLI 的 ai-tools 附加组件。

  • Sarah Rainsberger 也汇总了本月 Astro 的新动态，包括 Matthew Phillips 接任“Project Steward”，以及全新的 Astro Playground。

版本发布

  • ⭐ Rspack 2.2、Rsbuild 2.2 和 Rslint 0.9 – 更快的构建与 HMR、更短的模块 ID，Rsbuild 默认开启 Node.js chunk 拆分。值得一提的是，Rslint 现已实现 @typescript-eslint 的全部规则和预设。

  • Cypress 16、NestJS 12、Vue 3.6 RC6、Deno 2.9.6、Mocha 12.0、Electron 44（上周提到过，但现在有了正式文章）。

  • Node.js v26.8.0 (Current) 和 Node.js v24.20.0 (LTS)

Zod 4.5：解析更快，每个 schema 的内存占用降低 9 倍

htmx 4.0：这个反 SPA 库两年来的首个大版本

这个仅凭属性就能把 HTML 片段换入页面的库，已从 XMLHttpRequest 迁移到 Fetch API。属性继承现在改为按需启用（opt-in），事件已被标准化/重命名，morphing swaps 与 <hx-partial> 是新特性。还有一份完整的 htmx 4 新特性指南。

Carson Gross
