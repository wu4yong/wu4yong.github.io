JavaScript

javascript的语法

一、javascript是区分大小写的语言

标识符

  • 标识符的命名规则：
  1. 变量只能以字母 _ $ 开头
  2. 变量内部可以使用数字
  3. 关键字，和保留字不能使用
  4. 按照惯例采用小驼峰(第一个字母小写，后面的开头大写)的格式
  • 其他的命名规则
  1. 事件类型全部小写
  2. 构造函数首字母要大写
  3. 非构造函数以小写字母开头

二、严格模式

  • 严格模式是一种不同的 JavaScript 解析和执行模型，ECMA3 的一些不规范写法会在这种模式下被处理

三、执行代码时遇到错误

  1. (低级错误)语法错误代码一行也不会执行
  2. 逻辑错误(标准错误)后续代码不会执行
  • 无论哪种错误都不会影响到其他代码块的执行

四、标识符规则补充

  • 标识符以字母、下划线 _ 或美元符号 $ 开头，首字符之后可以包含数字
  • 除 ASCII 外，标识符也允许使用 Unicode 代码点；数字不能作为标识符首字符
  • 关键字和保留字不能作为变量名、函数名；保留字在对象属性名、私有属性名中不受此限
  • 标识符按字符串值比较，Unicode 转义序列会被解释成实际字符

五、注释与分号

  • 单行注释用 //，其后直到行尾都是注释；块注释用 /* */，可以跨多行
  • 块注释可以屏蔽一段代码不执行，但不能嵌套
  • 语句之间用分号分隔；行终止符附近符合规则时引擎会自动补全分号（ASI）
  • 后置 ++/–、continue、break、return、yield 等语句后紧跟行终止符时，不会自动补全到下一行，换行可能被切断
  • JavaScript 区分大小写，变量名、函数名、关键字的大小写不同就是不同的名字
// 单行注释
/* 这是
   多行注释 */
const userName = "foo";

六、代码错误的两类表现

  • 语法错误在解析阶段出现，整段脚本不会执行
  • 运行时错误在执行到对应语句时抛出，出错点之后的代码不再执行
  • 不同脚本块之间互不影响，一个脚本块出错不会阻止其他脚本块运行

字面量与分隔符

  • 数值字面量支持十进制、十六进制（0x）、二进制（0b）、八进制（0o）和数字分隔符（下划线）
  • 字符串可用单引号、双引号或模板字面量（反引号）书写，模板字面量支持插值和换行
  • 标识符中允许 Unicode 字符，中文等字符可以作为合法标识符
  • 一行内多个变量声明用逗号分隔，逗号在这里是声明分隔符，不是逗号运算符
  • 保留字不能作为声明标识符，但可以作为对象字面量的属性名

大小写与命名惯例

  • JavaScript 对大小写敏感，myVar 与 myvar 是两个不同的名字
  • 变量和函数名惯例用小驼峰，构造函数惯例首字母大写
  • 事件类型名、HTML 属性名在 DOM 接口中通常全小写，与 JavaScript 侧的命名区分开

错误处理的边界

  • 解析阶段的语法错误会阻止整段脚本执行，后续语句一条都不会运行
  • 运行时错误抛出后，当前执行流中断，错误点之后的同一段代码不再执行
  • 不同 script 块相互独立，一个块的错误不会阻止其他块运行
  • 未捕获的异步错误由对应异步机制处理，外层同步代码无法用 try…catch 拦截
const camelCase = 1;
const SCREAMING_CASE = "ok";
const 中文变量 = "合法标识符";
