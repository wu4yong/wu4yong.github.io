Deno 将加入 Cloudflare（但是……）

也许 David Bushell 早就看出了不祥之兆：Deno 团队加入 Cloudflare 并不是为了继续开发 Deno，而是要把 celld 并入 workerd，从而让 Durable Objects 可以自托管（更多内容见此）。Deno 运行时还将获得最后一年的官方修复支持，Deno Deploy 将在六个月后关闭，而 JSR 将迁移到 Cloudflare 的基础设施。

Ryan Dahl

💡 在 Hacker News 上，Ryan Dahl 指出 Deno “已被卷入 Node 兼容性的引力井”，并反问道：“为什么要重新实现 Node？它本来就能用。” 不过我不禁想问，JavaScript™ 商标案又会怎样呢……？

CodeAF：DeepSWE 十大编程 Harness 中的第一名

十个编程 harness 用同一个开放模型处理了 113 个真实的 GitHub issue。CodeAF 解决的问题最多，每个已解决 issue 的花费却最低：比 Claude Code 低 3.4 倍，比 OpenCode 低 4.8 倍。一个为开放模型打造的全新开源编程 harness。

Bun 1.4.3 新增 bun check：内置的 TypeScript 类型检查器

bun check 是 TypeScript 7 检查器的移植版，它会读取你的 tsconfig.json，报告与 tsc 相同的错误，而且据 Jarred 称运行速度快 3-6 倍。它还能接入 bun run/test/build。空闲的服务器进程现在占用的 CPU 大幅减少，JavaScriptCore 的升级也带来了大量性能提升。

Jarred Sumner
