tinyjs：用不到 10MB 构建 JavaScript 桌面应用

我用它构建了一个应用，印象深刻。你能得到一个由 txiki.js 驱动的后端，拥有完整的系统访问能力（包括 FFI！）、原生 webview 渲染，以及小巧的 macOS、Linux 和 Windows 构建产物。它甚至让最终应用的签名与公证变得很简单。

Tarwin Stroh-Spijer

不过这个领域还有很多出色的选择：

  • Electrobun 提供更丰富的多窗口和 GPU 功能，代价是更大的 TypeScript 运行时——不过它也可以改用 Zig、Rust、Go 或 Odin 来编写体积小巧的原生主进程。
  • Perry 是一个 TypeScript 到原生 AOT 编译器，其主要 UI 模型渲染 AppKit、Win32 和 GTK4 控件，带来更传统的原生观感。
  • Electron 和实验性的 Deno Desktop 功能强大，但它们的可执行文件通常要大好几倍。
  • Neutralinojs 应用甚至可以比 tinyjs 的更小，但按设计你会失去通用的 JavaScript 特权后端。

Linear 如何重构 CI，让测试量提升 4 倍

激进的智能体让 Linear 的测试套件不断膨胀，CI 成本也随之上升！他们分享了一些补救措施：把类型感知的 ESLint 规则改写为纯 AST 检查，让 lint 时间缩短了 55%，也让迁移到 Oxlint 更容易；而选择性地关闭 Vitest 的隔离机制，每月又节省了 17%。
