Temporal：修复 JavaScript 时间处理的九年征程

JavaScript 的日期/时间处理是出了名的混乱，诸如 Moment.js 之类的库作为变通方案广受欢迎。2017 年，Moment.js 的维护者 Maggie Johnson-Pint 提出了 Temporal API 来一劳永逸地修复日期/时间处理，如今我们已经基本到达终点（浏览器支持正在增长，Safari 和 Node 也将跟上）。

Jason Williams (Bloomberg)

Vite 8.0 发布

这个流行的构建工具迎来了一个重磅版本。设计为平滑升级，背后有许多重大变化：@vitejs/plugin-react v6 不再需要 Babel，Rolldown 取代了 Rollup 和 esbuild，支持 Wasm SSR，浏览器控制台转发到终端，以及巨大的性能提升。
