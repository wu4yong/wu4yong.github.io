RFC：是时候让 npm 的 Install Scripts 变为可选加入了

npm 是唯一一个默认运行依赖安装脚本（如 postinstall）的主流包管理器，而这已经成为了太大的安全弱点，GitHub（npm 的维护者）的 Jamie 如是说。此 RFC 进一步讨论了这一想法及其涉及的各种权衡。

Jamie Magee

Depot 如何在 AWS Lambda 上构建 CI 编排器

长时间运行的 CI 编排无需长驻服务器。Depot 使用 AWS Lambda 持久函数重建了他们的 CI 引擎——有状态、回调驱动且可崩溃恢复。深入探讨了驱动 Depot CI 的 run-workflow-job 层级结构。

Depot 赞助

简讯

  • 😱 Dr. Axel Rauschmayer（JavaScript 传奇人物、前 JS Weekly 编辑）将他的博客和 JavaScript 书籍从 Web 上撤下，原因是被 AI 爬虫搞得不堪重负。不过，你仍然可以在这里购买他出色的书籍。

  • Bun 的传奇继续。尽管曾淡化其重要性，基于 Rust 的 Bun 重写已被合并，但对 AI 移植代码质量的质疑也随之而来。Hacker News 上引发了大量讨论。

  • Deno 团队正在预告 Deno 2.8，预计本周发布。显著的 Node.js 兼容性改进、import defer 和 TypeScript 6.0.3 支持即将到来。

  • Chrome 和 Edge 团队正在开发一个新的 <install> HTML 元素，让浏览器能够为 PWA 渲染”受信任的安装按钮”。

  • Express.js 项目换上了全新的外观，包括新网站、新 Logo 和改进的文档。

版本发布

  • Angular 22 发布候选版 – 正式版预计 6 月初发布。值得期待的有基于 Signal 的表单和 OnPush 变更检测策略成为默认。

  • Bun 1.3.14 – 这个替代性 JS 运行时获得了 Bun.Image、更多 HTTP/2 和 HTTP/3 支持，以及更多 Node 兼容性改进。

  • ESLint Config Inspector 3.0 – 一个用于检查和理解你的 ESLint 扁平配置的可视化工具。

  • TypeORM 1.0、ESLint 10.4.0、Relay 21.0、Rolldown 1.0.1
