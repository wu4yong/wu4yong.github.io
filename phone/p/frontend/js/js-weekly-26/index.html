JavaScript Weekly Issue 783: 2026年4月28日

pnpm 11.0 发布

你已经听过它的好处，现在这个流行的包管理工具变得更好了。v11 默认将 minimumReleaseAge 设置为一天，采用 SQLite 支持的存储索引（安装更快！），原生包发布功能，pack-app 等。有面向 v10 用户的迁移指南。同时，名为 Pacquet 的 Rust 移植版项目也已恢复开发。

Zoltan Kochan

还在手动编写测试？Meticulous AI 来了

Notion、Dropbox、Wiz 和 LaunchDarkly 现在使用着一种他们离不开的测试范式。Meticulous 由前 Palantir 工程师构建，能够自动创建持续演进的 E2E UI 测试套件，以零开发者投入提供详尽覆盖率。

Meticulous 赞助

TypeScript 7.0 Beta：10 倍速 TypeScript 编译

Go 驱动的移植版，编译器性能*”约快 10 倍”。TypeScript 6.0 的弃用项和配置变更将帮助你从 v5 平滑升级到 v7。还需要审阅代码编写方式的变化。虽然 v7 被认为“接近生产就绪”*，但稳定的程序化 API 要到 v7.1 才会到来。

Microsoft

Nano Stores 1.3: 一个极小的（286 字节）状态管理器

适用于所有主要框架（包括 React）和原生 JS 的原子存储和派生存储。如果你对极小体积和框架无关的设计感兴趣，值得一看。

🍋 Fresh 2.3: 默认零 JS、视图过渡等

Deno 全栈 Web 框架（这里有介绍）新增了一等 WebSocket 支持，不再为不需要 JS 的页面传输任何 JavaScript，以及通过在视图中使用单个属性即可轻松使用 View Transitions API。

Bartek Iwańczuk (Deno)

📢 生态系统其他动态

🎵 Chip Player JS：在线复古游戏音乐播放器

一个基于 JavaScript 的在线播放器和仓库，收藏了超过 300,000 个 MIDI、Tracker、Chiptune 和视频游戏音乐文件。作为背景音乐非常棒，如果你能想起一款游戏，它很可能就在这里。《时空之轮》的配乐是我的最爱之一。

📊 Datatype: 将文本转为内联图表的字体

Datatype 是一种 OpenType 可变字体，可以将简单的文本表达式渲染为内联图表，无需 JavaScript 或图片。例如输入 {l:10,50,30,80,20} 就会被渲染为内联迷你走势图。
