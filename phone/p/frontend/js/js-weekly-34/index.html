使用 Deno Desktop 构建桌面应用

Deno 2.9（或现在的 ‘canary’ 构建版）可以将 JavaScript 项目转换为 macOS、Windows 和 Linux 上的自包含应用。与 Electron 不同，你可以选择使用操作系统默认的 WebView 或捆绑的 Chromium 后端，此外还支持交叉编译，并自动支持基于 Next.js 和 SvelteKit 等框架构建的应用。

Babel 8.0 发布：JavaScript 转译器

距离 Babel 7.0 已经过去了八年，尽管 SWC 和 Oxc 等工具崛起，@babel 包的每周下载量自那时起增长了 380 倍。v8.0 是一个现代化版本，仅支持 ESM，默认编译目标为 ~ES2023（而非之前的 ES5）。

Prop For That: JS 知道的，现在 CSS 也能访问
