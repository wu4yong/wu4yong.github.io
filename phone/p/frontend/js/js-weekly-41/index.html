将大型 Flow Monorepo 迁移到 TypeScript

在数年时间里，Yelp 将 140 万行代码从 Flow 迁移出去。这篇总结与其说是 Flow 的故事，不如说是一份适用于任何长期迁移的指南。就其本身而言，这是一次巨大的胜利，类型覆盖率从 83% 提升到了 96%。

Shawn Walton (Yelp)

Render 从前端到后端运行 JavaScript

关联你的仓库，Render 会接手后续工作。将你的 Vite 站点、Hono API、BullMQ 任务和分布式智能体工作流全部连接在同一个平台上。通过官方 Render /plugins 接入 Codex 和 Claude Code 中的智能体。免费开始，并按需扩展。

Render 赞助

Kitesurf：Cloudflare 面向智能体、运行于 V8 Isolate 的浏览器

一个运行在 Workers 上的浏览器引擎，每个页面一个 isolate。它面向智能体而非人类，CPU 和内存占用比 Chromium 少 3-7 倍，代价是速度较慢。你现在就可以在测试版中试用，它将在适当时候开源。

Martinho、Constant、Figueira 和 Duarte (Cloudflare)

来自 Deno 的、自托管的 Cloudflare Workers 和 Durable Objects 方案。V8 加 SQLite，以及 Litestream 的 LTX，通过 S3 存储桶协调，无需共识层。GitHub 仓库。

那个慢标签页不是 UI 的问题，而是查询

TimescaleDB 扩展了 Postgres，让查询在数据持续增长时依然快速，直接查询实时数据。获取 $1000 额度开始使用。

Tiger Data（TimescaleDB 创建者）赞助

hucre 1.0：零依赖的电子表格引擎

一个 MIT 许可、可 tree-shake 的引擎，用于读写常见的电子表格格式，支持嵌入图片、超链接、密码保护和数据透视表等功能。

Wind

vlt 1.0：支持类 CSS 选择器的 npm 替代品

一个可直接替换 npm 的替代品，主要亮点是 vlt query，它允许你在依赖图上使用 60 多个类 CSS 选择器（其中一半与安全相关）。vlt 还提供托管的私有包注册表。

Darcy Clarke

TanStack Table v9：更快、更模块化的基础

这个无头表格库获得了可 tree-shake 的架构，状态管理迁移到 TanStack Store 以实现细粒度响应式，并且针对大型数据集取得了显著的内存优化。

Kevin Van Cott
