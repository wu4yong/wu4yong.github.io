TanStack npm 入侵事件剖析

一种新的 Shai-Hulud 蠕虫变种昨天向 npm 推送了 TanStack 包的恶意版本（包含一个触发开关，一旦检测到令牌撤销就会删除文件），同时还波及了约 170 个其他包。维护者的凭证并未被盗取，攻击手段是通过链式利用 pull_request_target 滥用、缓存投毒和从 CI 内存中窃取 OIDC 令牌来完成的。

Tanner Linsley

❓ 你应该怎么做？ 考虑设置安装冷却期（例如通过 npm config set min-release-age=7 或 pnpm 的 minimumReleaseAge），因为这些包仅被入侵了 26 分钟。此外，使用 zizmor 等工具审计你的 GitHub Actions 工作流的安全问题。
