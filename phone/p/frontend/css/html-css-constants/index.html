HTML 与 CSS CSS 自定义属性

分类：frontend · css ｜ 标签：web

HTML+CSS

css的常量

定义形式

/* 原来一直以为常量只能定义在在:root上,其实不是的，可以定义在任何的元素上。并且有作用域,通常定义在:root上因为他是根元素 */
:root {
    <!-- 定义常量的时候必须要以--符号开头 -->
    --normal-height: 20px;
    --normal-height: 20px;
    --normal-color: red;
}

div {
    /* 使用常量的时候需要使用var字符来引用 */
    height: var(--normal-height);
    color: var(--normal-color);
}

:root 和 html 标签

  • css 的设计并不只是为了应用在 html 上
  • :root 在 css 中的意思是根元素。在 html 文档中代表的就是 html 标签。但是在其他文档中就不一定了。

在 css 中改变常量

  • 因为常量不只是定义在 :root 伪元素,也可以定义在文档中的其他子节点中。
  • 所以常量也和其他的 css 属性一样，具有层叠性和继承性。
  • 可以实现局部的变量的更改。(其中 animate.css 中就需要使用到这个特性)

自定义属性的作用域与继承

  • 自定义属性以两个连字符 -- 开头，可以声明在文档中的任意元素上，不只能写在 :root 上
  • 自定义属性是可继承的：子元素默认继承父元素声明的变量值，在子元素上重新声明会覆盖继承来的值
  • 自定义属性同样参与层叠，同一元素上多次声明时按普通 CSS 的层叠规则取值
  • 利用继承和层叠，可以在局部节点上覆盖变量，让同一套组件样式在不同区域呈现不同配色或尺寸
  • 自定义属性名区分大小写，--normal-color 和 --Normal-color 会被视为两个不同的属性
  • 子元素读取的是父元素计算后的变量值，而不是源码里的字面量

var() 与兜底值

  • 引用变量使用 var() 函数，第一个参数是自定义属性名，第二个可选参数是兜底值
.box {
  color: var(--normal-color, red);
}
  • 当引用的变量未定义或无效时，var() 使用第二个兜底值；兜底值本身也可以是另一个 var() 调用，形成链式回退
  • 第一个逗号之后到函数结尾前的内容都会被当作兜底值，因此兜底值里可以出现逗号
  • 引用未定义变量时应提供兜底值，否则该声明可能不生效
  • 自定义属性的值在计算时被替换进声明，var() 不能作为属性名、选择器或其他非属性值位置使用

变量值的替换时机与限制

  • 变量不能用来拼接属性名、类名或媒体查询条件，只能出现在属性值位置
  • 同一元素上变量被多次声明时，按层叠规则取最终值；子元素未覆盖时继承父元素的取值
  • 颜色、尺寸、间距、圆角等可复用的设计令牌适合抽成变量，配合局部覆盖实现主题切换
  • 变量命名应表达用途或角色，而不是直接写死视觉数值，便于后续调整
  • 自定义属性是运行期的层叠变量，跟随 DOM 继承和局部覆盖，切换主题时浏览器可以重新计算相关样式

与预处理器变量的区别

  • Sass 等预处理器变量在编译期被替换成固定值，输出的 CSS 里不再保留变量名
  • CSS 自定义属性不需要预处理器参与构建，样式表内即可引用和回退
  • 预处理器变量不存在 DOM 继承关系，父级变量不会自动传到子级选择器
  • 需要在运行时按节点覆盖、切换主题的场景，使用 CSS 自定义属性更直接

使用变量时的注意事项

  • 变量值可以是颜色、长度、百分比、角度、字符串等任意合法声明值
  • 同一个变量在不同组件上被引用时，取值跟随各自节点继承到的计算值
  • 仅使用一次的硬编码数值不必强行抽成变量，变量服务于可复用和可切换的设计令牌
  • 浏览器开发者工具可以在元素样式面板上查看继承到的变量取值
  • 局部覆盖变量时，覆盖规则写在对应选择器上，不需要为子组件复制整套样式
  • 变量命名表达用途或角色即可，避免在名字里写死具体视觉数值
  • 自定义属性的层叠和覆盖规则与普通 CSS 属性一致，不存在单独的变量优先级
  • 变量在 :root 上声明时，取值对整棵文档树可见，子节点未覆盖时都继承这份值
  • 组件内部专用的变量可以直接声明在组件选择器上，避免污染全局命名空间
  • 变量值在声明的节点上生效，子节点继承到的是计算后的值，修改父级变量会同步影响未覆盖的子节点
  • 不支持 CSS 自定义属性的旧浏览器需要配合后备声明，先写固定取值再写 var() 引用
