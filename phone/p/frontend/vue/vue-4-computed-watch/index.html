Vue 计算属性与 watch

分类：frontend · vue ｜ 标签：vue

计算属性 && watch

一、computed

  • 减少模板中表达式的使用
  • 当计算属性在模板中使用，并且计算属性的依赖值发生改变的时候就会触发它的更改。如果不发生变化，使用的就是缓存的属性值
  • computed 中使用 dirty 来标识是否需要重新计算，computed 中使用 value 变量缓存上一次计算结果的值，如果连续调用同一个计算属性会返回缓存的值
  • 计算属性中的 getter 函数要求是没有副作用的

1.1 计算属性 VS 方法

  • 计算属性是基于它们的响应式依赖进行缓存的。只在相关响应式依赖发生改变时它们才会重新求值。多次访问计算属性会立即返回之前的计算结果，而不必再次执行函数。
  • 相比之下，每当触发重新渲染时，调用方法将总会再次执行函数。

二、watch 侦听器

  • 适合在调试的时候使用
  • watch 是在属性有改变的时候调用对应的方法
// 想要监听一个对象的深层变化时，需要加上 deep 关键字
watch: {
  // 监听的变量只接受以 . 为分隔的路径(obj.person.name)
  combo: {
    handler: function() {
      ......
    },
    // 想要监听对象内部值的变化，需要指定 deep 为 true(值得注意的是，监听数组的变化不需要这样做)
    deep: true
  }
}

1.2 侦听器VS计算属性

  • 计算属性是依赖的属性发生变化时，计算属性跟着变化，并且主要得到的是一个属性。
  • 侦听器不是为了得到一个属性，而是期望在某些属性变化的时候能触发一些函数或者语句

计算属性的缓存语义

  • 计算属性基于响应式依赖缓存，只有相关依赖更新时才重新求值；多次访问直接返回之前的计算结果
  • 方法调用在每次重渲染时总会再次执行函数，不会走缓存
  • Date.now() 这类不是响应式依赖，对应的计算属性不会随之更新
  • 计算属性的 getter 应只做计算，不改变其他状态、不发异步请求、不更改 DOM

可写计算属性

  • 计算属性默认只读，直接修改会收到运行时警告
  • 同时提供 getter 和 setter 可以创建可写计算属性：get 返回派生值，set 接收新值并更新源状态
  • 组合式 API 中 computed() 接收 getter 函数，返回一个计算属性 ref，通过 .value 访问结果，模板中自动解包
  • 计算属性返回的是派生状态的快照，源状态变化时会生成新快照；不应直接修改计算属性返回的值

watch 的深度与立即执行

  • watch 默认是浅层监听，被侦听的属性只有被赋新值时才触发回调；监听嵌套对象内部变化需要显式设置 deep: true
  • 直接把一个响应式对象传给 watch() 会隐式创建深层侦听器，所有嵌套变更都会触发回调；此时回调里的新值和旧值是同一个对象
  • watch 默认懒执行，只有数据源变化时才跑回调；设置 immediate: true 会在创建侦听器时立即执行一遍回调
  • 深度侦听需要遍历对象的全部嵌套属性，用于大型数据结构时开销较大，只在必要时开启
import { ref, watch } from 'vue';

const question = ref('');

watch(question, (newQuestion, oldQuestion) => {
  console.log(newQuestion, oldQuestion);
});

侦听器的回调参数与数据源

  • 回调函数接收新值和旧值两个参数
  • 不能直接侦听响应式对象的某个属性值，需要传一个返回该属性的 getter 函数
  • 设置 once: true 后，侦听器回调只在数据源变化时执行一次
  • 组合式 API 中 watch 的第一个参数可以是 ref、计算属性、响应式对象、getter 函数，或多个数据源组成的数组
  • 回调初次执行发生在组件 created 钩子之前，此时 data、computed、methods 已经可用
  • 异步回调里创建的侦听器不会自动绑定到宿主组件，需要手动调用取消函数停止

watch 与 watchEffect

  • watch 只追踪明确指定的数据源，回调里访问到的其他响应式属性不会被追踪，触发时机更可控
  • watchEffect 会在副作用执行期间自动追踪所有访问到的响应式属性，写法更简洁，但依赖关系不如 watch 明确
  • setup 或 <script setup> 中用同步语句创建的侦听器会自动绑定到宿主组件实例，组件卸载时自动停止；需要提前停止时，调用 watch 或 watchEffect 返回的取消函数即可
  • 默认情况下侦听器回调在父组件更新之后、所属组件 DOM 更新之前调用；需要访问更新后的 DOM 时可以指定后置刷新，简单布尔值场景也可以用同步侦听器
  • 同步侦听器不做批处理，数据源频繁变化时会反复触发
