计算机网络 数据链路层

分类：frontend · network ｜ 标签：web

计算机网络

数据链路层

  • 链路 就是从一个结点到相邻结点的一段物理线路，中间没有任何交换结点(没有路由器)
  • 数据链路 是指把实现通信协议的硬件和软件加到链路上，构成了数据链路
  • 数据链路层是以 帧 为单位处理和传输数据

封装成帧

  • 数据链路层将从网络层来的协议数据单元添加帧头帧尾的过程叫封装成帧

  • 帧头和帧尾中含有重要的控制信息

  • 帧头和帧尾的作用之一是帧定界

  • 透明传输 指的是数据链路层对于上层交付的传输数据没有任何限制

  • 如何恰好数据中含有帧中的定界符的话，需要把数据中和定界符相同的字节加上转义符号。(这一步检查发生在数据链路层中)

  • 为了提高帧的传输效率，帧的数据部分应当尽可能大一点，但是每一层数据链路层又规定了帧中数据部分的长度上限。

差错检测

  • 接收方根据帧尾中的检测码来检查是否传送过程中出现了误码
  • 奇偶校验法(误差较大) 循环冗余校验CRC检测法(误差率较低)

可靠传输

  • 接收方不会接收有误码的数据帧

数据链路层向上层提供的服务类型

  • 不可靠传输服务 仅仅丢弃有误码的帧
  • 可靠传输服务 想办法实现发送端发送什么，接收端就收到什么。

传输错误类型

  • 比特差错
  • 分组丢失
  • 分组失序
  • 分组重复

可靠传输服务

  • 可靠传输服务的实现不仅仅局限于数据链路层，可以应用到计算机网络体系结构的各层协议中。

  • 停止等待协议(发送方每发送一个分组，就要等到接收方发送确认接收分组) 缺点是信道利用率十分底下

  • 回退N帧协议(发送方可以一次性的发送多个分组(窗口大于1)，接收方按序接收分组(接收方窗口等于1)，当发现误码时，丢弃差错误码后的所有分组，并发送接受错误的信息，要求发送方重传N个分组)(当通信线路质量不好时，效率低下)

  • 选择重传协议 在回退N帧协议的基础上接收方的窗口不在等于一，而是和发送方的窗口大小相同。这种实现只需要重传出现误码的分组。而不需要重传N个分组。

点对点协议PPP

  • 定义封装成帧的封装方法 链路控制协议 网络控制协议

以太网帧的基本格式

  • 以太网帧由目的 MAC 地址、源 MAC 地址、长度/类型字段、数据部分和帧校验序列（FCS）组成
  • 目的地址和源地址各 6 个字节，目的地址可以是单播、广播或组播地址
  • 长度/类型字段为 2 个字节：取值不超过 1500 时表示数据长度，取值不小于 1536 时表示封装的上层协议类型（EtherType）
  • 数据部分即上层交下来的 IP 数据报等内容，长度有上下限；不足下限的部分用填充补齐
  • FCS 为 4 个字节，使用 32 位 CRC 校验，覆盖目的地址、源地址、长度/类型和数据部分；接收方重新计算校验值，不一致就丢弃该帧
  • 帧前面的前导码和帧起始分隔符用于让接收方锁定数据流、完成时钟同步，通常不在软件可见的帧内容中出现

以太网的介质访问控制

  • 传统共享式以太网使用 CSMA/CD（载波监听多点接入/碰撞检测）：发送前先监听信道，信道空闲才发送，发送过程中持续检测碰撞，检测到碰撞后停止发送并执行退避
  • 交换式以太网中，交换机根据 MAC 地址表在端口之间转发帧，全双工链路下不再需要碰撞检测
  • 网桥和交换机工作在数据链路层，依据 MAC 地址在链路段之间转发帧，把各端口所在的链路段隔离开

点对点协议 PPP

  • PPP 用于点对点链路（如拨号、专线）上封装网络层协议数据，由链路控制协议（LCP）建立、配置和终止链路，由网络控制协议（NCP）协商网络层配置
  • LCP 报文封装在 PPP 信息字段中，PPP 协议字段标识类型；LCP 报文分为链路配置、链路终止和链路维护三类
  • LCP 配置报文包括 Configure-Request、Configure-Ack、Configure-Nak、Configure-Reject；终止报文包括 Terminate-Request 和 Terminate-Ack；维护报文用于管理和调试链路
  • 与以太网帧不同，PPP 链路只连接两个端点，不存在多个站点竞争同一媒体的问题
  • PPP 帧通过标志字段定界，包含协议字段和信息字段，FCS 做差错校验

帧定界与透明传输

  • 封装成帧时在网络层协议数据单元前后加上帧头帧尾，帧头帧尾中的控制信息用于帧定界，让接收方从比特流中识别出一帧的起止
  • 透明传输指数据链路层对上层交付的数据内容不加限制；数据中出现与定界符相同的字节时，需要加上转义符号处理
  • 帧的数据部分有长度上限，由各链路层协议规定；数据部分过短时用填充补齐到下限
  • 奇偶校验法的差错检出能力有限，循环冗余校验（CRC）的误差率较低；FCS 就是基于 CRC 计算的检测码

可靠传输协议的回顾

  • 停止等待协议每发送一个分组就等待接收方确认，信道利用率低
  • 回退 N 帧协议允许连续发送多个分组，接收方按序接收；发现误码时丢弃出错分组及其后的分组，要求发送方重传这一段
  • 选择重传协议只重传出现误码的分组，不需要重传其后的全部分组
  • 可靠传输服务的实现不限于数据链路层，同样的确认、重传机制可以应用在体系结构的各层协议中
