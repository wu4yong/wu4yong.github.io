MongoDB 与 Elasticsearch 的数据访问

同一套 Spring Data 抽象，换成文档库就是 MongoRepository + MongoTemplate，换成搜索引擎就是 ElasticsearchRepository + NativeSearchQuery。这一篇讲两者各自的写法与选型边界。

文档、倒排索引与检索结果三段式

1.1 MongoDB 接入

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-mongodb</artifactId>
</dependency>
spring:
  data:
    mongodb:
      uri: mongodb://127.0.0.1:27017/demo
@Document(collection = "orders")
@CompoundIndex(name = "idx_user_status", def = "{'userId': 1, 'status': 1}")
public class OrderDoc {
    @Id
    private String id;
    @Indexed
    private Long userId;
    private String status;
    private List<OrderItem> items;
    private LocalDateTime createdAt;
}
public interface OrderDocRepository extends MongoRepository<OrderDoc, String> {
    List<OrderDoc> findByUserIdOrderByCreatedAtDesc(Long userId);
    long countByStatus(String status);
}
注解
作用
@Document
指定集合名
@Id
主键（默认 ObjectId 字符串）
@Indexed
单字段索引
@CompoundIndex
联合索引，顺序很关键
@Field
字段改名，兼容历史文档

1.2 MongoTemplate：复杂查询

Criteria criteria = Criteria.where("userId").is(userId)
        .and("createdAt").gte(start).lt(end)
        .and("status").in("PAID", "SHIPPED");

Query query = Query.query(criteria)
        .with(Sort.by(Sort.Direction.DESC, "createdAt"))
        .limit(20);

List<OrderDoc> list = mongoTemplate.find(query, OrderDoc.class);

1.3 Elasticsearch 接入

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-elasticsearch</artifactId>
</dependency>
spring:
  elasticsearch:
    rest:
      uris: http://127.0.0.1:9200
@Document(indexName = "item")
public class ItemDoc {
    @Id
    private Long id;
    @Field(type = FieldType.Text, analyzer = "ik_max_word")
    private String name;
    @Field(type = FieldType.Keyword)
    private String category;
    @Field(type = FieldType.Double)
    private BigDecimal price;
}
public interface ItemDocRepository extends ElasticsearchRepository<ItemDoc, Long> {
    List<ItemDoc> findByName(String name);
}
类型
用途
注意
Text
全文检索
需分词器（中文用 ik）
Keyword
精确匹配/聚合
不分词
Double/Long/Date
数值与时间
聚合时用 keyword 或数值类型
Nested
数组内对象独立检索
查询语法不同

中文不分词是”搜不到”的第一原因：Text 不加 ik_max_word 时，中文会被按单字切分。

1.4 复杂检索

NativeSearchQuery query = new NativeSearchQueryBuilder()
        .withQuery(QueryBuilders.boolQuery()
                .must(QueryBuilders.matchQuery("name", keyword))
                .filter(QueryBuilders.termQuery("category", category)))
        .withPageable(PageRequest.of(0, 10))
        .withSort(SortBuilders.fieldSort("price").order(SortOrder.ASC))
        .build();

Page<ItemDoc> page = itemDocRepository.search(query);
子句

能用 filter 就别用 must：不打分、可缓存、更快。

1.8 清单

  1. 简单查询用 MongoRepository，动态与聚合用 MongoTemplate
  2. 联合索引的字段顺序按查询顺序写，否则不生效
  3. ES 的 Text 必须配分词器，中文要 ik，否则等于按字切
  4. 过滤条件用 filter 不用 must，不打分还能缓存
  5. 索引与主库同步走 MQ 或 binlog，别裸双写
  6. MongoDB 不适合强事务的核心交易场景
  7. 三种存储各司其职，别指望一个库解决所有问题
