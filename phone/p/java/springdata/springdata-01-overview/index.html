Spring Data（一）Repository 抽象与体系全景

分类：java · springdata ｜ 标签：SpringData

Spring Data 的抽象：一套接口，多种存储

MySQL 用 JPA、缓存用 Redis、文档用 MongoDB、搜索用 Elasticsearch——四种存储、四套 SDK，写法完全不同。Spring Data 把它们统一成同一套 Repository 抽象：继承一个接口，方法名起对，CRUD 和分页排序自动就有了。

一套抽象接口向下适配多种存储形态

关键点：Repository 接口没有实现类。Spring Data 在启动时扫描接口，用 SimpleJpaRepository 之类的通用实现 + 方法名解析器，生成代理 Bean 注册进容器。

1.3 起步示例

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
</dependency>
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/demo?serverTimezone=Asia/Shanghai
    username: root
    password: root
  jpa:
    hibernate:
      ddl-auto: update        # 开发期用，生产改 none + 手工脚本
    show-sql: true
    properties:
      hibernate:
        format_sql: true
public interface UserRepository extends JpaRepository<User, Long> {
    User findByUsername(String username);
    List<User> findByAgeGreaterThan(Integer age);
    Page<User> findByStatus(String status, Pageable pageable);
}

三个方法名，三份查询，一行 SQL 都不用写。

1.5 分页与排序

PageRequest pageRequest = PageRequest.of(0, 10, Sort.by(Sort.Direction.DESC, "createdAt"));
Page<User> page = userRepository.findByStatus("ACTIVE", pageRequest);

page.getTotalElements();     // 总数
page.getTotalPages();        // 总页数
page.getContent();           // 当前页数据
返回类型
内容
适用
List<T>

Page 每次都会额外发一条 count 查询；无限滚动的列表用 Slice 能省一半开销。

1.6 启动时的几个固定坑

  1. Repository 接口必须放在 @SpringBootApplication 的扫描包下，否则报 NoSuchBeanDefinitionException
  2. @EnableJpaRepositories(basePackages=...) 与 @EntityScan 同时配时容易漏掉实体包
  3. ddl-auto: update 在开发期方便，但不会删列、不会改类型，改结构请用 Flyway/Liquibase
  4. 方法名解析失败会直接启动报错（No property xxx found），拼错字段名最典型
  5. findByUsername 返回 Optional 与实体两种签名都支持，混用团队要约定

1.7 什么时候不该用方法名

场景
建议
条件超过 4 个
用 @Query 或 Specification
动态条件（前端可选筛选项）
Specification / Querydsl
跨表统计、复杂聚合
原生 SQL 或 @Query(nativeQuery = true)
性能敏感的大表查询
明确写 SQL，别让方法名隐式生成

方法名长到 findByAAndBAndCAndDAndE 时，可读性比手写 SQL 差得多，该换写法了。

1.9 清单

  1. Repository 是接口，实现由 Spring Data 运行时生成，不要自己写实现类
  2. 分页排序在 PagingAndSortingRepository，CRUD 在 CrudRepository，JpaRepository 两者合一
  3. 方法名解析有固定关键字表，拼错字段名会启动失败
  4. Page 会多一次 count，无限滚动场景用 Slice
  5. 条件超过 4 个或动态筛选，改用 Specification 或 @Query
  6. ddl-auto: update 只管加不管改，生产用迁移工具
  7. Repository 与实体都要在扫描包内，否则启动即报找不到 Bean
