分类：java · mybatisplus ｜ 标签：MyBatisPlus

注解映射与全局配置

表名、主键、字段、逻辑删除、乐观锁、枚举——这些映射信息写在实体上，配合全局 db-config 才能既统一又不啰嗦。

实体字段与表列之间的映射关系

1.2 常用写法

@Data
@TableName("tb_user")
public class User {

    @TableId(value = "id", type = IdType.AUTO)
    private Long id;

    @TableField("user_name")
    private String username;

    @TableField(exist = false)          // 表里没这一列
    private String token;

    @TableLogic
    private Integer deleted;

    @Version
    private Integer version;

    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createTime;

    @TableField(fill = FieldFill.INSERT_UPDATE)
    private LocalDateTime updateTime;
}

1.3 主键策略

mybatis-plus:
  global-config:
    db-config:
      id-type: auto
IdType
行为
适用

数据库自增
MySQL 单库

跟随全局 id-type
统一配置

自己设置
雪花 ID、UUID
ASSIGN_ID
雪花算法（Long/String）
分库分表

字符串主键

ASSIGN_ID 生成 19 位 Long，前端 JS 精度只有 53 位，返回给前端必须转 String，否则末几位被截断。

1.4 字段策略

@TableField(updateStrategy = FieldStrategy.NOT_NULL)
策略
含义
场景
NOT_NULL
非 null 才拼接
默认，updateById 行为
NOT_EMPTY
非空串才拼接
字符串字段想跳过空串
IGNORED
总是拼接
允许把 null 写进库
NEVER
永不拼接
只读字段

想”把字段更新为 NULL”时只能 UpdateWrapper.set("age", null) 或把策略改 IGNORED，这是最常见的困惑点。

1.5 全局 db-config 常用项

mybatis-plus:
  global-config:
    banner: false                     # 关掉启动 banner
    db-config:
      id-type: assign_id
      table-prefix: tb_               # 表名统一前缀，实体不用写 @TableName
      logic-delete-field: deleted     # 全局逻辑删除字段
      logic-delete-value: 1
      logic-not-delete-value: 0
      insert-strategy: not_null
      update-strategy: not_null
      where-strategy: not_empty
      table-underline: true           # 驼峰转下划线表名
      capital-mode: false
配置
影响
注意
table-prefix
表名加前缀
与 @TableName 同时存在时注解优先
logic-delete-field
全局逻辑删除
字段名要与实体一致
insert/update/where-strategy
空值拼接策略
where 用 not_empty 避免 = '' 查询
table-underline
驼峰表名转下划线
老库表名本身带下划线时要关

1.7 JSON 字段

@TableField(typeHandler = JacksonTypeHandler.class)
private List<String> tags;
<!-- XML 里也要标注，否则 resultMap 不会用处理器 -->
<result column="tags" property="tags"
        typeHandler="com.baomidou.mybatisplus.extension.handlers.JacksonTypeHandler"/>

autoResultMap = true 是让 typeHandler 在 BaseMapper 查询里生效的关键：

@TableName(value = "tb_user", autoResultMap = true)

1.9 清单

  1. @TableField(exist = false) 用于非表字段，否则 SQL 会带上不存在的列
  2. ASSIGN_ID 的 19 位 Long 传给前端必须转 String
  3. 字段策略默认 NOT_NULL，清空值要用 Wrapper 或改策略
  4. table-prefix 与 @TableName 并存时注解优先
  5. 枚举用 @EnumValue + type-enums-package，别存序号
  6. JSON 字段必须 autoResultMap = true 才在通用查询里生效
  7. where-strategy 建议 not_empty，避免空串参与查询
