快速开始与通用 CRUD

MyBatis-Plus 不是新框架，就是在 MyBatis 上”只做增强、不做改变”：你原来写的 XML 照样跑，多出来的是 BaseMapper 与 IService 里那套通用 CRUD。

Spring 应用经 ORM 层落到数据库

  datasource:

    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis-plus:
  mapper-locations: classpath*:/mapper/**/*.xml
  type-aliases-package: cn.demo.entity
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 开发期打印 SQL
  global-config:

updateById 的”只更新非 null”是特性也是坑：想清空字段必须用 UpdateWrapper.set("age", null)。

1.9 清单

  1. MyBatis-Plus 只做增强，原 XML 与 Mapper 继续可用
  2. 只引 mybatis-plus-boot-starter，别与 mybatis-spring-boot-starter 混用
  3. 多模块项目 mapper-locations 必须用 classpath*:
  4. updateById 只更新非 null 字段，清空字段要用 Wrapper
  5. 业务层优先 IService，需要精细控制时下探 BaseMapper
  6. saveBatch 是循环批处理，不是多值 insert
  7. log-impl 只在开发期开，生产用日志框架输出
