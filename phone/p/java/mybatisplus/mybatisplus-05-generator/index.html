MyBatis-Plus（五）代码生成器

分类：java · mybatisplus ｜ 标签：MyBatisPlus

代码生成器：从表到四层代码

一张 30 个字段的表，手写 Entity / Mapper / Service / Controller 要半小时，还容易漏。生成器把这件事变成”跑一次 main”，模板还能按团队规范改。

模板套出 Entity、Mapper、Service、Controller

1.2 基础生成（3.4.x 写法）

public class CodeGenerator {
    public static void main(String[] args) {
        AutoGenerator generator = new AutoGenerator();

        // 数据源
        DataSourceConfig ds = new DataSourceConfig();
        ds.setUrl("jdbc:mysql://127.0.0.1:3306/demo?serverTimezone=Asia/Shanghai");
        ds.setUsername("root");
        ds.setPassword("root");
        ds.setDriverName("com.mysql.cj.jdbc.Driver");
        generator.setDataSource(ds);

        // 全局配置
        GlobalConfig gc = new GlobalConfig();
        gc.setOutputDir(System.getProperty("user.dir") + "/src/main/java");
        gc.setAuthor("doubao");
        gc.setOpen(false);              // 生成后不打开目录
        gc.setFileOverride(true);       // 覆盖同名文件
        gc.setServiceName("%sService"); // 去掉 I 前缀
        gc.setBaseResultMap(true);
        gc.setBaseColumnList(true);
        generator.setGlobalConfig(gc);

        // 包配置
        PackageConfig pc = new PackageConfig();
        pc.setParent("cn.demo");
        pc.setModuleName("user");
        generator.setPackageInfo(pc);

        // 策略配置
        StrategyConfig sc = new StrategyConfig();
        sc.setInclude("tb_user", "tb_order");     // 指定表
        sc.setNaming(NamingStrategy.underline_to_camel);
        sc.setColumnNaming(NamingStrategy.underline_to_camel);
        sc.setEntityLombokModel(true);
        sc.setRestControllerStyle(true);
        sc.setTablePrefix("tb_");                 // 去掉表前缀
        generator.setStrategy(sc);

        generator.execute();
    }
}

1.4 3.5.x 的新 API

3.5.1 起 AutoGenerator 的 setXxx 换成 new XxxConfig() 构造注入：

FastAutoGenerator.create(url, user, pwd)
        .globalConfig(b -> b.author("doubao").outputDir(System.getProperty("user.dir") + "/src/main/java"))
        .packageConfig(b -> b.parent("cn.demo").moduleName("user"))
        .strategyConfig(b -> b.addInclude("tb_user")
                .entityBuilder().enableLombok()
                .controllerBuilder().enableRestStyle())
        .execute();

1.5 自定义模板

默认模板经常要改三处：BaseEntity 继承、Swagger 注解、字段注释格式。

resources/
└── templates/
    ├── entity.java.vm
    ├── mapper.java.vm
    ├── service.java.vm
    └── controller.java.vm
TemplateConfig tc = new TemplateConfig();
tc.setEntity("/templates/entity.java.vm");
generator.setTemplate(tc);

模板里可用变量：package、entity、table、fields、author、date。常见改造：

#if(${entityLombokModel})
import lombok.Data;
@Data
#end
public class ${entity} extends BaseEntity {
#foreach($field in ${table.fields})
    /** ${field.comment} */
    private ${field.propertyType} ${field.propertyName};
#end
}

1.6 与 BaseEntity 配合

团队通常有统一的 BaseEntity（id、createTime、updateTime、deleted）。生成器要跳过这些公共字段：

StrategyConfig sc = new StrategyConfig();
sc.setSuperEntityClass("cn.demo.common.BaseEntity");
sc.setSuperEntityColumns("id", "create_time", "update_time", "deleted");

否则生成出来的实体会重复定义公共字段，与父类冲突。

1.7 生成后的必改清单

  1. 主键类型：int 改成 Long（数据量上来后 int 会溢出）
  2. 时间字段：Date 改成 LocalDateTime
  3. 金额字段：BigDecimal，别用 Double
  4. Controller：删掉演示 CRUD，改成业务接口
  5. XML：确认 namespace 与 resultMap 类型正确
  6. @TableName 的表前缀是否已剥掉（setTablePrefix）

1.9 清单

  1. 必须引模板引擎，否则启动即报初始化失败
  2. 3.4.x 用 AutoGenerator，3.5.x 用 FastAutoGenerator
  3. setTablePrefix 剥掉统一前缀，实体不用手写表名
  4. 有 BaseEntity 时用 setSuperEntityColumns 跳过公共字段
  5. 生成的 Controller 是演示代码，生产要重写
  6. 生成后统一改 Long / LocalDateTime / BigDecimal
  7. 自定义模板能一次解决规范问题，比改完再 review 省事
