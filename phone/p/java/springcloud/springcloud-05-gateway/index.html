分类：java · springcloud ｜ 标签：SpringCloud

Gateway 统一网关

前端不该记住十个服务的地址，也不该处理十个服务的鉴权与跨域。网关把”对外一个入口、对内按路由分发”这件事做掉，Spring Cloud Gateway 就是官方推荐的实现。

唯一入口之后按路由断言分流到各服务

1.1 引入与启动

<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-gateway</artifactId>
</dependency>
<!-- 从注册中心拉服务列表 -->
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>

注意：网关是 WebFlux 技术栈，不能引入 spring-boot-starter-web，两者会冲突导致启动失败。

1.2 路由配置

server:
  port: 10010
spring:
  application:
    name: gateway
  cloud:
    nacos:
      discovery:
        server-addr: 127.0.0.1:8848
    gateway:
      routes:
        - id: user-service
          uri: lb://user-service           # lb = 从注册中心取实例做负载均衡
          predicates:
            - Path=/user/**
        - id: order-service
          uri: lb://order-service
          predicates:
            - Path=/order/**

lb:// 与 http:// 的区别：前者走服务发现 + 负载均衡，后者写死地址。

1.4 过滤器

局部过滤器作用于某个路由：

spring:
  cloud:
    gateway:
      routes:
        - id: user-service
          uri: lb://user-service
          predicates:
            - Path=/user/**
          filters:
            - AddRequestHeader=X-Source,gateway
            - AddResponseHeader=X-Trace,sg-001
            - StripPrefix=1        # 去掉第一层路径，/api/user → /user

全局过滤器作用于所有路由：

spring:
  cloud:
    gateway:
      default-filters:
        - AddResponseHeader=X-Author,doubao

1.5 跨域

spring:
  cloud:
    gateway:
      globalcors:
        cors-configurations:
          '[/**]':
            allowedOrigins: "*"
            allowedMethods:
              - GET
              - POST
              - PUT
              - DELETE
            allowedHeaders: "*"
            allowCredentials: true
            maxAge: 3600

默认（不配置）时网关会拒绝跨域请求，这是”本地 Postman 能通、网页报 CORS”的最常见原因。

1.6 登录校验（全局过滤器）

@Component
@Order(-1)
public class AuthGlobalFilter implements GlobalFilter {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String token = exchange.getRequest().getHeaders().getFirst("Authorization");
        if (StringUtils.isEmpty(token) || !jwtUtil.verify(token)) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
        // 校验通过后把用户信息透传给下游
        ServerHttpRequest req = exchange.getRequest().mutate()
                .header("X-User-Id", jwtUtil.parseUserId(token))
                .build();
        return chain.filter(exchange.mutate().request(req).build());
    }
}

@Order(-1) 保证鉴权先于其他过滤器执行；返回 setComplete() 才会真正中断请求。

1.7 限流（RequestRateLimiter）

需要 Redis：

spring:
  redis:
    host: 127.0.0.1
  cloud:
    gateway:
      routes:
        - id: order-service
          uri: lb://order-service
          predicates:
            - Path=/order/**
          filters:
            - name: RequestRateLimiter
              args:
                redis-rate-limiter.replenishRate: 10    # 每秒令牌
                redis-rate-limiter.burstCapacity: 20    # 峰值
                key-resolver: "#{@userKeyResolver}"
@Bean
KeyResolver userKeyResolver() {
    return exchange -> Mono.just(
            exchange.getRequest().getQueryParams().getFirst("userId"));
}

1.10 清单

  1. 网关不能引 spring-boot-starter-web，WebFlux 与 MVC 冲突
  2. lb://服务名 走服务发现 + 负载均衡，别写死 http://ip:port
  3. StripPrefix 用来剥掉统一前缀，Path=/api/** 场景几乎必配
  4. 跨域必须显式配 globalcors，否则浏览器请求全被拦
  5. 鉴权用 GlobalFilter + @Order(-1)，通过后把身份透传给下游
  6. 限流用 RequestRateLimiter + Redis，replenishRate 与 burstCapacity 别拉开太大
  7. Nginx 管加密与静态，Gateway 管业务路由，两层并存
