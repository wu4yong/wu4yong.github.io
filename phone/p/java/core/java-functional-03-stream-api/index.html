Stream API 全解

Stream 不是”更高级的 for 循环”，它是一套把数据加工拆成阶段、再按需驱动的流水线。三条铁律必须先记住：惰性（没有终止操作什么都不发生）、一次性（消费过再复用就报错）、不改变源（所有操作返回新流）。下面按”创建 → 中间 → 终止 → 收集器 → 并行”的顺序走一遍，官方文档同步对照：https://docs.oracle.com/javase/8/docs/api/java/util/stream/package-summary.html。

Stream 三段式：源头 → filter → map → collect，数据小球只走一遍

Stream<String> s = list.stream()          // 源头

1.3.1 filter 与 map

List<String> names = users.stream()
        .filter(u -> u.getAge() >= 18)     // 留下成年人
        .map(User::getName)                // 转成名字
        .collect(Collectors.toList());

顺序上先 filter 后 map 更省：过滤越早，后面的转换越少做。

1.3.2 flatMap：把嵌套摊平

// 每个订单有多个商品，想拿到所有商品
List<Item> items = orders.stream()
        .flatMap(o -> o.getItems().stream())
        .collect(Collectors.toList());

// 字符串按空格切词，一行 Stream 完成
List<String> words = lines.stream()
        .flatMap(l -> Arrays.stream(l.split(" ")))
        .filter(w -> !w.isEmpty())
        .collect(Collectors.toList());

map 是”一个变一个”，flatMap 是”一个变一串再摊平”，返回 Stream 的函数才能用在 flatMap。

1.3.3 distinct 与 sorted

list.stream().distinct().sorted().collect(Collectors.toList());

// 带比较器
list.stream().sorted(Comparator.comparing(User::getName)).collect(Collectors.toList());

// 排序 + 取 Top3
list.stream()
     .sorted(Comparator.comparingInt(User::getScore).reversed())
     .limit(3)
     .collect(Collectors.toList());

sorted 是有状态的：它必须先把全部元素缓存下来才能排，所以对无限流用 sorted 会直接卡死。

1.3.4 peek 的正确用法

list.stream()
    .peek(x -> System.out.println("before: " + x))
    .filter(x -> x.length() > 2)
    .peek(x -> System.out.println("after: " + x))
    .forEach(x -> {});

peek 只在被终止操作推动时执行，并行时顺序不可控。别用它做业务逻辑（比如累加、发消息），JDK 官方也说明它为调试保留。

// 1. 拼接
String csv = list.stream().collect(Collectors.joining(",", "[", "]"));

// 2. 分组 + 计数
Map<String, Long> byCity = users.stream()
        .collect(Collectors.groupingBy(User::getCity, Collectors.counting()));

// 3. 分组 + 取每组名字
Map<String, List<String>> nameByCity = users.stream()
        .collect(Collectors.groupingBy(User::getCity,
                 Collectors.mapping(User::getName, Collectors.toList())));

// 4. 二分区
Map<Boolean, List<User>> adultOrNot = users.stream()
        .collect(Collectors.partitioningBy(u -> u.getAge() >= 18));

// 5. toMap 建索引（value 冲突要显式给合并函数）
Map<Long, User> index = users.stream()
        .collect(Collectors.toMap(User::getId, Function.identity(), (a, b) -> a));

// 6. 分组后每组取分数最高的那位
Map<String, User> topByCity = users.stream()
        .collect(Collectors.groupingBy(User::getCity,
                 Collectors.collectingAndThen(
                         Collectors.maxBy(Comparator.comparingInt(User::getScore)),
                         Optional::get)));

toMap 不传合并函数时，遇到重复 key 直接抛 IllegalStateException——这是线上事故高发点，务必想清楚 key 会不会重复。

1.6 数值流与 Optional

mapToInt/mapToLong/mapToDouble 返回 IntStream 这类专门流，避免装箱，并直接提供 sum/average/max/min/summaryStatistics：

IntSummaryStatistics stat = users.stream()
        .mapToInt(User::getScore)
        .summaryStatistics();
// stat.getCount() / getSum() / getMin() / getMax() / getAverage()

// 数值流之间转换
IntStream.rangeClosed(1, 10).map(x -> x * x).boxed().collect(Collectors.toList());

Optional 是”可能没有值”的容器，与 Stream 的 findFirst、reduce、max 天然搭配：

String name = users.stream()
        .filter(u -> u.getAge() > 60)
        .findFirst()
        .map(User::getName)
        .orElse("none");        // 用 map 而不是 get()，避免 NoSuchElementException

1.7 并行流：三个前提

long n = list.parallelStream().filter(this::heavyCheck).count();
  1. 数据量大（一般万级以上才有意义）
  2. 单元素耗时可观（每个元素只做一次加法，切分开销比计算还贵）
  3. 无共享可变状态（否则要么错、要么要加锁，白白抵消收益）

默认使用 ForkJoinPool.commonPool()，并行度 = CPU 核数 − 1。IO 密集任务会把公共池打满，进而影响其他并行流，所以要么不用，要么显式传池：

ForkJoinPool pool = new ForkJoinPool(4);
long n = pool.submit(() -> list.parallelStream().filter(this::heavyCheck).count()).get();

1.8 清单

  1. 看返回类型判断阶段：返回 Stream 是中间操作，否则是终止操作
  2. 没有终止操作，整条流水线一行代码都不会执行
  3. 流只能用一次，复用会抛 IllegalStateException
  4. 先 filter 再 map，能让后续转换少做很多
  5. flatMap 用于”一对多再摊平”，返回的必须是 Stream
  6. sorted、distinct 是有状态操作，不能用在无限流上
  7. toMap 一定要考虑 key 重复，必要时给合并函数
  8. groupingBy 嵌 mapping/counting/maxBy 能一次遍历完成多级统计
  9. parallelStream 只在大数据量、无状态、CPU 密集时用，IO 密集请自定义线程池
