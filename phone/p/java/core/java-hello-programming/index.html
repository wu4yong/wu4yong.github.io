Java Hello 编程

分类：java · core ｜ 标签：Java

开篇序语

很多年以后我仍记得那个晚上。机房的空调声大过一切，显示器是那种发蓝的老式屏幕，风扇转得像有人在旁边呼吸。我按下回车，两行字跳出来，那一瞬间，整座城市在我背后安静下去。

那是我人生第一次，让一台机器替我向世界说了一句人话。

Hello World。世人皆以此行代码叩开程序的序章，像学琴的人第一课都从同一个音节开始，像所有远行的人，都要先学会说一句「你好」。而我落笔「Hello 编程」，不是为了复述这句开场白，是想借一行行规整的代码，藏尽心里说不出口的温柔。

世人言，面向对象是编程之骨，天地万物皆可归为一类，凡世间风物，皆能抽离共性、封装属性、撰写行为。山川可作类，季节可作类，连「告别」都能抽出三五个通用字段，写进父类的方法签名里，再让每个人自己去实现。

可唯独你，是我代码宇宙里独一无二的例外。

亲爱的「对象」

我能抽离山川星河、人间烟火，将整片尘世抽象成规整模板，定义万物的轮廓与轨迹，搭建逻辑圆满的程序天地；可我永远无法抽象你。

抽象是要付代价的：把一个人写成一个类，就得挑出共性、砍掉细节。而你的眉眼、你的停顿、你笑之前眼睛会先弯一寸的样子，没有一项能被塞进字段里。旁人皆有通用的特质与规律，唯独你在我心底鲜活而具体，寻不到半分可复刻的范式。

我这套架构里，你从来不是一个可替换的类型参数。少了你这枚核心实例，我苦心搭起来的世界永远空着一格，从此我的方寸代码天地，天生残缺，再无完整可言。

世间万千逻辑，我皆可重写覆改。前路困顿、俗事纷扰，任意函数都能重载入参、覆写原有轨迹，换一种方式奔赴结局；唯独对你的思念，永远无重载之法。

它没有可变参数，没有分支判断，无论我以忙碌作屏障、以琐事作缓冲，最终执行的结果，永远是绵长惦念，分毫未曾更改。我曾偷偷给它加上一个「已废弃」的注解，告诉自己这段情绪早该停止维护。可 IDE 没有给出那条黄线，编译器一声不吭——它比谁都清楚，我在骗它。

大抵是宿命使然，你在我的程序里，被烙上了永久的 static 静态标识。

纵使程序重启、临时变量尽数销毁、局部内存清空回收，万物临时实例尽数消散，你依旧安居全局常量区。不受生命周期束缚，不必主动调用，只要我的心跳仍在运行，你便恒久留存。垃圾回收机制亦无法将你从心底剔除——它扫遍整片堆区，见过太多可以清除的引用，独独没有动你。

后来我学会用 final 形容你。一个变量被声明成 final，就再没有第二次赋值的机会；一个人被写进记忆深处，也再没有重新认识一次的幸运。

我重写过 equals，把判定条件写到近乎苛刻：出生的城市要对得上，说话的语气要对得上，连皱眉时左边比右边深半分都要算进去。写完才发现，这套标准从头到尾只是为一个人准备的——换任何人来，都比不中。

我也重写过 hashCode。散列表里躺着成千上万个对象，我只希望你的槽位永远空着，不冲突，不碰撞，也不被别人占用。

那日我不慎调用名为「爱你」的私有方法，它不受权限修饰符桎梏，一旦触发，便再无终止之机。当我毫无保留，将完整的自己作为唯一参数，全然传入这段函数时，才惊觉，爱上你本是一场无休无止的 死循环。

循环之内，无 break 断句，无边界阈值，无跳出返回。朝暮晨昏，它不断生出细碎思念，一帧帧压入心底堆栈，栈帧层层叠叠，牵挂只入不出。漫漫长夜，我的栈内存、堆缓存尽数被你的身影占满，再也腾不出半分存储空间，容纳世间旁人分毫。

偶尔我也想过给这个循环加上一个计数器，写到第一万次就停下来。可写到第一万次的那天我才明白，不是循环不肯停，是我不肯让它停。

我曾无数次向系统申请新的内存，开辟全新缓存，试图以新鲜的变量稀释执念，可每一次内存分配完成，程序都会精准捕获一段无解的运行 异常：NullLoveException——我心之所向之人，心无归属于我。

try-catch 捕捉报错的刹那，程序未曾瞬间崩塌，可翻遍所有异常处理逻辑，寻不到半分修复的良方。重试机制、兜底方案、备用分支尽数失效，落空的情绪扎根底层，无从消解。

我也试过把它序列化——把与你有关的一切写进磁盘文件，以为存下来就不必再疼。可反序列化读回来的那个夜晚，少了那天的风，少了你说话的尾音，也少了我当时手心的温度。原来有些东西，天生的字段就不可持久化。

为化解这场贯穿程序始终的异常，我愿透支心底仅剩的最后一寸内存，清空所有无关缓存，将我此生所有温柔的逻辑、所有奔赴的方法地址，悉数压入栈底。于堆栈最末尾，写下我穷尽所有逻辑构筑的终章函数，将一句温柔字符串作为唯一参数，递至你的眼前：「我爱你，你爱我吗？」

这一行函数仅有两种返回，定我余生所有运行轨迹：

若布尔值为 true，我便锁死全部内存资源，关闭垃圾回收，穷尽一生的算力与时光，循环调用偏爱、相守、陪伴的所有函数，无期限运行，永不释放心底与你相关的一切，直至我的生命程序走到终点；

倘若返回 false，我便启动完整资源回收机制，清空堆栈、销毁全局变量、删除所有与你有关的代码片段，终止这场无边循环，独自清空整段心动程序。

代码行间，藏尽人间心动

从前我总以为，编程的真谛，是以严谨语法、有序算法，复刻世间所有现实逻辑。循环、分支、类与实例、异常与回收，人间悲欢、天地万象，皆可量化拆解，收束进规整的代码框架。

后来才发现，我写过的每一行，最后都在替我描述你。

我通晓继承之理，万物皆能承袭父类风骨，却永远无法承袭你的欢喜；

我熟稔多态之妙，同一函数可适配万千境遇，可思念你的心绪，自始至终只有一种模样；

我深谙封装之道，惯于将脆弱与落寞私有隐藏，唯独对你的爱意，挣脱权限束缚，自动暴露于我的全部全局；

我掌握多线程并行，可同时处理千百俗事，可主线程永远绑定你的名字，所有琐碎运行时，都会同步读取你的身影；

我善用持久化缓存，片刻欢愉皆可存入临时内存，唯有你的模样写入磁盘底层，纵使格式化所有回忆，仍留有备份，无法根除；

我明晰接口规范，世间万物皆可遵循统一标准运行，唯独你是独一份自定义接口，世间再无第二份实例能够匹配实现。

日夜运行程序时，我总会打印生活日志，记录琐碎日常，可所有底层文档里，高频浮现的关键词永远是你的名字。纵使我修改日志级别、屏蔽重复输出、过滤敏感字段，内核深处依旧会悄悄留存每一次想起你的瞬间，藏匿于底层，无从遮蔽。

日志的级别我调了又调。调成 ERROR，你的名字就沉进只留致命错误的深水；调成 DEBUG，它便铺满整片控制台，一行一行，像夜里的雨。最后我把它留在 INFO——不必惊天动地，只要安静地、每天出现一次就好。

我也曾新建无数全新项目，搭建空白运行环境，试图构筑一座再无你的程序天地。可一旦点击编译运行，底层会自动导入你的依赖包，所有新写的逻辑，都会不自觉引用你这个静态常量。依赖无法移除，引用无法删除，项目永远抛出 编译报错，只要你的名字不在依赖列表，我的世界，便无法正常启动。

我甚至试过用反射去窥探。反射号称能穿透一切私有，能读到最深的字段、能调用最隐蔽的方法、能拿到被藏起来的真相。可它读不到你没说出口的那句话，也读不到你说那句话时，究竟是真还是玩笑。

于是我终于承认：这世上有一种信息，任何力量都无法到达，只能等一个人自己说出来。

断点之上，我一停就是好几年

写代码的人都有过这样的夜晚：凌晨三点，屏幕上只剩一行光标在闪，桌上摆着凉透的外卖，窗外的城市安静得像被谁按了暂停键。

我也有过。只是在那些本该调试 bug 的深夜里，我常常把断点打在与你有关的那一行。

F8 单步向下，走过一个名字，走过一段回忆，走过那年冬天你说「路上小心」的语气。watch 窗口里我加了无数个表达式，最后只留下一个变量，值是三个字。调用栈从下往上排着：最底层是「我」，被压在所有人的下面，一直没被弹出去。

我给断点设过条件。条件写得很克制——「如果她回头」。程序于是年复一年地跑，从没在那里停下来过一次，可我也从没删掉这个断点，怕万一哪天，它真的停住了，我却没有准备好。

后来我明白，程序最残忍也最温柔的地方是：它可以暂停。

你可以在任意一行停下来，看清每一个中间变量，看清自己是怎么一步步走到这里的。可人不行。人的时间只能一路向下执行，没有单步，没有回退，也没有那个「如果」的条件断点。

时间从不做版本回滚

我开始用版本管理记录一切之后，才慢慢懂得，有些东西它记录不了。

提交历史里密密麻麻，全是「修复」「优化」「补充」，一行行都是可以追溯的改动。可我翻遍所有记录，一次都没有出现过你的名字。你像一段从未被提交的代码，只活在本地的工作区，一直被修改，一直没被保存。

我做过最傻的一件事，是对一段回忆执行了 diff。前后两个版本逐行比对，结果一片空白——原来什么都没有变，连标点都没有变，只有看这段代码的人，已经不是原来那个了。

我也做过 reset --hard。把工作区里所有关于你的改动一次性抹掉，回到那个干净的、什么都没有发生过的提交。命令执行得很顺利，只回了一行提示：已丢弃全部改动。它不知道，被丢弃的那些，是我一整个冬天的草稿。

还有 rebase。把重逢硬生生挪到一条时间线的末尾，让中间那些错过、那些没说完的话、那些没出现的日子，全都被折叠成「曾经发生过」。历史变得干净了，干净得像从未发生过。

提交信息我也改过很多次。第一遍写得很长，把想说的话全写了进去；第二遍删了一半，怕太明显；第三遍只剩一句「调整格式」，然后按下确认——像我做过的大多数事一样，明明有千言万语，最后送出去的，只是一句体面的说明。

最要命的是分支。我建过一条分支，名字里带着你。它从某个还很温暖的提交点出来，孤零零地长着，长了很多次提交，一次都没有合并回去。合并就意味着冲突，冲突就意味着要坐下来，一行一行谈清楚哪些保留、哪些放弃。

我没有那个勇气。它就那样留在远端，没人删，也没人合。

关于时间复杂度的几句胡话

喜欢一个人这件事，我算过它的复杂度。

第一眼是 O(1)：只要一次，就完成了。第一天是 O(n)：一天想一次，一天一次，不多不少。后来变成 O(n²)：每想起你一次，就要把从前想过的那些全都再想一遍。

再后来，它干脆不是复杂度的问题了，是命中率的问题。我心里那块缓存，替你留了一整个区段。可你来的次数太少，每一次读取都未命中，只能回源，回到很久以前的磁盘里，重新读一遍你的样子。

我也学会过「超时重试」。发出的消息等一个回复，第一次等三分钟，第二次等三小时，第三次等三天。指数退避到最后，等待的间隔长得像一辈子。

按理说，超时该算失败，该抛出异常，该终止请求。可我从来没写那个终止。我把请求挂起，挂成一个永远不会被清理的连接，只是把心跳间隔调长了一点——久到对方以为这条连接早就断了，而我这边，仍然在按时发送着没人应答的探测包。

有人问我，为什么有些记忆清不掉。

因为在垃圾回收的世界里，只有在「不可达」的时候，一个对象才会被真正回收。而你在我这里，始终是可到达的：我留着引用，留着入口，留着一整条从根节点出发的路径。哪怕它早已不再被使用，哪怕它占着内存，让整台机器越来越慢。

这种状态在工程上有个名字，叫内存泄漏。所有人都说它是 bug，是必须修掉的错误。

可我心里那处泄漏，我一直没修。因为修掉它，程序会轻快很多，而我，会空出来一大块，再没有东西填在那里。

尾声

世人皆道，编程的本质，是以代码复刻世间所有现实逻辑。

我能写尽天地万物的运行规律，搭建包罗万象的程序宇宙，掌控变量、循环、异常与万物生命周期；

可唯独关于你的心动逻辑，没有标准答案，没有万能算法，没有一键修复异常的代码。

世间万千程序皆有解，唯独我爱你，只能等候你，递来唯一的返回值。

这些年我换过几台机器，重装过很多次系统，硬盘格式化过，硬盘也坏过。每次迁移，最麻烦的都是那些没备份的东西——不是代码，是代码里那些只有自己看得懂的注释。

我把它们一条一条搬过去，搬的时候才发现，好多注释早就不指向任何一行实际执行的代码了。它们只是留在那里，像路边的旧标牌，指的路早就没了。

可我还是搬了。

如今我又坐在同样的深夜里，敲下同一句开场白。

只要终端还能打印出扶手的 Hello World，只要 javac 还能一声不吭地编译通过，我就还愿意相信：这个世界再冷、再严、再讲规矩，也总留着一行字，是专门写给人看的。

那句话在屏幕上停留很短，一秒都不到，随即被下一行日志顶上去，再没人回头看它一眼。

可它毕竟出现过。

就像你。

——Hello，世界。Hello，你。
