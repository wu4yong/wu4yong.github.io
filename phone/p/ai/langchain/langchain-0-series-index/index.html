00 系列目录与学习路线

14 讲 · 4 模块：基础与模型 → 工具与结构化输出 → Agent 与中间件 → 上下文与检索｜以 LangChain v1（1.x）为基线自绘

版本不一致提示

  • 本系列的旧版文章写的是早期 0.x 的写法（LLMChain、AgentExecutor、langchain.chains 那一套），与 v1 的包结构和 API 有破坏性差异，请按本系列重读；
  • 官方 1.x 文档本身仍在演进，个别口径（如 max_retries 的默认值）在不同页面给出的数值不一致，本系列的做法是把官方原话并列写出，不替官方统一；
  • 官方示例环境统一写 Python 3.11，本系列统一用 3.13，属解释器版本差异，不影响 API 与行为。

一、一句话定位

这套课以 LangChain v1（1.x）为主线，只写 Python，每个概念、每张参数表都对官方 docs.langchain.com；官方没写的，标「官方未说明」。
学完的目标不是「知道 LangChain 有哪些类」，而是能用 create_agent 独立做出一个能跑的 Agent。

二、三条口径先说清

  1. 版本：锁 v1（1.x）。AgentExecutor、create_react_agent、旧式 Chain 一律不教——它们要么已从主包移除，要么被 create_agent 取代。
  2. 来源：官方文档是唯一权威。任何「实践补充」都显式标注【实践补充，非官方文档内容】。
  3. 边界：LangSmith 的 trace 与评测，只做一句话引入，深入内容属于独立系列，本系列不展开；LangGraph 的图机制原本也在这里「一句话引入」，现在已单独成系列，需要自己画图、做中断与持久化时转读 LG00 LangGraph 系统课。

五、每讲的固定结构

每一讲都是同一副骨架，方便你跳读：

  1. 学习目标（三件具体的事）
  2. 前置知识
  3. 理论讲解（官方定义，段落顺序镜像官方页面 H2/H3）
  4. 原理拆解（通俗类比）
  5. 场景说明
  6. 示例代码（环境 → 凭证 → 导入 → 代码 → 预期输出 → 验证，六步）
  7. 常见坑（官方限制 + 版本差异）
  8. 课后小结
  9. 思考题（每题紧跟参考回答）
  10. 下一篇预告

六、怎么读这套课

  • 先跑通再回头：每讲的六步代码都能单独跑，先让它出结果，再读原理；
  • 参数表当手册：表里的「v1 变化」列是给自己排雷用的，遇到「为什么旧教程写不通」先查这张表；
  • 不背 API：v1 的入口只有五个模块，记住 agents、messages、tools、chat_models、embeddings，其余用到再查。
