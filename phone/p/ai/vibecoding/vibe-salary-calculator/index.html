Vibe Coding

工资计算器 — 上班情绪稳定器

一个带薪摸鱼风格的实时工资计算器：填好月薪和出工时间，工资卡上的数字就会随秒跳动，实时告诉你「现在这一刻已经赚了多少钱」。

在线链接：上班情绪稳定器

一、主界面

打开页面后，正中间是一张收据风格的工资卡；桌面端左侧是每日打卡面板、右侧是勋章墙，页面底部还有源源不断的 Emoji 喷泉当背景。

工资卡上从上到下依次是：

  • 日期与星期：旁边带一个「搬砖日 / 躺平日」开关，可以手动把今天切换成工作日（比如周末加班）或休息日（比如今天请假）
  • 电子木鱼：点击木鱼即可敲击，随机蹦出「暴富」「升职」「上岸」等好运词，累计的好运次数显示在下方
  • 实时到账金额：今天已经赚到手的钱，每秒刷新，红色大字带跳动动画
  • 多币种换算：同一笔钱自动换算成美元、日元、欧元，方便安慰自己「今天已经赚了 5 美元」
  • 出工进度条：今天已经搬完的砖占全天总量的百分比
  • 俏皮文案：随时间段变化，比如「早起的牛马有草吃 🌾」「进入倒计时，收拾收拾准备跑路 🏃」

工资卡下方还有一行状态文案：没到上班点显示「距开始搬砖还有 X 小时」，上班中显示「距收工还有 X 小时」，下班后显示「今日进账 ¥XXX，收工！」。

页面最底部固定两行文字：一行是牛马费摘要（月薪、休息模式、出工时间段），一行是本站宗旨——「把尿喝白、电冲绿、事办黄」。

二、牛马费设置

首次打开页面会弹出「牛马费设置」对话框，之后可以随时点击右上角的 ⚙️ 按钮重新打开。

  • 牛马费（到手多少）：填写月薪，输入时下方会实时弹出对应段位的吐槽彩蛋，比如「为爱发电，穷的稳定 💔」「大佬带带我 🧎」
  • 出工时间：设置每天的工作时间段，默认 09:00–12:00、13:00–18:00，支持添加多个时段，自动计算每天总时长
  • 喘气模式：双休 / 单休 / 自定义月休天数三种模式；选单休时还可以指定周几休息

四、勋章墙

桌面端位于主界面右侧，移动端是底部 Tab 的「勋章」页。共两排勋章，未解锁的灰显并带 🔒 标记：

五、移动端

移动端会自动切换为底部三个 Tab 的布局：「💰 工资」「📋 打卡」「🏆 勋章」，工资卡、打卡面板和勋章墙分页展示。

其他说明

  • 页面上的所有数据（配置、打卡计数、好运次数）都保存在浏览器本地，清除浏览器数据后需要重新设置
  • 工作日与休息日的判断基于设置的喘气模式，也可以用工资卡上的开关对「今天」单独覆盖
