00 系列目录与学习路线

16 讲 · 5 模块：图与状态 → 持久化与人机 → 运行时能力 → 架构与落地｜以 LangGraph v1（1.2.x）为基线自绘

版本不一致提示

  • 本篇基线是 LangGraph 1.2.x + Python 3.13；官方要求 Python ≥ 3.10（LangChain 1.5 起要求 ≥ 3.11），本系列统一 3.13，仅解释器版本不同；
  • langgraph.prebuilt 里的 create_react_agent 在 v1 已弃用，官方替代是 langchain.agents.create_agent；本系列不用预置件，全部手搭，需要高层 Agent 时指回 LangChain 系列；
  • 1.x 的 invoke() / stream() 默认仍是 version="v1"，官方建议新代码显式传 version="v2"（返回 GraphOutput，带 .value / .interrupts），本系列统一显式传；
  • DeltaChannel（1.2 新增）与 version="v3" 事件流仍是 beta，正文出现处会标 beta，不作为推荐路径；
  • 官方示例模型名随 provider 更新，不影响图的写法。

一、一句话定位

LangChain 系列讲的是「怎么用装好的 Agent」；这套讲的是「Agent 底下那台运行时，怎么自己搭」。

学完的目标不是「知道 StateGraph 有哪些参数」，而是能自己画一张有状态、能中断、能续跑、能观测的图，并把它部署成一个服务。

二、三条口径先说清

  1. 只讲原语。create_react_agent 已弃用，本系列不教；需要「一句话起一个 Agent」时，用 LangChain 系列的 create_agent，它本身就是一张编译好的 LangGraph。
  2. 官方文档是唯一权威。任何「实践补充」都显式标注【实践补充，非官方文档内容】；官方没写的，标「官方未说明」。
  3. 不重复 LangChain 系列。消息结构、工具协议、结构化输出、中间件已在那套课里讲过，这里只讲「图里的那部分怎么做」，需要时用一句「见 LCxx」补齐前置。

三、学习路线

  • M1 图与状态（4 讲）：手搭一张最小图，写 schema 与 reducer，用条件边 / Command / Send 控制走向。前置：无（最好读过 LC01–LC03）。
  • M2 持久化与人机协同（4 讲）：checkpointer 存线程、interrupt 让人点确认、回滚与分叉历史、跨线程长期记忆。前置：M1。
  • M3 运行时能力（3 讲）：五种流式模式、子图与状态映射、节点级超时与降级。前置：M2。
  • M4 架构与落地（5 讲）：多 Agent 拓扑、图内工具循环、测试与评测、部署清单、综合实战。前置：M3。

推荐顺序 M1 → M4，不跳。M2 的 checkpointer 是 M3 与 M4 的地基：没有 checkpoint，就没有 resume、没有时间旅行、也没有流式里的断点。

六、和 LangChain 系列怎么衔接

两套课不是并列关系，是「上层」与「底层」的关系：

你现在想做的事
该读哪一套
为什么
一句话起一个能跑的 Agent
LangChain LC08 create_agent
它直接返回一张编译好的 LangGraph
改 Agent 的行为（预算、摘要、审核）
LangChain LC09 / LC10 中间件
钩子已经挂在那张图里，不用自己画图
自己控制分支、循环、并行、多 Agent 交接
本系列 M1 / M3 / M4
这些是图结构问题，中间件替代不了
要断点续跑、人工审批、时间旅行
本系列 M2

先读哪一套都行，但两个概念必须分清：LangGraph 是运行时，LangChain 是建在运行时上的一套 Agent 封装。分不清这一点，就会一直在「为什么我的 Agent 不能自定义流程」里打转。

七、怎么读这套课

  • 先跑通再回头：每讲六步代码都能单独 uv run，先让它出结果，再读原理；
  • 状态优先：卡住时先问「这个值该存在哪个 key、有没有 reducer」，八成的坑都在这；
  • 不背 API：真正要记的只有五个入口——StateGraph、add_node、add_edge、compile、invoke，其余用到再查；
  • 图先画再写：每讲配一张图，写代码前先在纸上把节点和边画出来，比边写边想快得多。
