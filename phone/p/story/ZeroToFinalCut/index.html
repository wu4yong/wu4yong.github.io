〇、先建立正确学习路径

三份原始笔记的共同结论：

剪映解决“把素材变成作品”，即梦解决“从 0 生成素材和内容”。

建议顺序：

  1. 剪映基础剪辑：分割、删除、移动、字幕、音频、导出。
  2. 剪映节奏与表达：结构、转场、节奏、调色。
  3. 即梦 AI 生成：文生图、图生视频、文生视频、提示词。
  4. 即梦 + 剪映混合出片：AI 生成镜头进入剪映二次剪辑。
  5. 复盘与风格化：每周 2～3 条作品，做 8 项自查。

学习原则：每周只攻克一个重点；每 1～2 周产出一个 15～60 秒小作品；不要等“学完所有功能”再开始。

第一部分：剪映实战笔记

1.1 先认识界面：按钮在哪里

手机版编辑界面

上方是预览区，中间是时间轴，底部是工具栏。底部一级工具栏通常包含：剪辑、音频、文本、贴纸、画中画、特效、调节等入口。点击某个素材后，工具栏会切换为该素材可用的二级工具。

电脑版编辑界面

主要分为：素材箱（左上）、预览区（中上）、属性/调节区（右上）、时间轴（下方），工具栏竖排在左侧。导入素材从左上角“导入”进入素材箱，再把素材拖到下方时间轴。

建议截图后用红圈标出：①预览区 ②时间轴 ③底部工具栏 ④“分割”按钮 ⑤“导出”按钮。

【配图占位】剪映电脑版界面标注图
建议标出：①素材箱 ②预览区 ③时间轴 ④左侧工具栏 ⑤右上角“导出”。

工具：剪映官网 https://www.capcut.cn/

1.2 基础剪辑：分割、删除、移动

目标：能把一段长素材掐头去尾、删掉中间废段、调整顺序。

手机版操作步骤

  1. 打开剪映，点击 “开始创作”。
  2. 勾选视频/图片，点击 “添加”，素材进入时间轴。
  3. 把时间轴上的白色播放头拖到要剪掉的位置。
  4. 点击底部 “分割”，一段素材被切成两段。
  5. 点击不要的那一段，选中后片段边缘出现白框。
  6. 点击底部 “删除”。
  7. 删除中间段时：先在废段的开头和结尾各点一次“分割”，再选中中间那段并删除。
  8. 调整顺序：长按某段素材，左右拖动到目标位置后松手。

电脑版快捷键

  • 切割：Ctrl + B
  • 删除：Delete
  • 撤销：Ctrl + Z

新手建议

不要一上来做“精细卡点”。先用 5 分钟把素材里“发呆、重复、走路过长”的废段全部切掉，得到一个干净的骨架版本，再谈节奏和美化。

【配图占位】分割操作标注图
截图时间轴画面，红圈标出白色播放头位置 + 底部“分割”按钮。

【配图占位】删除中间段示意
用两条红色竖线标出“首尾各分割一次”的位置，中间段用灰色标“删除”。

1.3 转场与镜头衔接：少即是多

操作路径

  1. 找到两段素材之间的小白方块（衔接处）。
  2. 点击它，底部出现“转场”选项。
  3. 选择效果。
  4. 拖动调整转场时长。

新手推荐参数

  • 日常 Vlog、叙事片：优先用 叠化，时长 0.2～0.4 秒。
  • 需要段落分隔：用 黑场 1～2 帧。
  • 不要在同一个视频里混用 4～5 种转场，统一风格比“丰富”更重要。

【配图占位】转场入口标注图
在时间轴两段素材衔接处画红圈，箭头指向底部转场面板。

1.4 字幕：从“有字”到“能读”

自动字幕：口播/讲解首选

  1. 点击底部 “文本”。
  2. 选择 “识别字幕”/“自动字幕”。
  3. 等待识别。
  4. 点任意一条字幕进入编辑，修改错字、统一字体和大小。
  5. 批量统一：全选字幕轨道，统一设置字体、颜色、动画。

手动标题

  1. 点击底部 “文本”。
  2. 选择 “新建文本”。
  3. 输入标题。
  4. 在预览区拖动位置。

字幕规范

  • 字体：粗黑体/粗圆体，字号偏大。
  • 位置：画面上方或下方留白区。
  • 可读性：白字 + 黑描边，或深色半透明底。
  • 不遮挡人脸和产品主体。
  • 一行不超过 12～15 字。
  • 口播字幕与语音严格同步，宁可分段也不要堆长句。

【配图占位】自动字幕入口标注图
底部工具栏“文本”按钮 + 二级菜单“识别字幕”红圈。

【配图占位】字幕安全区示意
在预览画面上用虚线框标出“可放字幕的安全区域”，上下边缘和人物面部区域标“避开”。

1.5 音频：人声永远在音乐之上

导入音乐

  1. 点击底部 “音频”。
  2. 选择 “音乐”。
  3. 搜索或从素材库选择。
  4. 点击 “使用”，音乐进入时间轴。

音量分层：关键数值

  • 背景音乐：点音乐轨道，音量调到 20～30。
  • 人声/配音：点人声轨道，音量调到 80～100。
  • 操作顺序：先对人声，再垫音乐，不要让音乐在关键句上压住人声。

降噪

  1. 选中带人声的音频轨道。
  2. 下滑找到 “降噪”。
  3. 开启。
  4. 强度建议 60%～75%，过高会让人声发干。

卡点：可选进阶

  1. 选中音乐轨道。
  2. 选择 “踩节拍”/“自动踩点”。
  3. 选择节拍速度。
  4. 视频片段边缘贴合节拍标记。

【配图占位】音量分层标注图
截两条轨道（音乐 + 人声），分别标出音量数值 25 和 90。

【配图占位】降噪入口图
选中音频轨道后下滑出现的“降噪”开关。

1.6 调色：先“修复”再“风格化”

新手万能参数：日常 Vlog / 生活记录

  • 亮度：+5～+10
  • 对比度：+10～+15
  • 饱和度：+5 左右
  • 锐化：+15～+20

目标：画面通透、不灰不脏，而不是“加滤镜感”。

操作路径

  1. 选中视频。
  2. 点击底部 “调节”。
  3. 拖动各参数。
  4. 或点击 “滤镜” 选预设，强度拉到 30%～50%，避免过度。

风格化：进阶

  • 电脑版可导入 .cube LUT 文件。
  • 路径：调节 → LUT → 强度 60%～80%。
  • 一个视频只用一个主风格，不要在一条片子里反复换色调。

【配图占位】调节面板标注图
底部“调节”入口 + 亮度/对比度/饱和度滑块的推荐数值标注。

1.7 导出：别在最后一步翻车

操作路径

  1. 点击右上角 “导出”。
  2. 选择分辨率与比例。
  3. 保存最终作品。

短视频平台推荐参数

  • 竖屏：9:16，1080×1920，30fps
  • 码率：12Mbps 左右
  • 需要高清存档可选更高码率。

导出前检查

  • 有没有黑帧/错位。
  • 字幕是否被平台 UI 遮挡。
  • 人声是否清晰。
  • 画面是否清晰。
  • 音频是否正常。

1.8 剪映出片前 60 秒检查清单

  • 开头 3 秒有钩子。
  • 无黑帧/错位。
  • 人声音量 80～100，BGM 20～30。
  • 字幕不被裁切、不错字。
  • 色调统一不跳。
  • 导出比例 9:16 / 1080P。
  • 主题明确。
  • 节奏自然。
  • 没有明显空白镜头。
  • 配乐适合内容情绪。

第二部分：即梦实战笔记

工具：即梦 AI 官网 https://jimeng.jianying.com/
备用入口：https://jimo.capcut.cn/

2.1 先分清两个入口：文生视频 vs 图生视频

即梦的视频生成有两个基本通道，选错入口会多走很多弯路：

  • 文生视频：没有现成画面时用。输入文字描述，AI 直接生成视频。
  • 图生视频：已经有一张满意的图片时用。上传图片，AI 让画面“动起来”，生成 5 秒左右的基础运镜视频。

新手建议

第一条视频建议从图生视频开始：

  1. 先文生图。
  2. 选出一张构图和质感都满意的图。
  3. 再用这张图做图生视频。

原因：图比视频好筛选，而且“图生视频”的稳定性明显高于纯文生视频。

【配图占位】即梦首页标注图
底部“视频生成”入口 + 模式选择页的“文生视频 / 图生视频”两个按钮。

2.2 文生视频：提示词怎么写才不“抽卡”

操作路径

  1. 首页/创作中心。
  2. 点击 “视频生成”。
  3. 选择 “文生视频”。
  4. 输入提示词。
  5. 设置参数。
  6. 点击 “立即生成”。

提示词结构：直接套

主体 + 动作 + 环境 + 光线/材质 + 风格 + 运镜

示例：

“一位穿深色外套的年轻人在雨后的老城区街道行走，地面积水反光，暖色路灯，电影胶片质感，镜头缓慢跟随推进。”

新手参数建议

  • 比例：按平台选 9:16。
  • 时长：5 秒。
  • 分辨率：1080P。
  • 模型：默认最新版即可。

提示词注意

  • 不要用“好看”“高级”这类模糊词。
  • 要写颜色、材质、光照方向、动作幅度。
  • 系统一次通常返回 4 个候选视频，逐个预览。
  • 重点看：人物面部有没有畸变、动作是否连贯、背景是否稳定。
  • 不满意不要反复微调同一句提示词，先换主体或场景重新生成一批，筛选效率更高。

【配图占位】文生视频界面标注图
提示词输入框、比例下拉框、时长/分辨率设置区、“立即生成”按钮。

2.3 图生视频：让一张好图“动起来”

操作路径

  1. 视频生成。
  2. 选择 “图生视频”。
  3. 上传图片。
  4. 写运动提示词。
  5. 设置参数。
  6. 生成。

关键认知

图生视频的提示词只描述“运动中变化的部分”，不需要重新描述图中已有的静态内容。

示例：图片是“女生站在海边”，运动提示词写：

“镜头缓慢推近，头发被海风吹动，裙摆轻摆，海浪向后流动。”

运镜控制

  • 生成后可点 “镜头控制” 加推远、旋转等效果。
  • 新手先用 “自动运镜”模板，避免参数误调。

【配图占位】图生视频界面标注图
图片上传区 + 运动提示词输入框 + “自动运镜”按钮。

2.5 即梦的局限：它生成的是“素材”，不是“作品”

AI 生成的片段通常：

  • 没有叙事结构。
  • 节奏可能失控。
  • 字幕和配音需要重新组织。

因此即梦的输出必须进入下一步：

导入剪映 → 二次修剪 → 重排 → 配音 → 字幕 → 音量分层 → 导出。

把即梦当作“素材生产线”，而不是“一键成片按钮”。

2.6 即梦生成前 60 秒检查清单

  • 模式选对：文生视频 / 图生视频。
  • 提示词有主体 + 动作 + 环境 + 光线 + 风格。
  • 比例 9:16。
  • 时长 5 秒。
  • 一次生成 4 条再筛选。
  • 生成后只取最稳的 1～3 秒进剪映。
  • 检查人物面部、动作连贯、背景稳定。
  • 检查是否“AI 感过重”。

第三部分：从“做完”到“出大片”

3.1 先结构，后节奏，再美化

正确顺序：

定主题 → 搭结构 → 控节奏 → 加字幕/音频 → 调色 → 导出

新手最容易做反：先加滤镜、先找转场、先堆特效。正确做法是先让内容成立。

15～40 秒结构模板：直接套

  1. 3 秒钩子：最强情绪/动作/悬念镜头，不要用空镜开场。
  2. 建立环境：1～2 个空镜或交代镜头，告诉观众“在哪、什么氛围”。
  3. 推进信息：3～6 个短镜头，每个镜头只承担一个信息点。
  4. 情绪收束：一个稍长的镜头 + 2～4 秒留白或收尾字幕/钩子。

节奏不是“平均切”

  • 信息镜头（走路、街景、操作）：0.6～1.2 秒。
  • 情绪镜头（表情、光影、远景）：2～4 秒。
  • 整体做 “快—慢—快”。
  • 高潮前故意放慢一个长镜头，比全程快切更像“片子”。

【配图占位】结构模板时间线示意
画一条横向时间轴，用色块标出“钩子 0–3s / 环境 3–8s / 推进 8–30s / 收束 30–40s”。

3.2 新手到高阶的分阶段训练任务

第 1～2 周：剪映基础

只练三件事：分割、删除、移动。

  • 用同一组 10 个镜头，剪出 3 个 15 秒版本。
  • 只改“保留哪几个镜头、顺序怎么变”。
  • 目标不是好看，是手熟。

第 3～4 周：节奏与结构

  • 选一条你喜欢的 30 秒短视频。
  • 逐镜头记录每个镜头的时长。
  • 用自己的素材模仿它的节奏剪一条。
  • 这是提升最快的一步。

第 5～6 周：即梦生成

  • 先用文生图批量出图。
  • 筛选出 3～5 张可用图。
  • 再分别做图生视频。
  • 每个生成片段在剪映里只保留 1～3 秒最稳的部分，不要整段使用。

第 7～8 周：混合出片

完成一条：

“即梦生成镜头 + 剪映剪辑 + AI 配音/字幕”的 30～40 秒讲解或情绪短片。

这才是 AI 创作的真实工作流。

第 9 周起：稳定输出

  • 每周 2～3 条。
  • 每条做完必须做一次 8 项自查：
    • 主题明确？
    • 开头抓人？
    • 有空镜废段？
    • 节奏顺？
    • 字幕清楚？
    • 配乐合适？
    • 画面干净？
    • 导出正常？

3.3 三个防止“永远在准备、从未出片”的规则

规则一：第一个作品允许“不完整”

先做完一条 15 秒的，再谈优化。完成比完美优先。

规则二：一次只改一个维度

今天这条只调字幕，下一条只调节奏，再下一条只调声音。
同时改五个地方，你无法判断哪个改动起了作用。

规则三：即梦用来“补镜头”，不用来“替大脑”

脚本结构、节奏判断、什么该留什么该删，仍然由你决定。
AI 提高的是素材获取速度，不是替代叙事判断。

3.4 作品复盘清单：每做完一个作品必须做

  • 这条视频的主题是否明确？
  • 开头是否抓住注意力？
  • 是否有明显“空白镜头”？
  • 节奏是否自然？
  • 字幕是否清晰？
  • 配乐是否适合？
  • 画面是否有杂质？
  • 导出是否达到预期？

复盘不是“查错”，而是“提升作品的逻辑和审美”。

D. 最终总结

剪映和即梦不是两个独立的世界，而是：

传统剪辑 + AI 创作的组合工具。

最好的学习方式：

  1. 学会剪映基础。
  2. 学会短视频表达与节奏。
  3. 学会 AI 生成与人工修正。
  4. 持续输出作品并复盘。

如果按照本手册持续练习，通常可以达到：

  • 能熟练使用剪映基础功能。
  • 能剪出结构清晰、节奏自然的视频。
  • 能使用即梦进行快速创作。
  • 能提高知识输出效率。
  • 能逐步形成自己的剪辑风格与视频表达方式。

先做小作品，先抓重点，再慢慢完善。
把工具当成手段，最终目的是“讲清楚内容”。
