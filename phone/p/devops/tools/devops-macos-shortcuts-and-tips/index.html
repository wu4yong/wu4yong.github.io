macOS 快捷键与常用技巧指南

Mac 上手的第一道坎不是”找软件在哪”，而是”手指该放哪”。Windows 那套肌肉记忆搬过来，一半失效、一半改名：复制粘贴的 Ctrl 变成 ⌘，任务管理器变成活动监视器，右键菜单要按两根手指。这一篇把 macOS 的快捷键、终端命令和日常技巧按场景捋成一张表，抄下来贴在副屏上练几天就能脱手。

macOS 快捷键与常用技巧：修饰键、访达、终端、截图四组入口

1.1 通俗小故事：四把钥匙，一把主角

Mac 的快捷键就是四把钥匙的组合，记住”谁当主角”就够用。

● ⌘ Command：主命令键，Windows 里 Ctrl 的位置（复制、粘贴、保存、查找）
● ⌥ Option：次要修饰，负责”另一个维度”（按词跳、扩展选区、打开隐藏项）
● ⌃ Control：系统层修饰，接管调度中心、输入法、锁屏这类全局动作
● ⇧ Shift：方向键，表示”反向、扩大、连选”

真正别扭的是少数几个反直觉映射：Windows 的 Ctrl+C 在终端里不是复制而是中断进程，要复制得用 ⌘C；⌘Q 退出应用、⌘W 只关窗口；⌘⌫ 才是删除文件，delete 键在 Mac 上叫退格。

装环境的标准动作，一行一行抄：

# 1. 装 Homebrew（国内网络建议先配镜像，否则会很慢）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 常用工具
brew install git wget jq ripgrep fd tree htop
brew install --cask iterm2 visual-studio-code docker

# 3. 确认 shell 与路径
echo $SHELL            # 新版 macOS 默认 /bin/zsh
brew --prefix          # 记下路径，写进 .zshrc

.zshrc 里加几条就够用很久：

# 历史命令补全与常用别名
autoload -Uz up-line-or-beginning-search
zle -N up-line-or-beginning-search
bindkey '^[[A' up-line-or-beginning-search

alias ll='ls -alF'
alias gs='git status -sb'
alias gp='git push'
alias dps='docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"'

# Homebrew 路径
export PATH="/opt/homebrew/bin:$PATH"   # Apple Silicon
# export PATH="/usr/local/bin:$PATH"    # Intel 机型

窗口管理是 Mac 的老大难：系统原生只支持全屏与左右半屏（macOS 10.15 起拖到屏幕边缘即可分屏），要四分之一屏、三列布局就得靠 Rectangle、Magnet 这类工具，装一个能省掉大量手动拖拽。

1.10 排障速查

  • 应用无响应：⌥⌘⎋ 强制退出，别长按电源键
  • 风扇狂转、发热：打开活动监视器按 CPU 排序，先找占用最高的进程
  • 蓝牙/Wi-Fi 抽风：先关开一次；仍不行再重置网络（系统设置 → 网络 → 过滤器/位置）
  • 键鼠、电源异常：Intel 机型可重置 SMC（关机后按 ⇧⌃⌥ + 电源 10 秒）；Apple Silicon 关机等 30 秒再开机即可
  • 开机异常、扬声器无声：重置 NVRAM（Intel：开机按 ⌥⌘PR 约 20 秒）
  • 系统起不来：进恢复模式（Intel ⌘R，Apple Silicon 长按电源），先用磁盘工具急救
  • 权限诡异（终端 Operation not permitted）：多半是 SIP 或”完全磁盘访问”没给权限，去 隐私与安全性 → 完全磁盘访问 里勾选终端

1.11 清单

  1. 先记四个修饰键的分工，再背具体组合，比死记快捷键表快
  2. ⌘Space、⌃↑、⇧⌘4、⌘⇧G 这四个是每天都会用到的骨架
  3. 终端里 Ctrl+C 是中断进程，复制要用 ⌘C
  4. 装 Homebrew 之后，Mac 的命令行体验才真正接近 Linux
  5. 截图想直接贴进文档，用 ⌃⇧⌘4 走剪贴板
  6. 窗口分屏系统原生只给半屏，四分之一屏要靠第三方工具
  7. 换机前先插上 Time Machine 硬盘跑一次完整备份，再动迁移助理
