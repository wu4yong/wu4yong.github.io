IDEA 快捷键 Windows 全表

Windows 上的 IDEA 默认键位以 Ctrl 为主、Alt 补位。真正高频的只有二十来个，其余是”用到时能查”。这一篇按功能分组把 Windows 的默认键位列全，并与 macOS 篇一一对应，换机器不用重新学。

Windows 三个修饰键的分工：Ctrl 主命令、Alt 备用修饰、Shift 方向扩展

2.1 通俗小故事：三把钥匙

Windows 的快捷键是三把钥匙的组合。
● Ctrl 是主键，复制、查找、提交、编译都从它开始
● Alt 是副键，管”另一个维度”：多光标、参数、生成、跳到光标
● Shift 是方向盘，配合方向键表示”扩大、反向、多选”

和 macOS 相比少一把 ⌘，多的那把是 Ctrl——所以从 Windows 转 macOS 会觉得”键位全挪了一格”，但组合的逻辑没变。

2.14 练习清单

  1. 第一周只练：Alt+Enter、Ctrl+D、Ctrl+Y、Ctrl+E、Ctrl+B
  2. 第二周加编辑：Ctrl+Alt+L、Ctrl+Alt+O、Ctrl+/、Ctrl+W
  3. 第三周加导航：Ctrl+N、Ctrl+Shift+N、Ctrl+F12、Alt+F7
  4. 第四周加重构与调试：Shift+F6、Ctrl+Alt+M、Alt+F8、Alt+F9
  5. 提交前固定 Ctrl+Alt+L → Ctrl+Alt+O → Ctrl+K
  6. 换 macOS 时对照本系列上一章，把 Ctrl 换 ⌘、Alt 换 ⌥ 即可，注意格式化与优化导入那位是错位的
