IDEA 快捷键 macOS 全表

macOS 上的快捷键不是把 Windows 的 Ctrl 换成 ⌘ 就完事，有几处映射是”天然错位”的：格式化从 Ctrl+Alt+L 变成 ⌥⌘L，优化导入从 Ctrl+Alt+O 变成 ⌃⌥O，文档从 Ctrl+Q 变成 F1。这一篇按功能分类把 macOS 的默认键位列全，照着练一周就能脱手。

macOS 四个修饰键的分工：⌘ 命令、⌥ 选项、⌃ 控制、⇧ 上移

1.1 通俗小故事：四把钥匙

macOS 的快捷键是四把钥匙的组合。
● ⌘ Command：命令键，多数主操作的起点（复制、查找、提交）
● ⌥ Option：次要修饰，多用于”另一个维度”（参数、多光标、扩展选区）
● ⌃ Control：系统层修饰，IDEA 里常与窗口、文档、优化导入搭配
● ⇧ Shift：方向键，表示”反向、扩大、多选”

同一个功能在 Windows 与 macOS 上用的钥匙数量一样，只是起点不同。记住”谁当主角”就够：Windows 以 Ctrl 为主，macOS 以 ⌘ 为主，⌥ 补位。

1.14 练习清单

  1. 先只练五个：⌥Enter、⌘D、⌘⌫、⌘E、⌘B
  2. 第二周加编辑组：⌥⌘L、⌃⌥O、⌘/、⌥↑
  3. 第三周加导航组：⌘O、⌥⌘O、⌘F12、⌥F7
  4. 重构只用 ⇧F6，等肌肉记住再加 ⌥⌘M
  5. 调试记住 ⌥F8 + ⌥F9，别只会 F8 单步
  6. 提交前固定 ⌥⌘L → ⌃⌥O → ⌘K
