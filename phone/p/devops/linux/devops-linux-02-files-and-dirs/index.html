文件与目录操作

运维一天里最高频的动作是找文件、看文件、删文件。看起来简单，出事也最多：rm -rf 少一个空格就把生产目录带走，> 写错就把配置清空。这一章只讲”稳”。

路径、目录、软链接与文件详情的关系

2.1 通俗小故事：仓库货架

文件系统是一座仓库。
● 路径是货架编号，/ 是仓库大门，/var/log 三号货架第六层
● 目录是货架上的格子，文件是格子里的箱子
● . 是当前这一格，.. 是上一层货架
● 软链接是”便签纸，写着另一个货架号”；硬链接是”同一只箱子挂两个编号牌”

理解这四句话，cd ../..、ls -a、ln -s 就不用背了。

2.2 看清当前位置与内容

pwd                          # 现在在哪
cd /var/log && pwd           # 进目录并确认
cd -                         # 回到上一个目录（很实用）
ls                           # 列表
ls -lh                       # 大小人类可读、带权限与属主
ls -lht                      # 按修改时间倒序
ls -la --time-style=full-iso # 含隐藏文件与精确时间
ls -li                       # 带 inode，排查硬链接

通配符与花括号展开：

ls *.log                     # 当前目录的 log 文件
ls /var/log/nginx/*.log
cp config.yml{,.bak}         # 等同于 cp config.yml config.yml.bak
mkdir -p /data/app/{logs,conf,tmp}

{,.bak} 这个写法是最常用的备份技巧，比手敲两遍文件名可靠。

2.3 复制、移动、删除

cp -a src/ dst/              # 保留权限、时间、链接（归档式复制）
cp -r src/ dst/              # 递归复制
cp -av src/ dst/             # 边复制边看，长任务心里有数
mv file1 /data/              # 移动（同分区是改名，瞬间完成）
rm file                      # 删文件
rm -rf dir/                  # 递归强删（高危）

删除的安全习惯：
● 先 ls 把目标打一遍，确认路径拼对了
● 用绝对路径，不在 /、/var、/etc 这类目录里用 rm -rf *
● 批量删除前先 find ... -print 试跑，把 -print 换成 -delete 才是执行
● rm 之后没有回收站，重要目录先 tar 一份

find /data/old -name "*.tmp" -mtime +7 -print    # 先看
find /data/old -name "*.tmp" -mtime +7 -delete   # 再删

2.4 看文件内容

cat file                     # 看小文件
less file                    # 大文件分页，/ 搜索，q 退出
head -n 20 file              # 前 20 行
tail -n 20 file              # 后 20 行
tail -f app.log              # 跟踪追加内容（排障最常用）
tail -F app.log              # 文件被切割/重建也能跟住
nl file | sed -n '100,120p'  # 带行号看指定区间
wc -l file                   # 行数
file bin                     # 判断文件真实类型

tail -f 与 tail -F 的差别值得记：日志按天轮转时 -f 会跟丢（inode 变了），-F 会重开文件继续跟。

2.5 找文件：find 与 locate

find / -name "*.conf" 2>/dev/null                    # 全盘找，屏蔽报错
find /data -type f -size +500M                        # 大于 500M 的文件
find /var/log -type f -mtime -1                       # 一天内改过的
find /data -type f -newermt "2018-05-01"              # 某时间之后
find /data -name "*.log" -exec grep -l "ERROR" {} \;   # 找内容
find /data -type d -empty                             # 空目录
find . -maxdepth 2 -name "*.yml"                      # 限制深度，更快

2>/dev/null 很关键：find / 会撞上一堆权限不足的目录，把报错屏蔽掉才看得清结果。

2.6 链接：软与硬

ln -s /data/releases/2026-11-25 /data/current   # 软链接，类似快捷方式
ln /data/a.txt /data/b.txt                      # 硬链接，同一 inode 两个名字
ls -li /data/a.txt /data/b.txt                  # inode 相同才是硬链接

● 软链接可以跨分区、可以指向目录；源被删后链接变成”红字断链”
● 硬链接不能跨分区、不能链目录；删掉任一个名字，数据仍在
● 发布切换用软链：新版本目录建好，ln -sfn 换 current 指向，一条命令回滚

2.7 打包与压缩

tar -czf app-2018-05-05.tar.gz /data/app            # gzip 打包
tar -xzf app.tar.gz -C /data/releases/              # 解到指定目录
tar -tzf app.tar.gz | head                          # 只看内容不解
tar -czf backup.tar.gz --exclude=logs --exclude=tmp /data/app
zip -r app.zip dir/                                 # zip 跨平台友好
unzip -l app.zip                                    # 列表

打包前先估体积：du -sh /data/app，别让 /tmp 被一个 40G 的 tar 撑爆。

2.8 清单

  1. 先 pwd 再动手，路径用绝对路径
  2. 复制保留属性用 cp -a，批量删除先 -print 后 -delete
  3. 跟日志用 tail -F，看大文件用 less
  4. 找文件用 find，加 2>/dev/null 与 -maxdepth
  5. 发布用软链接切换，回滚只改指向
  6. 打包前 du -sh 估体积，tar 排除日志目录
