Linux 介绍与安装

服务器上跑的 Docker、Nginx、MySQL、Kubernetes，底下都是同一层东西：Linux。它是内核，也是”一切皆文件”的操作约定。运维的日常九成时间在跟文件、进程、网络、权限打交道，而这些动作全都落在几条命令上。

从根目录展开的 Linux 目录树

1.1 通俗小故事：钥匙串

机房是一栋楼，服务器是房间，Linux 是你进房间时用的那把钥匙串。
● 内核（kernel）是楼里的水电系统，负责调度 CPU、内存、磁盘、网卡
● Shell 是门口的传达室大爷，你说话他办事，办完把结果递回来
● 发行版是装修公司，把内核 + 一堆工具 + 包管理器打包成 Ubuntu / CentOS / Debian
● 一切皆文件，网卡、硬盘、进程、设备都挂在 /dev、/proc、/sys 上

理解”内核做事、shell 传话、发行版配菜”，后面所有命令就有了位置。

1.2 选哪个发行版

● Ubuntu LTS（20.04 / 22.04 / 24.04）：生态最新，apt 包全，云主机默认，适合新手与互联网业务
● Debian：稳定到极致，包偏旧，适合长期不折腾的基础设施
● Rocky / AlmaLinux：接替 CentOS 的 RHEL 兼容发行版，企业内网常用，dnf 管理
● Alpine：几十 MB，容器基础镜像首选，但 musl libc 会让部分二进制编译踩坑

选一个长期支持（LTS）版本，别追最新。生产环境的版本选择标准是”有安全更新、有社区、有文档”，不是”版本号大”。

1.3 装一台练手环境

三种方式按成本排序：

# 1. Windows：WSL2，最省事
wsl --install -d Ubuntu-22.04

# 2. 虚拟机：VMware / VirtualBox 装 ISO
#    内存 2G、磁盘 20G、网络 NAT 即可

# 3. 云主机：1 核 2G 最便宜的按量实例
ssh root@<公网IP>

安装时几个关键选项：
● 分区用默认的 ext4 + /，练习不需要 LVM
● 创建普通用户并加入 sudo 组，不要习惯性全用 root
● 只装 OpenSSH Server，其余组件后续按需装

1.4 首次登录的三条自检

cat /etc/os-release          # 发行版与版本
uname -r                     # 内核版本
whoami && id                 # 当前用户与所属组

再补两条环境信息：

df -h                        # 磁盘挂载与剩余
free -h                      # 内存与 swap

这五条命令合起来就是一台机器的”身份证”，任何工单、报障、贴日志之前先跑一遍，信息量比描述十句都大。

1.5 目录结构与 FHS

Linux 的文件系统有一份约定（FHS），记住主干就够了：

目录
放什么
/
根，所有路径的起点
/etc
配置文件，几乎全部在这里
/var
变化的数据：日志、缓存、数据库文件
/usr
程序与库（/usr/bin、/usr/lib）
/home
普通用户的家目录
/root
root 的家目录
/tmp
临时文件，重启可能被清
/proc、/sys
内核暴露的运行时信息，不是真文件
/dev
设备文件
/opt
第三方独立软件

排障时的直觉很重要：配置在 /etc、日志在 /var/log、程序在 /usr/bin、数据在 /var/lib 或自定义数据盘。

1.6 关机、重启与运行级别

shutdown -h now              # 立即关机
shutdown -r +5 "5分钟后重启"  # 定时重启并广播
reboot                       # 重启
systemctl reboot             # systemd 方式
systemctl poweroff

生产机器上别直接 reboot：先确认业务已切走、who 看有没有人在线、systemctl list-jobs 看有没有卡住的任务。容器化环境更要注意，重启宿主机等于所有容器一起停。

1.7 上手清单

  1. 选 LTS 发行版，装一台能 SSH 的练手机器
  2. 会跑五条自检：os-release、uname -r、id、df -h、free -h
  3. 记住 FHS 主干：/etc 配置、/var 数据、/usr 程序、/proc 运行时
  4. 养成普通用户 + sudo 的习惯，不长期用 root
  5. 关机重启前先确认业务与在线用户
