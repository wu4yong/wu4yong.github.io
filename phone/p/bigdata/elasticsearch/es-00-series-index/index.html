总目录

一句话定位

全部内容以 Elastic 官方文档（Elasticsearch Guide 8.17）为唯一权威来源，
凡是定义、默认值、限制、边界条件，都以官方原文为准；
凡是我自己给的工程判断，一律标注「工程结论（非官方原文）」，两者不混着说。

八条编写规则：

  1. 每节只解决一个知识点，不把多个强独立技术点塞进一篇；
  2. 每节结构固定：学习目标 → 前置知识 → 理论讲解（官方定义）→ 原理拆解 → 场景说明 → 实操 → 常见坑 → 课后小结 → 思考题；
  3. 官方有明确数值的地方（默认 1s 刷新、max_result_window 10000、堆上限等）一律给数值，不给「大概」「差不多」；
  4. 官方写了警告的地方（动态映射、强制刷新、bootstrap checks），照原文保留，不做「简化理解」；
  5. 章节之间有硬依赖，标注了「前置」，没读完前置不要跳；
  6. 章节末尾有官方链接，争议处回原文核对；
  7. 图只做辅助，图里信息不得与官方规范冲突，示意图会标注「非官方原图」；
  8. 版本基准统一为 8.17（当前官方文档版本）。7.x 与 8.x 的差异（types 取消、默认开启安全）单独标注。
