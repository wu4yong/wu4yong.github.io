    Axios 软件包被入侵；恶意版本包含木马依赖

    Axios 是一个每周下载量超过 1 亿的 HTTP 库，这主要得益于其历史积累的广泛使用。一名攻击者利用这一点推出了一个包含恶意依赖的版本，其中包含远程访问木马（尽管 Axios 代码库本身没有问题）。这事关重大，因为即使你不在项目中直接使用 Axios，你的依赖项可能使用了它。以下是如何检查你是否受到影响。

    Ashish Kurmi
