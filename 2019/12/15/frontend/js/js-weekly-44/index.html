    Turbopack 如何分块打包你的 JavaScript

    从 Network 面板入手、层层向上，审视分块策略，以及打包器在更少请求与更少代码之间所做的权衡（例如 8 个 chunk 可能比 355 个更重），并以打包 Next.js 官网本身的数据为佐证。

    Sam Poder

    在你的 JS PR 合并前捕获运行时 Bug

    Greptile 现在会运行你的代码来查找 Bug。T-Rex 在沙箱中运行你的 PR 分支，使用浏览器智能体点遍你的 UI，并将截图和视频作为问题证据直接附在 PR 中。

    Greptile 赞助

    Vitest 5.0 聚焦速度与测试调试

    这个 Vite 原生测试运行器迎来重大版本，其基准测试仓库显示，在依赖繁重的应用上运行速度最高提升 53%。新的 Trace View 可以逐步回放浏览器模式下的测试，vitest doctor 则会推荐一些设置，让你的测试套件跑得更快。

    Vitest 团队

    Safari 如何修复顶层 await

    Safari 的模块加载器最初构建在一个已被放弃的规范提案之上，加入顶层 await 后引发了持续数年的 “cannot access before initialization” 错误。Safari 27 让它完全符合规范，但这需要一次彻底重写，本文解释了其中的复杂性。

    Kai Tamkun (WebKit)

    简讯

    • 🎂 jQuery 1.0 已经 20 岁了。InfoQ 回顾了 $() 如何帮助我们避开浏览器大战，以及为什么许多网站仍在使用它。再往前十年，微软为了规避商标问题，以 JScript 的名义在 Internet Explorer 中发布了 JavaScript。

    • 两名男子因 TeamPCP npm 供应链攻击被捕。TeamPCP 被怀疑克隆了 Shai-Hulud 蠕虫，从而引发了 “Mini Shai-Hulud” 攻击浪潮。

    • VoidZero 的最新进展庆祝 Vitest 周下载量突破 1 亿、React Compiler 支持进入 Vite，以及 Rolldown、Vite+ 和 ViteConf 的最新消息（后者将于今年 10 月 15 日在线举行）。

    版本发布

    • deck.gl 9.4 – 这个 GPU 驱动的数据可视化库扩展了实验性的 WebGPU 支持，预计这将是 v9 系列的最后一个版本。
    • Bun 1.4.1 和 1.4.2 – 大幅降低空闲内存占用，bun build 产物体积更小，Bun.serve 可在同一端口上同时支持 HTTP/2 与 HTTP/1.1，等等。
    • NVM for Windows 2.0 – Windows 上的 Node 版本管理器。v2 不再需要管理员权限。
    • Astro 7.3、ESLint 10.10.0、Storybook 10.6、Vuetify 4.2

    Gábor Koós

    Dropzone.js 6.x：拖拽上传库回归

    Mat Simon

    Rslib 1.0：用于发布 JavaScript 库的构建工具

    来自 Rspack 团队的统一构建流水线，处理发布软件包时那些令人头疼的部分，比如让 ESM 和 CJS 并存、输出 Module Federation，以及跨 React、Vue、Svelte 和 Solid 的组件 CSS。

    vgpu：在浏览器或 Node.js 中渲染 WebGPU 着色器

    提供了一种方式，让同一份着色器既能在浏览器中使用，也能通过 Node 无头渲染（输出高分辨率 PNG 或 MP4 视频）。WGSL 模块可以像 TypeScript 那样导入和导出。

    Vercel

    SimpleWebAuthn 14.0：现已支持后量子 Passkey

    这个 passkey 库现在可以验证后量子 ML-DSA passkey，并且在 Node 24.7 及以上版本中，注册时默认优先使用 ML-DSA-44。
