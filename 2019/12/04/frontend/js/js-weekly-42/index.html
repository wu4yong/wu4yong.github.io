    与 Webflow 联合推出

    Bun 1.4：Node.js 兼容性前所未有地强

    在最初预期的发布时间过去数周后，Bun 从 Zig 到 Rust 的大规模 AI 驱动重写终于到来，还配上了传统的▶️ 发布视频。团队在兼容性上投入了大量精力，不仅针对 Node，还包括 Next.js、Playwright、Vitest 和 Nuxt。吞吐量以及 CPU/内存占用也有巨大改善。

    Bun 团队

    ☕ 如果你打算读完这篇发布文章，请先准备尽可能大的一杯咖啡。这很可能是我运营这份通讯十五年来见过的最长的一篇。

    Webflow for Developers

    大多数工具迫使你在可视化构建器和真实代码之间二选一。Webflow 让你两者兼得：提供 API、SDK、代码组件（Code Components）和用于部署自定义应用的 Webflow Cloud，另外还有可用于配合智能体构建的 MCP server。

    Webflow 赞助

    面向 JavaScript 开发者的乐理

    一场从第一性原理出发的乐理之旅：用简单的算术推导出十二个音、音阶、和弦与和弦进行，全程配有可运行的 Web Audio 示例。

    Luke Haas

    Solid 2.0 RC：大揭晓（The Big <Reveal>）

    异步现在被纳入响应式图（reactive graph）之中，因此异步数据可以流经普通的 memo。createResource、batch 和 startTransition 已被移除。SolidStart 被并入 Vite 插件上的 start: true 标志，API 现已冻结。

    Ryan Carniato

    简讯

    • Aurora Scharff 展示了 Next.js 16.3 如何帮助开发者构建“类应用”体验。

    • Aviv Keller 带来了 Node.js Interactive 2026 的全面回顾，该活动两周前在亚特兰大举行。

    • 🤖 TanStack AI 已进入 RC 阶段，文章回顾了迄今为止的历程及其主要功能集。

    • Oxlint 新增了对 React Compiler 的支持。

    版本发布

    • Electron 44 – 尚无发布文章，但它已放弃 32 位支持，要求 macOS 13+，clipboard 现在与 W3C Clipboard API 对齐，并新增了 net.WebSocket 以及在 Linux 上设置窗口透明度的能力。

    • Waku 1.0 RC – 极简的 RSC 优先 React 框架，现已在 v1 正式版发布前冻结 API，新增能在编译期捕获错误路由的类型安全导航，以及基于缓存路由外壳的实验性即时渲染（instant paints）。

    • SvelteKit 3 候选发布版、React Native 0.87、ESLint 10.9（以及 10.9.1）、Axios 1.20.0、pnpm 11.23

    移除代码为何胜过更好的调度

    很多性能工作都花在调整资源的加载时机上，而更大的收益通常来自根本不发送这些代码。Alex Russell 论证说，这与其说是技术问题，不如说是管理问题。

    Alex Russell

    ESM 与 CommonJS：import 和 require 究竟做了什么

    它们看起来是同一种操作，但 Gabor 展示了 ESM 的 import 始终连接到导出方的绑定，而解构后的 require() 只持有一份副本。其后果会在循环依赖和已发布的包中显现。

    Gabor Koos

    🛠 代码与工具

    MicroLighter：一个不碰 DOM 的 2KB 语法高亮器

    一个小巧的客户端语法高亮器，利用了 CSS Custom Highlights API。零依赖，并提供浅色和深色主题。主页上有一些在线演示。

    Dave Rupert

    TermDOM：用 HTML、CSS 和 DOM 构建终端 UI

    一个真实的 DOM 与布局引擎，可将内容绘制到终端，因此你可以用原生 JS（或任意框架）和 HTML 编写 TUI（而不像 Ink 那样只能用 React）。本周的 v0.1.5 版本新增了 CSS grid 支持。

    Brian Kim

    无需第二套系统，在 Drizzle 中实现全文搜索

    试试 Drizzle 的官方 ParadeDB 集成。直接在实时的 Postgres 表上搜索。无需 ETL，无需 Elasticsearch 集群。

    ParadeDB 赞助

    Formisch 1.0：框架无关、基于 Schema 的表单库

    一个无头表单库，由 Valibot schema 驱动类型与校验，覆盖八种框架。v1 新增了 Angular 和 React Native 支持，为 TanStack Form/React Hook Form/Formik 用户提供了迁移指南，还为智能体提供了 Markdown 文档。

    Formisch 团队

    Stryker Mutator 10.0：用变异测试来检验你的测试

    Stryker 会对你的代码做出细小而刻意的改动，并检查你的测试套件能否捕获它们。如果捕获不到，说明你的测试可能过于宽松，需要改进。这里是入门指南。

    Jansen、de Lang 等
