    Bun v1.3.10 发布：一个出人意料的大更新

    Bun 的 REPL 已完全重写，带来了许多改进（实用和外观兼具），新增了 --compile --target=browser 选项，用于构建包含所有 JS、CSS 和资源的自包含 HTML 文件（非常适合简单的 JS 驱动单页应用），完整支持 TC39 阶段 3 的 ES 装饰器，更快的事件循环，barrel import 优化等等。

    Jarred Sumner

    还在手动编写测试？Meticulous AI 来了

    Notion、Dropbox、Wiz 和 LaunchDarkly 现在使用着一种他们离不开的测试范式。Meticulous 由前 Palantir 工程师构建，能够自动创建持续演进的 E2E UI 测试套件，以零开发者投入提供详尽覆盖率。

    Meticulous 赞助

    外部 Import Map，就在今天！

    几周前，Lea 发表了一篇关于 Web 依赖管理存在问题的文章，现在她有了解决方案。用于模拟外部 import map 支持的核心技术虽然简单但不太显而易见，不过已经由 JSPM 4.0 提供支持。

    Lea Verou

    • React 基金会已正式成立，接管了 React、React Native 和 JSX 的所有权。基金会设有八位创始成员组成的董事会（包括 Meta），由 Meta 前 React 负责人 Seth Webster 担任执行董事。

    • 虽然尚未正式确定，但这篇预览文章揭示了 Node.js 发布计划将如何在今年晚些时候进行调整（每年一个主要版本，每个版本都是 LTS，不再区分奇偶版本号）。

    • 📢 Svelte、ViteLand / VoidZero 和 Astro 的月度回顾已发布。

    • 🔒 Angular 团队解释了 Angular 中最近修复的两个漏洞。

    • Navigation API 现已在所有主流浏览器中达到 Baseline Newly Available 状态。
