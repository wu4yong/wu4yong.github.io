    还在手动编写测试吗?

    Notion、Dropbox、Wiz 和 LaunchDarkly 已经找到了一种新的测试范式——他们无法想象没有它的工作。由前 Palantir 工程师打造,Meticulous 自主创建一个持续演进的端到端 UI 测试套件,无需开发人员付出任何努力即可提供近乎详尽的覆盖率。
