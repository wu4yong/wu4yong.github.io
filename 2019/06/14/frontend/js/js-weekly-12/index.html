    📰 头条新闻

    jQuery 4.0 正式发布

    距离最初发布已经 20 年，这个依然广受欢迎（从实际使用情况来看）的库迎来了 4.0 版本。新版本迁移到 ES 模块（兼容现代构建工具），同时放弃了对 IE 10 及更早版本的支持。jQuery 在我们早期的周刊中是常客，很高兴看到它再次回归。

    💡 如果你正在使用 jQuery，你会发现 jQuery Migrate 这个官方工具对升级很有帮助。不过在 2026 年，jQuery 在某种程度上已经是一个传统选择，而且你可能根本不需要 jQuery。

    Astro 加入 Cloudflare

    Web 框架领域的重大新闻——流行的 Astro 框架（v6.0 的 beta 版本现已推出）背后的团队正在加入 Cloudflare。现在几乎所有主流框架都在大公司的羽翼之下了。

    📦 赞助商

    为你的 JavaScript 应用添加类似 Excel 的电子表格功能

    SpreadJS 是业界领先的 JavaScript 电子表格组件，可为企业应用添加高级电子表格功能。构建财务、分析、预算等应用。支持 Excel I/O、500+ 计算函数、表格、图表等。立即查看演示。

    • 🕒 Temporal Playground 是一个用于体验 Temporal API 的在线沙盒

    • 🤖 Node.js 和 Deno 的创建者 Ryan Dahl 在 X 上表示：”人类编写代码的时代已经结束“，并且”这并不是说软件工程师没有工作可做，但直接编写语法已经不是重点了“。我希望不是这样，但这确实是一个有趣的时代！

    ASCII 字符不是像素：深入探讨 ASCII 渲染

    Alex 深入研究了如何使用 JavaScript 正确渲染基于 ASCII 的图形，包含所使用算法的示例和大量演示。这是我今年看到的技术上最精彩的博客文章。

    JavaScript 现在是 Aspire 中的一等公民

    Aspire 是微软用于编排分布式应用部署的框架。最初只支持 .NET，Aspire 13 现在让 JavaScript 成为一等公民，因此你可以运行 Vite 和全栈 JS 应用，并具备服务发现、遥测和生产就绪的容器。

    断点和 console.log 已成过去，时间旅行才是未来

    比使用断点和 console.log 快 15 倍的 JavaScript 调试，支持 Vitest、jest、Karma、Jasmine 等。

    介绍 <geolocation> 元素

    Chrome 144 引入了一个新的 <geolocation> 元素用于请求用户位置数据，摆脱了 JavaScript 触发的提示方式。

    🛠 代码和工具

    Starry Night 3.9：类似 GitHub 的语法高亮

    GitHub 自己的语法高亮器不是开源的，但这个库是一个强大的替代方案，尽可能接近 GitHub 的效果，支持数百种语言。我创建了一个基础的 Web 演示来展示如何在 Web 上使用它。

    Extension.js 3：浏览器扩展开发框架

    创建跨浏览器扩展，无需手动构建配置，通过统一的工作流程在各个浏览器中开发、构建和预览。GitHub 仓库。

    轻松为你的 Web 应用添加图像编辑功能

    导入 pintura，提供一张图片，立即获得裁剪、旋转和注释等功能。立即免费试用。

    React Aria：Adobe 的世界级 React 组件

    React Aria 拥有一个出色的新网站和全新的文档，真正展示了整个体验，包含交互式 CSS 和 Tailwind 示例，让你快速上手。

    localspace：现代 localForage 兼容存储工具包

    localForage 是/曾是一个流行的存储库，它用简单的、类似 localStorage 的 API 封装了各种浏览器存储 API。不过它已经多年没有更新了，“localspace 的存在就是为了填补这个空白”。
