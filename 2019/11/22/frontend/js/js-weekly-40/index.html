    与 Master.dev 联合推出

    Next.js 16.3 发布

    新近扩充的 Next.js 团队（现在包括 Dan Abramov 和 Pete Hunt！）发布了这款流行 React 框架的最新版本，带来更快的构建、可选的 TypeScript 7 类型检查、更快的 SSR、Instant Navigations、AI 改进 等。

    Next.js 团队

    前端架构：从单体到微前端

    Maxi Ferreira 带你走查模块化单体、monorepo 和微前端方案，帮助你为代码库选择正确的结构，并在做出决定前了解真正的成本。

    Master.dev 赞助

    来做一个史上最糟糕的 htmx

    在做出“最糟糕”的 React 和 Vue.js 实现之后，Serge 这次从零开始重建 htmx 的精髓。这是理解 htmx 底层究竟在做什么的一种有趣方式。

    Serge Zaitsev

    2026 年安全发布 npm 包的方法

    一份更安全地发布 npm 包的实用指南，由众多流行包（如 postcss）的作者撰写。他不仅展示了如何使用分阶段发布（staged publishing）和可信发布（trusted publishing），还解释了为什么这些做法有帮助。

    Andrey Sitnik

    💡 GitHub 正持续聚焦 npm 安全，并开始在发布时扫描每个 npm 包以查找恶意软件。这会带来一些影响，包括发布与可供安装之间出现延迟。

    简讯

    • 🚨 事件仍在发展： 流行的 keyv 和 cacheable 包今天遭到一个窃取凭证的蠕虫入侵。影响仍在持续，目前已有数百个包受到波及。
    • Astro 团队和 Svelte 团队发布月度更新：前者见这里，后者见这里。SvelteKit 3 的首批预览版现已可用。
    • ⚖️ Deno 诉 Oracle 的 JavaScript™ 商标案仍在继续，随着取证推进，Deno 同意第五次延期请求。
    • 以高产 JS 库著称的 TanStack 已完成品牌焕新，并推出了新的 “Markdown” 和 “Highlight” 库。

    版本发布

    • MobX 7.0 – 这个流行的状态管理器瘦身了，移除了废弃项，更新了 React 绑定，现在始终使用由 Proxy 支持的 observable 对象和数组。
    • Javy 9.1 – 用于将 JavaScript 编译为 WebAssembly、供 WASM 运行时使用的工具链。
    • Node.js v26.6.0 (Current) 和 v24.19.0 (LTS)
    • Vite 8.2、React Three Fiber 9.7、Lerna 10.0、Hono 4.13.0

    Gabor Koos

    MicroDiff 1.6：快速的对象与数组比较库

    给定两个对象或数组，它返回差异（可以理解为针对 JS 对象的 diff）。本周发布的版本增加了对 Temporal 类型的支持。

    📊 Perspective 5：交互式分析与数据可视化组件

    最初由 JP Morgan 构建，是一个由 WASM 驱动的数据可视化组件，适合大型和/或实时流式数据集。5.0/5.1 刚刚发布，包含大量修复、wasm64 构建以及窗口列。

    OpenJS Foundation

    版本发布

    • Neutralinojs 6.9 – 这个轻量级 Electron 替代品新增了 C++ 网络 API，发起 HTTP 请求时不再受 webview 的 CORS 限制。
    • DukPy 0.6 – 面向 Python 的简单 JavaScript 解释器。现在使用 QuickJS-NG 引擎，以支持更多现代 JavaScript 特性和 Promise。
    • isomorphic-git 1.40.0 – 适用于 Node 和浏览器的纯 JS Git 实现。
    • better-result 3.0 – 面向 TypeScript 的轻量级 Result 类型，支持基于生成器的组合。
    • ip-address 10.4 – 解析、验证和操作 IP（v4 和 v6）地址。
