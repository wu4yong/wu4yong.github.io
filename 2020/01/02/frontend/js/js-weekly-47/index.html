    与 Meticulous 联合推出

    Anthropic 如何在两周内让 Claude 应用快 3 倍

    一次性能冲刺的经验杂烩：p75 的“可输入时间”从 3.1s 降到 0.55s。破折号（真是讽刺！）把 V8 推上了更慢的正则路径，一个多余的 location.reload() 每天造成 50 万次隐藏刷新，等等。

    Wang、Attard 和 G (Anthropic)

    还在写测试？Meticulous 来了

    Notion、Dropbox 和 Wiz 如今都在使用一套离开就没法发布的测试范式。Meticulous 由前 Palantir 工程师打造，会生成一套持续演进的确定性 E2E UI 测试，无需开发者投入即可实现详尽覆盖。

    Meticulous AI 赞助

    Vite+ 1.0：用一个 CLI 管理你的整个 JavaScript 工具链

    单个 vp 命令现在可以（如果你愿意）管理你的 Node 运行时、包管理器、开发服务器、lint、格式化、测试、构建和任务运行，全部通过 vite.config.ts 配置。vp migrate 可以把现有的 Vite、Vitest、ESLint、tsup 等配置迁移到 Vite+。

    VoidZero

    💡 Evan You 还回顾了 VoidZero 在 Cloudflare 的四个月，包括 Oxc React Compiler、Vitest 5、稳定的类型感知 lint 等方面的工作。

    简讯

    • 最新的 TC39 会议正在东京举行，已有三个 iterator 提案推进到 stage 4：chunking、join 和 includes（后者刚刚在 Chrome 154 中发布）。

    • Jarred Sumner 在 𝕏 上分享了 Bun 提前编译 JavaScript 的预览：Claude Code 启动快 24%、内存占用少 48%，但二进制体积约为 2 倍。

    • 🎉 Cloudflare 终于有了一个统一所有 API 的 CLI。cf 用 TypeScript 编写，覆盖全部功能，而 Wrangler 一直只覆盖其中一部分。

    • Angular 团队正在构建一个部分由 Rust 驱动的编译器，因为 TypeScript 7 的 Go 移植版缺少当前版本所依赖的 API。

    版本发布

    • MSW (Mock Service Worker) 3.0 – 这个流行的 API mock 库现在仅支持 ESM，新增 Vite 插件，支持 GraphQL 订阅，并能拦截页面导航和表单提交。
    • Vinext 1.0 – Cloudflare 基于 Vite 的 Next.js 重实现，现已支持 Pages 和 App Router，并为现有应用提供迁移路径。
    • Mermaid 12.0 – 这个图表工具现在对流程图、类图、状态图等默认使用 ELK 布局引擎，因此现有图表外观会发生变化，除非你设置 layout: dagre。还新增了 UML 用例图。
    • pnpm 12.8、Angular 22.2、TinyBase 10、QUnit 3.0

    Size Limit：JavaScript 性能预算工具

    为代码设定体积或加载时间预算，一旦变更超出预算，这个工具就能让 CI 失败（或在 PR 上标记）。你也可以做一次性检查，并查看字节都花在哪里的可视化。它与框架无关，也不在乎你用什么打包器或 CI。

    Andrey Sitnik

    你的 UI 背了慢查询的锅

    TimescaleDB 扩展了 Postgres，让你的 UI 背后的查询在数据增长时依然快速返回。立即获取 1000 美元额度开始使用。

    Tiger Data（TimescaleDB 的创造者）赞助

    EmDash 1.0：Cloudflare 的 WordPress “继任者”现已稳定

    Buscemi、Kane 和 Pham (Cloudflare)
