    与 Svix 联合推出

    tsrs：Cloudflare 与 VoidZero 打造的 TypeScript Rust 移植版

    这是一个将基于 Go 的 TypeScript 7 编译器移植到 Rust 的项目，构建过程中得到了 TypeScript 团队的一些意见，并将进入 Oxc。基准测试声称其速度最高可达 TypeScript 7.0 的 8 倍，而且可以运行在 WebAssembly 中。目前仍是实验性项目，但 npx tsrs 已经可用。

    Chen、Mitropoulos 与 Nakazawa（Cloudflare / VoidZero）

    💡 Max Schwenk 启动了这次移植，最初由 Agent 编写代码；他在这里讲述了完整故事，包括如何将公司的类型检查时间从 80 秒缩短到 7 秒。

    几分钟内从你的 TypeScript API 发送 Webhook

    一个带类型的 npm 包，每个事件只需一次调用。Svix 负责重试、签名、投递日志，以及面向客户的门户，你无需自行构建这些。Resend 每年通过它发送超过 2 亿个 Webhook。

    Svix 赞助

    谢谢你，Deno：竞争推动 JavaScript 不断前进

    上周我们报道了 Deno 加入 Cloudflare 以及 Deno 运行时的未来。Darcy 表示，Deno 很有价值，因为它（以及 Bun）推动 Node 和 npm 采纳其最佳创意，让整个生态变得更好。

    Darcy Clarke（vlt）

    简讯

    • 🔒 Next.js 已修复两个严重 RCE 漏洞：一个位于 use cache 函数中，源于上游 React Server Components 的 Bug；另一个位于图片优化器的 SVG 处理逻辑中。请升级到 16.4.1 或 15.5.28；公开 PoC 已经发布。

    • 🔒 Node.js 安全版本将于明天发布，覆盖 26.x、24.x 和 22.x 版本线，其中最高严重级别为“高”。

    • Bun 的 JavaScript 提前编译功能几周前已预览，现在又有一份 PR 草案，可生成不含 JIT 或字节码的二进制文件。

    版本发布

    • Node.js v26.12.0（Current） 和 v24.22.0（LTS） – 26.12 现在可以同步加载大多数 ES 模块，并将配置文件标记为稳定；24.22 新增了 util.throttle 和 util.debounce。

    • Astro 7.4 – 为 astro build 新增 --timings 参数，可查看构建时间花在哪里；此外还加入了跨 Worker 线程并行预渲染的实验性支持。

    • React Router 8.5 – 废弃自身的 View Transition API，改用 React 的 <ViewTransition> 组件，并新增实验性的“仅 API”模式。

    • Pretext 1.0 – 无需操作 DOM 的多行文本布局。1.0 移植了浏览器自身的换行算法，因此结果更接近实际渲染。

    • React Native 0.88、Elysia 2.0 RC、ESLint 10.13、tsup 9.0、Vuetify 4.3

    📊 Chartist 2.0：轻量级 SVG 图表库回归

    一个始于 2014 年、由 CSS 驱动样式的 SVG 图表库——曾“在过去几年逐渐停滞”——如今携组合式 API、服务端渲染为 SVG、终端图表等功能回归；折线图经 gzip 压缩后仍约为 12KB。1.x 用户可参考迁移指南。

    Gion Kunz 等

    Pele：将 Mermaid 图表渲染为轻量、可主题化的 SVG

    一个用于 Mermaid 图表语法的零依赖渲染器，支持响应式布局，并可通过 CSS 变量为 SVG 设置主题。体积约为 Mermaid.js 的六分之一。试试 Playground。

    Steph Ango（Obsidian）

    <rich-input>：带 GitHub 风格搜索过滤器的富输入框

    Bramus Van Damme

    版本发布

    • Chokidar 6.0 – JS 工具链背后广泛使用的文件监视器。现已重写为在报告变更前先核对磁盘，以避免例如连续编辑后出现误报事件。

    • Happy DOM 21.0 – 用纯 JavaScript 实现的无头浏览器环境，在测试中很受欢迎。现在默认阻止样式表和 iframe 加载。

    • p-queue 10.0 – 支持并发控制的 Promise 队列。现在零依赖，并且是一个 EventTarget。

    • Paper.js 0.13 和 0.14 – 面向 canvas 的矢量图形脚本框架。多年来首次值得关注的版本。（主页及示例。）

    • 🕹️ LittleJS 1.27 – 无依赖的 HTML5 游戏引擎，现在还支持 3D。

    • 🖼️ Skia Canvas 4.0 – 面向 Node 的 Canvas API，基于 Skia 构建。

    📢 生态系统其他动态

    • 🖼️ JPEG XL： 这种现代图片格式现已得到所有主流浏览器支持，最新默认启用它的是 Firefox 158。Jake Archibald 在这篇详尽评测中将其与 AVIF 对比。我觉得最惊人的是它能在不到 100 字节内渲染出什么。

    • NodeConf EU 2026： ▶️ 最新的 NodeConf EU 演讲已经上线，包括 James Snell 关于每个运行时都应支持的通用最小 API的论述，以及关于 V8 堆管理和 Emscripten 与 WebAssembly的演讲。

    • 一个新的社交网络： /dev/null 是一个面向 GitHub 用户的开发者社交网络，在 48 小时内从零构建。它已经有超过 8000 名成员，包括我。目前玩起来很有趣！
