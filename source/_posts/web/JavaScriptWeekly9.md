# JavaScript Weekly

## December 19, 2025

## JavaScript Weekly 2025 年终特刊

这是 2025 年的最后一期 JavaScript Weekly。编辑 Peter Cooper 宣布，从 2026 年 1 月开始，周刊将改为每周二发布（下一期是 2026 年 1 月 6 日）。本期先带来几条新内容，然后回顾 2025 年度 Top 10 热门链接，并按月份整理今年 JavaScript 生态中的重要事件。[在线阅读本期原文（英文）](https://javascriptweekly.com/link/178777/web)。

## JavaScript 打包工具大奖赛

[JavaScript 打包工具大奖赛（JavaScript Bundler Grand Prix）](https://javascriptweekly.com/link/178698/web) — 打包工具如今已经成为大部分 JavaScript 工作流的核心，甚至被集成进一些运行时本身（例如 [Bun](https://javascriptweekly.com/link/178699/web)）。这篇文章对当下打包工具的生态进行了盘点，并提出一个观点：**“速度战”基本告一段落，真正的战场正在转向产物体积，以及最终真正发给用户的代码质量。**

## Coding with AI：JavaScript 开发者的实战之路（赞助）

[用 AI 编码：JavaScript 开发者的实战路径（Coding with AI: The Practical Path for JavaScript Devs）](https://javascriptweekly.com/link/178697/web) — 一门来自 Frontend Masters 的课程，重点不是花哨 Demo，而是**如何将 AI 实实在在地融入 JavaScript 开发生产力**：从提示工程、编码 Agent，到 MCP、ML 以及生产级应用落地。

## 我用 LLM 在 4.5 小时内把 JustHTML 从 Python 迁到 JavaScript

[我用 LLM 在 4.5 小时内把 JustHTML 从 Python 迁到 JavaScript（I Ported JustHTML from Python to JavaScript with LLMs in 4.5 Hours）](https://javascriptweekly.com/link/178700/web) — 资深博主 Simon Willison 分享了他如何利用 OpenAI Codex CLI 和 GPT 5.2，将一个通过 9200+ 条 [html5lib 测试](https://javascriptweekly.com/link/178701/web)的 HTML5 解析器从 Python 迁移到 JavaScript。[可以在线体验最终结果](https://javascriptweekly.com/link/178702/web)，也可以直接[查看源码](https://javascriptweekly.com/link/178703/web)。

## 2025 年度 Top 10 热门链接

基于读者互动数据统计，以下是 2025 年最受关注的 10 篇链接：

1. [令人困惑的 JavaScript 解析谜题（A Perplexing JavaScript Parsing Puzzle）](https://javascriptweekly.com/link/178716/web) — 一道只有 14 字节的 JavaScript 解析谜题，却让大量资深 JS 工程师“翻车”。即便作者自己在写了几十年 JavaScript 之后，第一次也答错了。
2. [Ecma 国际通过 ECMAScript 2025：有哪些新内容？（Ecma International Approved ECMAScript 2025: What’s New?）](https://javascriptweekly.com/link/178717/web) — 每年 Ecma 大会都会批准最新一版 ECMAScript 语言规范，你也可以[直接阅读 ES2025 规范全文](https://javascriptweekly.com/link/178718/web)，不过更推荐 Dr. Axel 的这篇高质量总结。
3. [MACROSCOPE：面向开源项目的免费 AI 代码审查（MACROSCOPE - Free AI Code Review for Open Source）](https://javascriptweekly.com/link/178719/web) — 面向开源项目的免费 AI 代码审查工具，商用项目则可使用 OSSAI，并享受前两个月 5 折优惠。
4. [我越来越喜欢生成器的人机工程体验（I Think the Ergonomics of Generators is Growing on Me）](https://javascriptweekly.com/link/178720/web) — 一篇关于生成器（Generator）使用体验的思考文章，如果你从未在生产中过生成器，这篇文章是一个不错的入门视角。作者认为“它们的实用性还没有真正被挖掘出来”。
5. [Web 正在如何使用 JavaScript（How the Web is Using JavaScript）](https://javascriptweekly.com/link/178722/web) — 来自今年 HTTP Archive *Web Almanac* 报告中的 JavaScript 章节，深入分析了 Web 世界到底在如何使用 JS：代码体积、TypeScript 流行度、Web Worker 使用情况，以及……是的，[jQuery 依然非常流行](https://javascriptweekly.com/link/178722/web)。
6. [如何让 package.json 不失控（How to Keep package.json Under Control）](https://javascriptweekly.com/link/178724/web) – 关于如何保持 `package.json` 依赖“干净可控”的最佳实践与工具推荐。
7. [JavaScript 简史（A Brief History of JavaScript）](https://javascriptweekly.com/link/178725/web) – 一份极其详尽的 JavaScript 历史时间线，将在很长一段时间内都是学习 JS 发展史的权威资源。
8. [战争故事：我调试过的最棘手 Bug（War Story: The Hardest Bug I Ever Debugged）](https://javascriptweekly.com/link/178726/web) – 一位前 Google Docs 工程师讲述了十年前他们遇到过的“最难调试的 Bug”之一的故事。
9. [人们常误解的那些 Electron 事实（Things People Get Wrong About Electron）](https://javascriptweekly.com/link/178727/web) – Electron 维护者之一对项目多年来所做技术决策的一次系统性辩护，回应了围绕 Electron 的一些常见误解。
10. [是时候转向只支持 ESM 了（Move On to ESM-Only）](https://javascriptweekly.com/link/178728/web) – Anthony 解释了为何现在是时候让包“只支持 ESM”，而不是同时兼容 ESM 和 CommonJS。

## 2025：JavaScript 一年大事记（月度回顾）

### 一月（JANUARY）

这一年对替代 JavaScript 运行时来说是个高产的开始，Bun 发布了 [Bun 1.2 发布](https://javascriptweekly.com/link/178729/web)。同时，我们也看到了关于 [Express.js 未来规划的大更新](https://javascriptweekly.com/link/178730/web)。

### 二月（FEBRUARY）

一部关于 Angular 的[长篇纪录片](https://javascriptweekly.com/link/178731/web)发布。与此同时，Deno 与 Oracle 围绕“JavaScript 商标”的[法律拉锯战](https://javascriptweekly.com/link/178732/web)仍在继续。[TypeScript 5.8 发布](https://javascriptweekly.com/link/178733/web)，尤其对 Node 开发者意义重大。还有人用 TypeScript 的类型系统实现了一个[完全用类型跑的 Doom](https://javascriptweekly.com/link/178734/web)。

### 三月（MARCH）

[Babylon.js 8.0 发布](https://javascriptweekly.com/link/178735/web)，这是微软维护的重量级 3D 引擎。与此同时，[Express 5.1 发布](https://javascriptweekly.com/link/178736/web) 也正式发布。

### 四月（APRIL）

[Koa 3.0 发布](https://javascriptweekly.com/link/178737/web)；[一场重要的 Node.js 协作峰会](https://javascriptweekly.com/link/178738/web)在巴黎召开；[p5.js 2.0 发布](https://javascriptweekly.com/link/178739/web) 也在本月发布。

### 五月（MAY）

Remix 项目经历了一次[重大调整](https://javascriptweekly.com/link/178740/web)。[GSAP 动画工具包](https://javascriptweekly.com/link/178741/web) 宣布免费开放使用。[Glitch 平台宣布关闭](https://javascriptweekly.com/link/178742/web)。Deno 团队整理了[一份精彩的 JavaScript 历史时间线](https://javascriptweekly.com/link/178725/web)，微软则发布了[原生 Go 版本 TypeScript 的首个预览](https://javascriptweekly.com/link/178743/web)。

### 六月（JUNE）

[Oxlint 1.0 发布](https://javascriptweekly.com/link/178744/web) 和 [Vite 7.0 发布](https://javascriptweekly.com/link/178745/web) 双双发布。Dr. Axel 公布了 ES2025 版本的《Exploring JavaScript》新书（[相关介绍](https://javascriptweekly.com/link/178746/web)）。[Biome v2 发布](https://javascriptweekly.com/link/178747/web) 成为首个无需依赖 `tsc` 的“类型感知” linter，Ecma International 也正式[通过了 ECMAScript 2025 规范](https://javascriptweekly.com/link/178717/web)。

### 七月（JULY）

[JS1024 代码高尔夫比赛](https://javascriptweekly.com/link/178749/web) 举行，[Deno 2.4 发布](https://javascriptweekly.com/link/178750/web)，[Vercel 宣布收购 NuxtLabs](https://javascriptweekly.com/link/178751/web)。

### 八月（AUGUST）

[TypeScript 5.9 发布](https://javascriptweekly.com/link/178752/web) 和 [Apache ECharts 6 发布](https://javascriptweekly.com/link/178753/web)。jQuery 团队发布了 [jQuery 4.0 的 RC 版本](https://javascriptweekly.com/link/178754/web)（正式版仍在路上）。

### 九月（SEPTEMBER）

[Mediabunny 媒体处理引擎](https://javascriptweekly.com/link/178755/web) 在媒体处理领域引起关注。[Chrome 庆祝其 17 岁生日](https://javascriptweekly.com/link/178756/web)。同时，一系列 npm 包遭遇钓鱼攻击导致被劫持，[拉开了一段混乱的 npm 供应链安全时期](https://javascriptweekly.com/link/178757/web)。作为回应，[pnpm 增加了延迟依赖更新功能](https://javascriptweekly.com/link/178758/web)。macOS Tahoe 用户发现，[Electron 应用在新系统上出现卡顿](https://javascriptweekly.com/link/178759/web)，原因是某个私有 API 的改动。Deno 项目则[向社区募集 20 万美元](https://javascriptweekly.com/link/178760/web)，以支援其在 JavaScript 商标案件中的诉讼。

### 十月（OCTOBER）

[React Compiler v1.0 发布](https://javascriptweekly.com/link/178761/web)，[Node.js v25.0 发布](https://javascriptweekly.com/link/178762/web)，[Node.js 24 成为新的 LTS 版本](https://javascriptweekly.com/link/178763/web)。React 团队[宣布成立 React Foundation](https://javascriptweekly.com/link/178764/web)，以逐步弱化 React 与 Meta 公司之间的直接绑定。[Bun 1.3 发布](https://javascriptweekly.com/link/178765/web) 引发大量讨论，Evan You 也[公布了 Vite+ 项目](https://javascriptweekly.com/link/178766/web)。GitHub 则宣布 [TypeScript 成为了平台上 #1 的语言](https://javascriptweekly.com/link/178767/web)。

### 十一月（NOVEMBER）

代号“Shai Hulud”的供应链攻击[以“第二形态”回归](https://javascriptweekly.com/link/178768/web)。[JavaScript Engines Zoo 项目](https://javascriptweekly.com/link/178769/web) 上线，向大家展示当今 JavaScript 引擎与运行时生态的多样性。Google 发布了 [Angular v21 发布](https://javascriptweekly.com/link/178770/web)。

### 十二月（DECEMBER）

[JavaScript 正式迎来 30 周岁生日](https://javascriptweekly.com/link/178778/web)。微软分享了 [TypeScript 7.0 的最新进展](https://javascriptweekly.com/link/178771/web)，[Deno 2.6 发布](https://javascriptweekly.com/link/178772/web)。[Node.js v24.12.0 (LTS) 发布](https://javascriptweekly.com/link/178773/web) 同时发布，使“类型剥离（type stripping）”首次在 LTS 版本中变为稳定特性。
