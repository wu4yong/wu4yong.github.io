# HTML+CSS

## 伪元素

* css 的伪元素，之所以被称为伪元素，是因为他们不是真正的页面元素，html 没有对应的元素，但是其所有用法和表现行为与真正的页面元素一样，可以对其使用诸如页面元素一样的 css 样式，表面上看上去貌似是页面的某些元素来展现，实际上是 css 样式展现的行为，因此被称为伪元素
* p::after 伪元素使用定位时它的直接父元素就是这个 p 元素
* 伪元素 ::before 和 ::after 添加的内容默认是 inline 元素
* ::before 和 ::after 时必须设置其 content 属性，否则伪元素就不起作用
* 伪元素是通过样式来达到元素效果的，也就是说伪元素不占用 dom 元素节点。

## 伪元素的特点

1. 伪元素不属于文档，所以 js 无法操作它
2. 伪元素属于主元素的一部分，因此点击伪元素触发的是主元素的 click 事件
3. 原文说块级元素才能有 ::before, ::after，其实是不妥的，大部分行级元素也可以设置伪元素，但是像 img 可替换元素，因为其外观和尺寸由外部资源决定，那么如果外部资源正确加载，就会替换掉其内部内容，这时伪元素也会被替换掉，但是当外部资源加载失败时，设置的伪元素是可以起作用的。

## 基于伪元素的特点可以知道其优缺点

* 优点

1. 减少 dom 节点数
2. 让 css 帮助解决部分 js 问题，让问题变得简单

* 缺点

1. 不利于 SEO
2. 无法审查元素，不利于调试

## 常见伪元素

- 规范定义的伪元素还包括 `::first-letter`、`::first-line`、`::marker`、`::selection`、`::placeholder`、`::backdrop`、`::file-selector-button` 等
- `::first-letter` 作用于段落首字母，`::first-line` 作用于段落第一行
- `::marker` 用于修改列表项标记（圆点或序号）的样式，`::selection` 作用于用户选中的文本
- `::placeholder` 用于修改输入框占位文本的样式
- 双冒号 `::` 是 Selectors Level 3 起区分伪类与伪元素的写法；旧规范的单冒号写法（如 `:before`）多数浏览器仍兼容
- 一个选择器中只能出现一个伪元素，伪元素要跟在简单选择器之后

## ::before 和 ::after 的生成规则

- `::before` 成为匹配元素的第一个子元素，`::after` 成为最后一个子元素
- 这两个伪元素必须显式设置 `content`；`content` 为 `normal`、`none` 或无效值时，伪元素不渲染，行为如同 `display: none`
- 生成的盒子默认是行级元素，需要独占一行时再手动设置 `display: block`
- 不能用于 `<img>` 这类可替换元素：其外观和尺寸由外部资源决定，内容不在 CSS 格式化模型范围内
- `content` 里写特殊字符时使用 Unicode 转义序列，不能直接写 HTML 实体
- 伪元素的定位上下文就是主元素，给伪元素设置绝对定位时，包含块跟随主元素的定位规则

## 伪元素的使用限制

- 伪元素不进入 DOM 树，JavaScript 无法直接选中或操作它
- 点击伪元素触发的是主元素的事件，伪元素本身没有独立的事件目标
- 浏览器开发者工具可以在对应元素下查看生成的伪元素，但它不是真实的 DOM 节点
- 辅助技术（如屏幕阅读器）对伪元素内容的支持不可靠，装饰性内容可以用伪元素，承载语义的内容应写进真实 DOM
- 伪元素上能使用的样式与普通元素一致，但它的盒模型、定位和层叠行为都依附于主元素
- 伪元素不占用独立的 DOM 节点数，适合做图标、分隔线、引号等纯视觉装饰

## 伪元素与伪类的区别

- 伪类根据元素的状态（如 `:hover`、`:visited`、`:checked`）改变样式，选中的仍然是真实元素
- 伪元素创建的是文档中不存在的盒子或片段，用来修饰主元素的特定部分
- 特异性计算中，伪元素与类型选择器处于同一层级，伪类与类选择器处于同一层级
- 伪类可以和其他选择器组合使用，伪元素则必须放在整条选择器的末尾

## 常见用法示例

- 清除浮动的 clearfix 就是给父元素的 `::after` 设置 `content: ""`、`clear: both` 和 `display: block`
- 列表项的圆点、序号样式可以通过 `::marker` 调整，不需要替换成真实元素
- 引用段落的前后引号、卡片左上角装饰等纯视觉元素，适合用 `::before` 和 `::after` 生成

## 伪元素内容的生成方式

- `::before` 的内容排在主元素现有子节点之前，`::after` 的内容排在最后
- 伪元素生成的是盒子，不生成文本节点，文本内容通过 `content` 属性给出
- `content` 可以接受字符串、图标引用、计数器等取值，不支持直接嵌入 HTML 标签
- 计数器 `counter()` 配合 `::marker` 或 `::before` 可以输出列表序号
- 伪元素继承主元素的可继承样式，字体、颜色等属性默认跟随主元素
- 需要给伪元素独立配色或尺寸时，在伪元素选择器上单独书写对应声明
- 伪元素可以参与主元素内部的层叠和定位，与真实子元素按同一套规则排列
- `::before` 和 `::after` 互不冲突，可以同时出现在同一个主元素上
- 伪元素上设置的外边距、内边距和边框同样计入盒子模型计算
- 装饰性伪元素不需要写进无障碍标签，承载信息的文字不能只放在伪元素里
- 浏览器对个别伪元素的支持程度不同，上线前需要对照兼容性表确认目标环境
- 伪元素不能通过 `querySelector` 等 DOM 接口选中，样式调试在开发者工具的元素面板中进行
- 伪元素的盒模型尺寸由主元素的可用空间和自身样式共同决定，不会自动撑开主元素之外的文档流
- 选择器末尾同时写伪类和伪元素时，伪元素排在最后面，伪类写在它之前
- 伪元素生成的内容随主元素一起被复制，例如打印或克隆主元素时伪元素样式同样生效
