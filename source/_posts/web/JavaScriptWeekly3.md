## 主要文章

[JavaScript Source Maps 的内部工作原理](https://javascriptweekly.com/link/176757/web) — 有没有想过开发者工具如何神奇地将被混淆、压缩的 JavaScript 还原成可读的源代码？这不是魔法；而是 [Source Map](https://javascriptweekly.com/link/176758/web) 在发挥作用。但 Source Map 实际上是如何工作的？

[无需依赖 API 密钥即可实现安全的 MCP 身份验证](https://javascriptweekly.com/link/176756/web) — API 密钥难以限定范围且会破坏用户流程。WorkOS Connect 提供完全合规的 OAuth 2.1 流程。它开箱即用地处理 PKCE、作用域、用户同意和安全令牌签发。

## 🎯 Anders Hejlsberg 谈 TypeScript 的崛起

[Anders Hejlsberg 谈 TypeScript 的崛起](https://javascriptweekly.com/link/176759/web) — TypeScript 的联合创造者表示，他对该语言的成功感到"震惊"（现在是 [2025 年 GitHub 上排名第一的语言](https://javascriptweekly.com/link/176760/web)），并分享了一些关于正在进行的用 Go 重写编译器的信息，以及 AI 日益增长的作用。

[使用 Hako 嵌入 TypeScript](https://javascriptweekly.com/link/176761/web) — 对 [Hako](https://javascriptweekly.com/link/176762/web) JavaScript 引擎的技术深入探讨。它运行在 WebAssembly 中，因此可以更容易地嵌入到更多环境中，包括移动应用。

## 🛠 代码和工具

![110703](@@CDN@@/assets/img/web/JavaScriptWeekly3/img-03.webp)

[Perspective 4.0：高性能分析和数据可视化组件](https://javascriptweekly.com/link/176788/web) — 最初由摩根大通构建，这个用 C++ 编写并编译为 WebAssembly 的数据可视化组件非常适合大型和实时流数据集。主页上的演示让你可以尝试每秒高达 1000 次更改的可视化类型。v4.0 [项目迁移到 OpenJS 基金会](https://javascriptweekly.com/link/176789/web)。

💡 Perspective 附带了一套丰富的[示例](https://javascriptweekly.com/link/176790/web)，带有完整代码演示如何使用它，[如这个流式示例](https://javascriptweekly.com/link/176791/web)。

[Agentic Postgres：让你的 Agents 大展身手](https://javascriptweekly.com/link/176792/web) — 更快地构建 AI 应用：内置内存、搜索和免费可分叉数据库的 Postgres。在 Tiger 上免费试用。

[Vue Data UI 3.6：用于数据叙事的 Vue 组件库](https://javascriptweekly.com/link/176793/web) — 这个组件套件包含了很多内容，包括基本图表类型、甜甜圈图、迷你图、世界视图、堆叠图、热力图、词云等等。如果你使用 Vue，绝对值得一看。[在线示例](https://javascriptweekly.com/link/176794/web)。

🖼️ [image-dimensions：获取图像尺寸](https://javascriptweekly.com/link/176795/web) — 一种零依赖的方式，在_任何_现代 JavaScript 环境中获取 JPEG、PNG/APNG、GIF、WebP、AVIF 和 HEIF 图像的像素宽度和高度。

[React Syntax Highlighter：代码语法高亮组件](https://javascriptweekly.com/link/176796/web) — 如果你需要在 React 应用的某个地方展示源代码，这是一个可以完成工作的组件。[GitHub 仓库](https://javascriptweekly.com/link/176797/web)。

[CSSOM：用纯 JavaScript 编写的 CSS 解析器](https://javascriptweekly.com/link/176798/web) — 也是 CSS 对象模型的部分实现。

[debounce 3.0](https://javascriptweekly.com/link/176799/web) – 延迟函数调用，直到最后一次调用后经过设定时间。现在是纯 ES 模块。

[bcrypt.js 3.0.3](https://javascriptweekly.com/link/176800/web) – 在纯 JavaScript 中优化的 bcrypt，甚至可以在浏览器中使用。

[Marked 17.0](https://javascriptweekly.com/link/176801/web) – Markdown 解析器和编译器。([文档](https://javascriptweekly.com/link/176802/web))

[AlaSQL.js 4.8](https://javascriptweekly.com/link/176803/web) – 同构 JavaScript SQL 数据库。

[fast-copy 4.0](https://javascriptweekly.com/link/176804/web) – 快速的深度对象复制器。
